---

`argvus-hyprland` empacota o compositor; `argvus-portal` integra portais XDG; `argvus-greeter` integra greetd; `argvus-lock` integra Hyprlock; o overlay de loading do `argvus-gtk` integra o loading da sessão; e `argvus-boot-splash` integra o boot.
