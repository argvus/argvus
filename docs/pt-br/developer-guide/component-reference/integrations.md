`argvus-hyprland` empacota o compositor; `argvus-portal` integra portais XDG; `argvus-greeter` integra greetd; `argvus-lock` integra Hyprlock; `argvus-theme-splash` integra o loading da sessão; e `argvus-splash` integra o boot Plymouth.
