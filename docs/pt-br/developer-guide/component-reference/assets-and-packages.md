`argvus-appearance` possui o estado de tema e accent, os orquestradores de tema e os adapters para consumidores externos. Os consumidores visuais gerados são do `argvus-config`. `argvus-wallpapers`, `argvus-fonts` e `argvus-icons` fornecem assets. `argvus-app-profiles` fornece perfis de aplicativos. `argvus-waybar` empacota o binário Waybar corrigido.
