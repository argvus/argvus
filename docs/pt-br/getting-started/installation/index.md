ARGVUS é distribuído como pacotes Arch assinados. O instalador público configura o repositório ARGVUS; o conjunto de pacotes instala os componentes do desktop.

Veja os [requisitos](/pt/docs/getting-started/installation/requirements/), siga a [instalação](/pt/docs/getting-started/installation/install/) e conclua com a [primeira sessão](/pt/docs/getting-started/installation/first-session/).
