ARGVUS é um desktop modular baseado em Hyprland e Wayland para Arch Linux. Comece pela [instalação](/docs/getting-started/installation/) e escolha uma funcionalidade no guia.

O desktop combina uma sessão Hyprland, uma taskbar Waybar, um painel Quickshell, aplicativos nativos e provedores do sistema. A [arquitetura](/docs/developer-guide/architecture/overview/) explica como essas partes trabalham juntas.
