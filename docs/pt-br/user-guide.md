ARGVUS é um desktop modular baseado em Hyprland e Wayland para Arch Linux. Comece pela [instalação](./user-guide/installation/) e escolha uma funcionalidade no guia.

O desktop combina uma sessão Hyprland, uma taskbar Waybar, um painel Quickshell, aplicativos nativos e provedores do sistema. A [arquitetura](./developer-guide/architecture/overview/) explica como essas partes trabalham juntas.
