Esta seção guia você desde uma instalação limpa do Arch Linux até um desktop ARGVUS em funcionamento.

Se você quer apenas o caminho mais rápido, veja o [Início Rápido](/docs/quick-start/).

## Passos

1. Confira os [requisitos](/docs/getting-started/installation/requirements/) para seu hardware e stack gráfica.
2. Siga [Instalar o ARGVUS](/docs/getting-started/installation/install/) para adicionar o repositório de pacotes e instalar os pacotes.
3. Finalize com a [Primeira sessão](/docs/getting-started/installation/first-session/) para iniciar sua sessão gráfica ou TTY pela primeira vez.

Com o ARGVUS em execução, o [Guia do Usuário](/docs/user-guide/) cobre a configuração do dia a dia: aparência, sessões, aplicativos, hardware e muito mais.
