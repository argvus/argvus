---
title: Início Rápido
description: Deixe o ARGVUS rodando em um único comando.
---

A forma mais rápida de experimentar o ARGVUS em uma instalação nova do Arch Linux, direto de um TTY:

```sh
curl -fsSL https://argvus.github.io/install.sh | sh
```

Esse comando único importa e assina a chave do repositório ARGVUS, configura o repositório de pacotes, atualiza o banco de dados de pacotes e instala o pacote `argvus` com suas dependências.

Saia da sessão, selecione **ARGVUS** no seu gerenciador de login (ou inicie uma sessão TTY), e pronto.
