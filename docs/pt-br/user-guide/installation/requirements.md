---

ARGVUS tem como alvo o Arch Linux e requer uma pilha gráfica compatível com Wayland, Hyprland e as dependências instaladas pelos pacotes. Um display manager é opcional: há fluxo gráfico com greetd e fluxo manual por TTY.

Antes de instalar, confirme que o sistema está atualizado, possui kernel e driver gráfico funcionais, permite uma sessão Wayland e tem acesso à rede. Máquinas virtuais podem exigir os ajustes de [máquinas virtuais](../virtual-machines/).
