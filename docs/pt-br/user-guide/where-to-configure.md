Use esta tabela quando souber o que quer alterar, mas não qual superfície do ARGVUS é responsável por isso.

| Quero… | Vá para… |
| --- | --- |
| Escolher tema ou modo | **Control Center → Aparência → Temas** |
| Alterar a cor de destaque | **Control Center → Aparência → Acentos** |
| Alterar o wallpaper | **Control Center → Aparência → Wallpapers** |
| Ativar ou desativar efeitos visuais | **Control Center → Aparência → Efeitos**, **Control Center → Aparência → Inicializadores**, **Control Center → Configuração**, **Taskbar**, **Widget Telemetry** ou **Control Panel** |
| Alterar posição ou agrupamento de utilitários da taskbar | **Control Center → Aparência → Espaços, bordas e posição** |
| Personalizar JSONC ou CSS da taskbar | [Overrides da Waybar e da taskbar](/pt/docs/argvus-waybar/) |
| Alterar gaps ou bordas das janelas | **Control Center → Aparência → Espaços, bordas e posição** |
| Escolher cards visíveis do Control Panel | **Control Center → Aparência → Control Panel** |
| Alterar atalhos de teclado | **Control Center → Localidade e região → Atalhos de teclado** |
| Adicionar uma regra avançada do Hyprland, configuração de monitor ou novo keybinding | [Overrides do Hyprland](/pt/docs/argvus-hyprland/hyprland-overrides/) |
| Alterar comportamento do mouse ou touchpad | **Control Center → Localidade e região → Mouse e touchpad** |
| Alterar fontes | **Control Center → Fontes** |
| Escolher aplicativos padrão | **Control Center → Aplicativos padrão** |
| Alterar configurações de display | **Control Center → Displays** ou card de display do Control Panel |
| Verificar ou alterar conexões de rede | Card de rede do Control Panel; a configuração permanente usa as ferramentas de rede instaladas |
| Alterar volume ou silenciar rapidamente | Card de volume do Control Panel ou teclas de mídia |
| Alterar brilho rapidamente | Card de brilho do Control Panel ou teclas de brilho |
| Bloquear, sair, suspender ou desligar | Cards de sessão/energia do Control Panel |
| Configurar idioma, fuso horário ou região | **Control Center → Localidade e região** |

## Configuração ou ação rápida?

O Control Center é o lugar quando você quer que um ajuste continue fazendo parte da configuração do desktop. O Control Panel é o lugar quando você quer consultar status ou executar uma ação frequente agora. Alguns cards do Control Panel abrem os mesmos providers usados pelo Control Center, mas o painel não é uma segunda base de configurações.

Se uma configuração não estiver listada, use a busca da tela inicial do Control Center. O registro de busca inclui rotas de aparência e os domínios de teclado, entrada, display, rede e sessão voltados ao usuário.
