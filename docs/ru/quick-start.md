---
title: Быстрый старт
description: Запустите ARGVUS одной командой.
---
Самый быстрый способ попробовать ARGVUS на свежей установке Arch Linux прямо из TTY:

```sh
curl -fsSL https://argvus.github.io/install.sh | sh
```
Эта одна команда импортирует и подписывает ключ репозитория ARGVUS, настраивает репозиторий пакетов, обновляет базу данных пакетов и устанавливает пакет `argvus` с его зависимостями.

Выйдите из системы, выберите **ARGVUS** в вашем дисплейном менеджере (или запустите TTY сессию), и вы войдете в систему.
