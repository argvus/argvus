ARGVUS — это коллекция независимо упакованных проектов, объединённых общей конфигурацией, сервисами пользователя systemd, контрактами Wayland/Hyprland и общей системой интернационализации (i18n).

- [Архитектура](/docs/developer-guide/architecture/overview/)
- [Подсистемы](/docs/developer-guide/subsystems/session-and-systemd/)
- [Разработка](/docs/developer-guide/development/environment/)
- [Справочные материалы](/docs/reference/)

Исходные репозитории под `de/` являются авторитетными. Манифесты пакетов и установленные единицы определяют границы времени выполнения; файлы README являются дополнительными.
