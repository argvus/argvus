---
title: Упаковка
description: Создавайте и проверяйте пакеты ARGVUS для Arch.
---
Каждый компонент владеет своей Arch-пакетной сборкой в своем репозитории. Проверьте `packaging/archlinux/`, функции пакета и список установленных файлов перед документированием полезной нагрузки. Настройки пакета по умолчанию в `/usr/share/argvus` и конфигурация администратора в `/etc/argvus` не взаимозаменяемы.

Для проверки во время выполнения сравните содержимое пакета с `pacman -Ql <package>` и отдельно проверьте активные пользовательские изменения.

Локальные сборки сохраняют объекты Cargo в `build/cargo-target`, вне исходного дерева пакета, поэтому повторная `make build` перекомпилирует только то, что изменилось. `make clean` удаляет этот каталог, и следующая сборка начинается с нуля.

Не делайте вывод о полезной нагрузке во время выполнения только по названию репозитория. Пакет может содержать бинарные файлы, пользовательские сервисы, настройки по умолчанию `/usr/share/argvus`, конфигурацию администратора `/etc/argvus` или ресурсы. Подтвердите фактическую полезную нагрузку с помощью `PKGBUILD` и `pacman -Ql` репозитория после установки.
