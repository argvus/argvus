---
title: Установка
description: Установите пакеты ARGVUS на Arch Linux.
---
ARGVUS распространяется в виде подписанных пакетов Arch Linux. Публичный установщик настраивает репозиторий пакетов ARGVUS; затем набор пакетов устанавливает компоненты рабочего стола.

См. [requirements](/docs/getting-started/installation/requirements/), следуйте [installation steps](/docs/getting-started/installation/install/) и завершите [first session](/docs/getting-started/installation/first-session/).

Репозиторий пакетов и метапакет `argvus` поддерживаются отдельно от пакетов компонентов рабочего стола. См. [package matrix](/docs/reference/package-matrix/) для сведений о владельцах.
