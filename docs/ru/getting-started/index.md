Этот раздел проведет вас через все шаги, необходимые для перехода от чистой установки Arch Linux к работоспособному рабочему столу ARGVUS.

Если вы хотите только самый короткий путь, смотрите [Quick Start](/docs/quick-start/).

## Шаги

1. Проверьте [requirements](/docs/getting-started/installation/requirements/) для вашего оборудования и графического стека.
2. Следуйте [Install ARGVUS](/docs/getting-started/installation/install/) для добавления репозитория пакетов и установки пакетов.
3. Завершите с [First session](/docs/getting-started/installation/first-session/), чтобы запустить графическую сессию или TTY в первый раз.

После запуска ARGVUS, [User Guide](/docs/user-guide/) охватывает повседневную настройку: внешний вид, сессии, приложения, оборудование и многое другое.
