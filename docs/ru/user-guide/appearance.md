Цвет, показанный в таблице, это значение, записанное в `config.json` при выборе этой семьи или при использовании **Сбросить к теме по умолчанию**. Ручной выбор шестизначного RGB-акцента применяется до следующей смены темы, которая заменяет его на значение темы по умолчанию.

**Прилипающий (Sticky)** — это компактная раскладка: плиточные окна используют маленькие внутренние отступы, внешние отступы равны нулю, а панель задач находится близко к краю экрана. **С расширением (Spaced)** добавляет большие отступы, закругленные углы, тени и поля вокруг панели задач и оболочки.

Существующие значения раскладки `float` и идентификаторы тем `-float` распознаются как устаревшие названия для Spaced. Новые значения раскладки и разрешенные идентификаторы тем используют `spaced` и `-spaced`.

Режим изменяет геометрию и обработку поверхности; он не создает шестую цветовую семью. См. [Themes](/docs/user-guide/appearance/)] для выбора и [Desktop](/docs/user-guide/desktop/)] для расположения панели задач и окон.

## Колебание окна

Откройте **Рабочий стол и ввод → Hyprland → Анимации → Окна** и используйте
элементы управления **Колебание**. Найдите `wobble`, или откройте страницу напрямую:

```sh
argvus control-center hyprland animations windows
```
Колебание по умолчанию отключено. Его значения по умолчанию в ARGVUS: жесткость `100`, демпфирование `10`, масса `1`, интенсивность `1` и разрешение сетки `8`. Жесткость и масса принимают `0.0001–1000`, демпфирование `0–1000`, интенсивность `0–2`, а сетка — целое число `2–32`. Более высокое разрешение сетки увеличивает затраты на рендеринг. Используйте клавиши со стрелками для изменения значений или Enter для их ввода. **Восстановить значения по умолчанию для Колебания** изменяет черновик; **Применить** сохраняет все ожидающие изменения анимации и один раз перезагружает Hyprland без перезапуска сессии. Возврат в раздел Анимации сохраняет общий черновик.

Глобальный переключатель Анимаций подавляет Колебание, при этом сохраняя его индивидуальные настройки. Канонические значения находятся под `effects.wobble_*` в состоянии ARGVUS; `hypr/state.lua` генерируется и не должен редактироваться вручную.

Для этого требуется Hyprland **0.57.0 или новее**, что обеспечивается зависимостью пакета `argvus-hyprland`. Версия 0.56 не поддерживается для этой конфигурации. Максимальная интенсивность соответствует [релизу исходного кода 0.57.0](https://github.com/hyprwm/Hyprland/blob/v0.57.0/src/config/values/ConfigValues.cpp), который ограничивает её до `2`, хотя в более новой документации может быть указано `3`.
