ARGVUS приложения читать `ARGVUS_LANGUAGE` от пользователя `locale.conf`Если он отсутствует, они разрешают региональный `LANG` значение для установленного каталога. Наследственные локальные переменные не переопределяют явные `ARGVUS_LANGUAGE` Предпочтение. Сторонние приложения продолжают использовать систему региональных локализаций.

Проверить эффективные значения с помощью:

```sh
systemctl --user show-environment | rg '^(LANG|LC_|ARGVUS)='

```
