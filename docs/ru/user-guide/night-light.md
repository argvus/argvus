---
title: Ночной свет
description: Отрегулируйте цветовую температуру и установленные локальные расписания в Hyprland.
---
Откройте **Панель управления > Рабочий стол и ввод > Дисплеи > Ночной режим**, найдите **Ночной режим**, или запустите `argvus control-center displays night-light`.

Ночной режим и его расписание изначально выключены. Выберите температуру от **1000 до 20000 Кельвинов** (по умолчанию **4500 К**). Меньшие значения дают более тёплые цвета. Страница показывает сохранённое ручное включение, фактическое состояние и следующую смену. Ввод значения редактирует его; Esc отменяет его или возвращает к Дисплеям. Неверные значения отклоняются до сохранения. Изменения сохраняются и применяются сразу. Если применение не удалось после сохранения, сохранённое предпочтение остаётся видимым рядом с фактическим состоянием и ошибкой.

## Расписание и быстрые действия

Фиксированное расписание использует текущий часовой пояс. Начало включается, а конец исключается; **20:00–07:00** пересекает полночь. Начало и конец должны различаться и использовать `HH:MM`. Местоположение или солнечные расчёты не используются.

Используйте карту **Дисплей** в Панели управления или **SUPER + Shift + B** для быстрых переключений. Селектор яркости сохраняет все свои действия по регулировке яркости и добавляет Ночной свет, когда доступен бэкенд, включая дисплей без бэкенда яркости. Постоянного модуля на панели задач нет.

При выключенном расписании ручная активация сохраняется. При включенном расписании быстрое переключение создаёт временное переопределение до следующего запланированного перехода. Изменение расписания или температуры снимает это переопределение. Выход из системы, новый экземпляр композитора или изменённый следующий переход (включая смену часового пояса) также делает его недействительным.

## Команды и состояние

Все интерфейсы используют одну и ту же публичную команду:

```sh
argvus config display night-light status
argvus config display night-light enable
argvus config display night-light disable
argvus config display night-light toggle
argvus config display night-light temperature 4500
argvus config display night-light schedule on 20:00 07:00
argvus config display night-light schedule off 20:00 07:00
argvus config display night-light apply
argvus config display night-light apply-schedule
```
`status` возвращает JSON-схему версии 1: `available`, `unavailable_reason`, `settings` (включено, температура, расписание включено, начало, конец), `active`, `effective_temperature`, `mode` (`manual` или `scheduled`), `manual_override`, `next_transition` (ISO 8601 с смещением), `minimum_temperature` и `maximum_temperature`. Эффективные поля равны null, если недоступны; эффективная температура равна null, если личность активна. Ошибки доступности сообщаются в статусе; ошибки действий возвращают ненулевое значение с диагностикой.

Каноническое предпочтение — `/displays/night_light`, сохраняется атомарно с помощью `argvus config` в `$XDG_CONFIG_HOME/argvus/config/displays.json`. Временные переопределения и блокировка действий находятся в `$XDG_RUNTIME_DIR/argvus/night-light/`. Сгенерированные файлы монитора независимы. Не редактируйте сгенерированные файлы для настройки этой функции.

## Время выполнения

Требуются Hyprland и **hyprsunset >= 0.4.0**. Сессия запускает верхний `hyprsunset.service` один раз, применяет сохранённое состояние через `argvus-night-light-init.service` и оценивает расписания каждую минуту через `argvus-night-light.timer` и `argvus-night-light.service`. Изменения часов и часового пояса также вызывают оценку. При отключённом расписании периодическая операция не меняет ручное состояние. Повторные применения проверяют фактическую идентичность/температуру и пропускают неизменённые записи. Перезагрузка композитора не требуется.

ARGVUS поставляет systemd drop-in для исходного сервиса: он начинается с `--identity` и изолирует обнаружение конфигурации к `/usr/share/argvus/session/config/night-light`. Это избегает конкуренции с нативными профилями и не затрагивает личные файлы `hyprsunset.conf`. Drop-in применяется к этому исходному сервису, пока установлен пакет сессии ARGVUS, включая запуск вне ARGVUS. Существующие системные переопределения пользователей могут иметь приоритет; проверяйте `systemctl --user cat hyprsunset.service` при диагностике этой ситуации. Hyprsunset 0.4.0 отклоняет отдельный аргумент пути `--config`, поэтому обнаружение конфигурации изолируется с помощью локальных для сервиса переменных XDG.

Бэкенд использует официальный Hyprsunset IPC (`temperature`, `identity`, `identity get`) с ограниченным вводом/выводом и чтением после изменений. Шейдеры, альтернативный бэкенд композитора, запись конфигурации системы или повышение привилегий не используются. Недоступные элементы управления отключены в Центре управления и скрыты в карточке дисплея.
