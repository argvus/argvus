Используйте эту таблицу, когда вы знаете, что хотите изменить, но не знаете, какая поверхность ARGVUS отвечает за это.

Для пошагового обзора основных областей рабочего стола откройте **ARGVUS Welcome** с `argvus welcome` или через **Центр управления → Инструменты и диагностика**.

| Я хочу… | Перейти в… |
| --- | --- |
| Выбрать тему или режим | **Центр управления → Внешний вид → Темы** |
| Изменить цвет акцента | **Центр управления → Внешний вид → Акценты** |
| Изменить обои | **Центр управления → Внешний вид → Обои** |
| Включить или отключить визуальные эффекты | **Центр управления → Внешний вид → Эффекты**, **Центр управления → Внешний вид → Запускатели**, **Центр управления → Настройки**, **Панель задач**, **Телеметрия виджетов** или **Панель управления** |
| Изменить положение панели задач, высоту, границу или группировку утилит | **Центр управления → Внешний вид → Панель задач → Положение**, **Высота**, **Граница** и **Значки** |

| Изменение зазоров или рамок окна | **Центр управления → Рабочий стол и ввод → Hyprland → Окна → Пространства** и **Рамки** |
| Изменение тени окна | **Центр управления → Рабочий стол и ввод → Hyprland → Рамки → Тень** |
| Выбор видимых карточек панели управления | **Центр управления → Внешний вид → Панель управления** |
| Изменение комбинаций клавиш | **Центр управления → Локаль и регион → Горячие клавиши** |

## Настройка или быстрое действие?

Центр управления — это место, куда следует обращаться, если вы хотите, чтобы настройка оставалась частью конфигурации рабочего стола. Панель управления — это место, куда следует обращаться, если вы хотите проверить состояние или выполнить частое действие сейчас. Некоторые карты Панели управления открывают те же базовые провайдеры, что используются в Центре управления, но сама панель не является второй базой данных настроек.

Если настройка не указана, используйте домашний поиск в Центре управления. Его реестр поиска включает маршруты внешнего вида для пользователя и такие области, как клавиатура, ввод, дисплей, сеть и сеанс.
