title: Первая конфигурация
description: Практический путь первой загрузки для настройки ARGVUS.
---
После первой графической сессии вам не нужно настраивать каждую часть ARGVUS. Начните с настроек, которые влияют на восприятие рабочего стола, затем настройте оборудование и сервисы по мере необходимости.

## Полезный порядок

1. Прочтите [обзор рабочего стола](/docs/user-guide/desktop/), чтобы определить окна, рабочие пространства, панель задач, Панель управления и лаунчер.
2. Откройте [Центр управления](/docs/components/argvus-control-center/) и выберите тему, режим, акцент и обои в разделе **Внешний вид**.
3. Настройте [окна и макет](/docs/argvus-hyprland/windows-and-layout/), если стандартные промежутки, границы или расстояние на панели задач не подходят для вашего экрана.
4. Настройте [панель задач](/docs/argvus-taskbar/taskbar/) и решите, какие карточки Панели управления вы хотите видеть.
5. Просмотрите [клавиатурные сокращения](/docs/argvus-hyprland/keyboard-shortcuts/) и изменяйте только те назначения, которые вы действительно используете.
6. Настройте [мышь и тачпад](/docs/argvus-hyprland/input/), дисплеи, сеть и питание на соответствующих страницах настроек.

Первые четыре шага являются необязательной персонализацией. Оставшиеся шаги обычно требуются только тогда, когда ваше оборудование, язык или рабочий процесс этого требуют.

## Два места для изменения настроек

Используйте **Панель управления** для настроек, которые описывают, как ARGVUS должен быть настроен: внешний вид, расположение, шрифты, ввод, горячие клавиши, язык, регион и приложения по умолчанию. Используйте **Панель управления (Control Panel)** для состояния и частых действий с сеансом, таких как громкость, яркость, состояние сети, уведомления, управление питанием и сеансом.

См. [Control Center vs Control Panel](/docs/components/argvus-control-center/) для полного различия] и [Где настроить вещи](/docs/user-guide/where-to-configure/) для быстрого справочника].

## Изменения, сохранение и восстановление

Большинство изменений в Центре управления применяются во время работы сеанса и сохраняются как состояние пользователя ARGVUS. Изменения внешнего вида фиксируются в канонической конфигурации, а `argvus-config` проецирует файлы, используемые Hyprland и оболочкой, из нее. Переключатель в Панели управления может быть прямым действием или изменением состояния сеанса вместо постоянной конфигурации.

Когда на странице предлагается **Сбросить настройки по умолчанию**, используйте это действие на странице, а не удаляйте созданные файлы. Во внешнем виде есть отдельные действия сброса для акцентов, обоев и значений макета; страница привязки клавиш имеет собственное действие восстановления. Нет одной универсальной кнопки сброса для всех настроек рабочего стола.
