---
title: Датчики температуры
description: Обзор текущей температуры с поддержкой JSON от lm_sensors.
---
`argvus sensors` открывает панель Ratatui в процессе, используемую всплывающим окном температуры ЦП на панели задач. Она запускает `sensors -j`, группирует показания по именам чипов и меткам, предоставленным аппаратным обеспечением, и обновляется каждые две секунды. Мониторинг GPU осуществляется `argvus system-monitor --gpu`.

Показания ведутся в градусах Цельсия. Панель отображает `max`, `crit` и состояние тревоги, когда их предоставляет lm_sensors. Индикатор показывается только тогда, когда имеется положительный лимит. Отсутствующие `lm_sensors`, сбои команд, недействительный JSON и пустые показания остаются видимыми как состояния, подлежащие восстановлению; повторная проверка выполняется в следующем цикле.

Нажмите `q` или `Esc`, чтобы закрыть. Панель задач открывает панель в Kitty через `argvus tui-terminal`; локализованная нижняя вкладка показывает подсказку закрытия. Эта команда управляет деталями температуры ЦП; значок температуры GPU открывает монитор btop только для GPU. Пакет панели задач уже зависит от `lm_sensors`, поэтому отдельный пакет или зависимость не требуются.
