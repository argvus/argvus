title: Съёмные устройства
description: Монтировать и управлять съемными накопителями через ARGVUS.
---
`argvus-removable-devices` отслеживает UDisks2 и предоставляет модуль хранения панели задач ARGVUS и его меню устройств. Меню также доступно как отдельный интерфейс в стиле Rofi, поэтому те же действия с устройствами могут использоваться как с панели задач, так и через запуск из рабочего процесса.

Доступные действия: `open`, `mount`, `unmount`, `eject`, `poweroff`, `lock`, `unlock` и `copy`. Команды `list`, `watch` и `menu` предоставляют соответствующие интерфейсы статуса, потока панели задач и меню для интеграций.

## Меню панели задач

С `"mode": "gui"` (системный по умолчанию) клик по иконке хранения на панели задач открывает GTK-меню, прикреплённое к панели задач ARGVUS, как всплывающее окно календаря: под панелью, если панель задач находится в верхней части экрана, и над ней, если панель задач находится внизу. Каждая строка устройства имеет подменю действий только с теми действиями, которые разрешены его состоянием.
- **Указатель:** при наведении или щелчке по строке устройства открывается её подменю. Подменю остаётся открытым, пока указатель пересекает края меню или покидает их, и оно переходит на другую строку только после того, как указатель ненадолго задерживается там, поэтому диагональный путь к подменю не закрывает его. Щелчок вне обоих меню закрывает всплывающее окно.
- **Клавиатура:** `Up`/`Down` выбирают строку, `Right`, `Enter` или `Space` открывают подменю (или выполняют **Обновить**/**Выйти**), `Enter` или `Space` выполняют выбранное действие, `Left` или `Escape` возвращают к списку устройств, а `Escape` закрывает всплывающее окно.

**Копировать путь** помещает точку монтирования в буфер обмена через `copy_command` (по умолчанию `wl-copy`, из `wl-clipboard`), так что путь остаётся после закрытия меню; уведомление подтверждает это, когда `show_notification` включён. **Блокировка** предлагается для каждого разблокированного зашифрованного тома и сначала размонтирует его, если это необходимо.

Действие файлового менеджера по умолчанию следует за файловым менеджером, выбранным в Центре управления ARGVUS. Это обеспечивает согласованность действий с переносными устройствами с настройками приложений пользователя по умолчанию.

Системная конфигурация — `/etc/argvus/removable-devices/config.json`. Управляемая ARGVUS проекция для каждого пользователя — `~/.config/argvus/data/removable-devices/config.json`, с соответствующей `theme.css` рядом с ней. Этот таблица стилей также проецируется на `~/.config/argvus/data/generated/removable-devices/theme.css` из канонической темы, акцента и режима, с резервным вариантом семейства/варианта для тем, которые не поставляются с отдельным ресурсом для переносных устройств, так что изменение темы сохраняет согласованность модуля без каких-либо ручных действий. Пути устаревших компонентов являются входными данными для миграции; последующая конфигурация пользователя переопределяет системные настройки по умолчанию.

Полезные настройки включают в себя, скрыт ли модуль, когда устройство отсутствует (`hide_when_empty`), отображаются ли имена и емкости, порядок сортировки устройств, поведение уведомлений, меню бэкенда и иконки состояния. Его таблица стилей формируется из активной темы ARGVUS (`removable-devices/theme.css` сборки темы) и копируется в `theme.css` панели при каждой смене темы или акцента.

Интерфейс использует язык пользователя из `LANG` в `$XDG_CONFIG_HOME/locale.conf`, с английским языком по умолчанию для неконфигурированного пользователя. Наследуемые переменные локали не выбирают язык интерфейса.

## Общие языковые каталоги

Интерфейс использует общие каталоги `argvus-i18n` для всех десяти языков. Тексты хранятся в `resources/locales/<locale>/removable-devices.json` в основном рабочем пространстве и устанавливаются `argvus`. Английский является запасным; новые языки больше не требуют локального билингвального словаря.
