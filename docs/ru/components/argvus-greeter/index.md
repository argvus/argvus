---
title: Приветствующий
description: Программа приветствия при входе в систему, которая запускается greetd, поставляется в пакете argvus.
---
`argvus-greeter` является экраном приветствия для greetd. Это терминальный интерфейс с поддержкой клавиатуры, который обнаруживает установленные сеансы Wayland, отображает учетные записи с их аватарами и применяет активную тему ARGVUS для выбранной учетной записи.

Он является частью пакета `argvus`, единственного пакета рабочего стола. Его исходный код находится в `crates/argvus-greeter` репозитория `argvus`, как часть корневого рабочего пространства Cargo, и собирается вместе с остальной частью `argvus`.

Экран приветствия сам по себе не аутентифицирует пользователей. Аутентификацию осуществляет greetd через PAM. Запуск происходит через `argvus tui-terminal`, поэтому экрану приветствия не нужна отдельная программа терминала.

Файлы конфигурации экрана приветствия устанавливаются в `/etc/argvus`. Используйте `argvus greeter-setup --help`, чтобы увидеть параметры настройки, предоставляемые пакетом. Для информации о процессе входа см. [Sessions](/docs/user-guide/sessions/).

Сокет передачи входа в систему авторизует каждого клиента с учетными данными ядра. Только root, владелец помощника и учетная запись, аутентифицированная через greetd, могут отправлять управляющие команды. Другим локальным учетным записям доступ запрещен, даже если сокет позволяет подключения между пользователями. Подготовленный DRM-фрейм остается привязанным к своему исходному дескриптору; помощник ждет этот дескриптор перед тем, как взять управление дисплеем.

Когда поле аутентификации в фокусе, вводимые печатные символы (включая `j` и `k`) добавляются в ответ. Tab и Shift-Tab перемещают фокус; Backspace удаляет последний символ. Это относится как к секретным, так и к не секретным подсказкам.

Список учетных записей прокручивается, чтобы выбранная учетная запись оставалась видимой при навигации или изменении размера терминала.
