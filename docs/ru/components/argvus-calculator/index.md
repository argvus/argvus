# Калькулятор ARGVUS

`argvus calculator` · `SUPER + C` · launcher: **ARGVUS Calculator**

Выберите профиль в Настройки → Профиль с помощью ↑/↓ и Enter или щелчком. Профиль и параметры сразу сохраняются и восстанавливаются при следующем запуске. В сеансе каждый профиль хранит своё выражение. Enter или = заменяет выражение результатом без выделения, с курсором в конце.

Ставки задаются в процентах за период; ставка, число периодов и платёж должны иметь одну периодичность. Платежи — в конце периода. Нулевая ставка поддерживается. Простые и сложные проценты дают накопленную сумму. Преобразование работает офлайн, без валют. История хранит до 100 записей с профилем, параметрами и финансовыми полями; выбор результата восстанавливает контекст. Очистка очищает и сохранённый файл.

## Настройки

- `s Настройки` → **Профиль** → Базовый / Научный / Программирование / Финансы / Преобразование единиц.
- ↑ / ↓ · Enter · Escape / ←.
- **Копировать результат** · **История** · **Очистить историю**.
- **Базовый**: 370 × 420; **Научный**: 440 × 640.
- **Программирование**: 520 × 640; **Финансы**: 440 × 640; **Преобразование единиц**: 440 × 520.

## Базовый / Научный

`+ - * / %` · `50% = 0.5` · `1.5 = 1,5` · `2+2` → Enter → `4` → `+2` → Enter → `6`.

`sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `sqrt`, `log`, `ln`, `exp`, `pi`, `e`, `^`, `(`, `)`.

**Единица угла**: Градусы / Радианы. `-2^2 = -4`; `2^3^2 = 512`; `2*pi`.

IEEE 754 / f64 · 15 значащих цифр · 4096 байт · 64 уровня разбора.

## Программирование

По умолчанию: десятичные числа, 64 бита со знаком. Переполнение ограничивается шириной слова; правый сдвиг со знаком расширяет знак. Целочисленное деление округляется к нулю. Деление на ноль и сдвиги вне [0, bits) — ошибки. Без префикса действует выбранное основание. Смена основания преобразует допустимое выражение; ширина и знак переинтерпретируют те же биты.

- **Основание**: 2 / 8 / 10 / 16; **Размер слова (биты)**: 8 / 16 / 32 / 64.
- **Со знаком** / **Без знака** · `0b1010`, `0o12`, `0xA`.
- `+ - * / %`, `AND OR XOR NOT`, `<< >>`, `& | ^ ~`, `(`, `)`.
- `9007199254740993+2 = 9007199254740995`; `0xFF AND 0b1010 = 10` (base 10).
- 8-bit: `255+1 = 0`; `NOT 0 = -1` (Со знаком); `-7/2 = -3`.

## Финансы

Простые проценты · Сложные проценты · Фиксированный платёж · Текущая стоимость · Будущая стоимость · Процентное изменение.

- `P`: Начальный капитал; `FV`: Будущая сумма; `A`: Платёж за период.
- `r`: Ставка за период (%) / 100; `n`: Число периодов.
- `G=(1+r)^n`; `H=(G-1)/r` (`r=0`: `H=n`).
- Простые проценты: `P*(1+r*n)`; Сложные проценты: `P*G`.
- Фиксированный платёж: `P*G/H`; Текущая стоимость: `(FV+A*H)/G`; Будущая стоимость: `P*G+A*H`.
- Процентное изменение: `(Конечная сумма - Исходная сумма) / Исходная сумма * 100`.

## Преобразование единиц

Длина · Масса · Температура · Площадь · Объём · Время · Скорость · Хранение данных.

**Из** / **В**: Настройки · `1500 m → 1.5 km` · `32 °F → 0 °C` · `K ≥ 0`.

`1 B = 8 bit`; `1 kB = 1000 B`; `1 KiB = 1024 B`; `US gal = 3.785411784 L`.

## История

100 · Профиль + `context` · `Очистить историю`.

`$XDG_DATA_HOME/argvus/calculator/history.json` (→ `~/.local/share/argvus/calculator/history.json`).

`$XDG_CONFIG_HOME/argvus/calculator/settings.json` (→ `~/.config/argvus/calculator/settings.json`).

`{"scientific":true}` → `{"profile":"scientific"}`; `{"scientific":false}` → `{"profile":"basic"}`.

`.desktop`: `/usr/share/applications/argvus-calculator.desktop` · `Name=ARGVUS Calculator` · `Exec=argvus calculator`.

Текст приложений использует Applications Font в Control Center → Appearance → Desktop Style → Fonts. GTK наследует gtk-font-name; размеры цифр и заголовков сохраняются. Лаунчер читает сгенерированный apps_family и отслеживает изменения.

Заголовок сочетает знак ARGVUS акцентного цвета с названием приложения. Нажимаемая строка s Settings занимает всю ширину на отдельном фоне темы в стиле Control Center.
