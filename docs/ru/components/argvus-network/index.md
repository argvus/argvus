---
title: Сетевые технологии и Bluetooth
description: Управляйте NetworkManager и Bluetooth через ARGVUS.
---
Подкоманда `argvus network` сообщает и управляет NetworkManager, а `argvus bluetooth` сообщает и управляет состоянием и доступностью адаптера Bluetooth. Обе выполняются в процессе внутри `argvus`; `networkctl` и `bluetoothctl` остаются как псевдонимы. Панель управления и Waybar вызывают эти команды.

Используйте `--help` с любой из команд для установленных подкоманд. Интеграция сети и Bluetooth в пользовательский интерфейс отделена от дополнительных опциональных менеджеров, таких как Blueman.

Центр управления разделяет состояние сети и страницы настройки: **Сеть → Состояние** подводит итог текущему состоянию, тогда как интерфейсы, Wi-Fi, Ethernet, VPN, DNS, прокси и брандмауэр являются отдельными маршрутами, когда их провайдеры доступны. **Bluetooth → Состояние**, **Устройства** и **Сопряжение** охватывают состояние адаптера и действия с устройствами. Эти страницы выполняют системные действия с поддержкой провайдера; панель задач и Панель управления предоставляют быстрый доступ к статусу и действиям.

Изменения в сети и Bluetooth могут требовать авторизации и могут применяться немедленно через NetworkManager или службу Bluetooth. Это не то же самое, что изменение индикатора панели задач ARGVUS.

Центр управления передает пароли Wi-Fi в nmcli через стандартный ввод с `--ask`; пароли исключаются из аргументов процесса и скрываются в возвращаемых ошибках команд.

## Управление сетью через командную строку

Используйте `argvus networkctl` для запроса и управления сетью без графического интерфейса:

```sh
# Show network status
argvus networkctl status

# Toggle networking on/off
argvus networkctl enable
argvus networkctl disable

# Wi-Fi control
argvus networkctl wifi on
argvus networkctl wifi off

# Open the network manager
argvus networkctl manager
```
## Управление Bluetooth через командную строку

Используйте `argvus bluetoothctl` для адаптера Bluetooth:

```sh
# Show the adapter state (key=value lines)
argvus bluetoothctl status

# Exit 0 when an adapter is available, 1 otherwise
argvus bluetoothctl available

# Turn the adapter on or off, or toggle it
argvus bluetoothctl enable
argvus bluetoothctl disable
argvus bluetoothctl toggle

# Open the Bluetooth manager (Blueman)
argvus bluetoothctl manager
```
Когда ядро не перечисляет ни одного контроллера в `/sys/class/bluetooth`, `status` отвечает `status=no-controller` немедленно, не спрашивая `bluetoothctl` (который в противном случае ждал бы BlueZ, когда служба остановлена). Модуль панели задач и карточки Панели управления читают тот же статус.

Используйте `--help` с любой командой, чтобы увидеть дополнительные параметры и подкоманды, специфичные для вашей установленной версии.

Когда диалоговое окно ввода пароля Wi-Fi открыто, обновления сканирования сохраняют выбранный SSID и тип безопасности. Если эта сеть исчезает или меняется её безопасность, подтверждение прекращается с ошибкой и требует нового выбора.

Ручная настройка DNS отправляет IPv4 и IPv6 серверы в соответствующие настройки NetworkManager перед обновлением файла разрешателя. Символические ссылки на решатель, управляемые службой, сохраняются за счёт отказа от замены файла. Успешное возвращение к автоматическому DNS восстанавливает и удаляет резервную копию, поэтому последующий ручной цикл сохраняет текущее состояние разрешателя.

Закрытие редактора сетевого профиля ожидает завершения текущей задачи, поэтому сохранение или удаление профиля не может быть прервано путем закрытия редактора. Фоновое обновление остается возможным для отмены.

Запросы на Wi-Fi соединение используют общий механизм защиты действий сети: выполняющаяся операция или задача редактора профиля завершается, прежде чем может начаться другое изменение. Сообщения о прогрессе и завершении отображаются на выбранном языке.

Подтверждение удаления Bluetooth сохраняет исходный адрес устройства, даже когда список устройств обновляется. Проценты заряда батареи из bluetoothctl распознаются, а запросы деталей устройства выполняются с ограниченной конкуренцией и индивидуальными таймаутами.

Поля ввода пароля Wi-Fi, ручного DNS и поиска сети принимают вставку с использованием скобок. Вставляемые элементы управления и разрывы строк опускаются. Не поддерживаются сочетания клавиш только с Ctrl или только с Alt и не вставляют буквы. Редакторы принимают печатаемые события AltGr, закодированные как Ctrl+Alt; Ctrl+S сохраняет только без Alt. Общий текстовый редактор сохраняет вертикальную навигацию в визуальных колонках и выравнивает горизонтальную прокрутку для широких символов.
