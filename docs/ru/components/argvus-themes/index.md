Тема в ARGVUS задает цвета, поверхности, обои по умолчанию и геометрию расположения, используемые на рабочем столе: Hyprland, Waybar, Панель управления, панель задач, экран блокировки, уведомления и приложения ARGVUS. Этот гид охватывает все, что вам нужно для работы с темами как пользователю.

## Что включено в тему

Каждая официальная тема представляет собой полную визуальную идентичность с двумя режимами:

- **Sticky** — компактная раскладка с небольшими промежутками между окнами, без внешних отступов и панелью задач близко к краю экрана.
- **Spaced** — просторная раскладка с большими промежутками, закругленными углами и отступами вокруг панели задач и оболочки.

Выбор темы не изменяет её идентичность: палитра, цвет выделения по умолчанию и ассоциация с обоями остаются одинаковыми между режимами. Режим является отдельной настройкой, см. [Официальные темы](/docs/components/argvus-themes/official-themes/).

## Быстрая справка

| Задача | Где |
| --- | --- |
| Выбрать тему | **Центр управления → Внешний вид → Темы → Официальные темы** |
| Переключить Sticky и Spaced | **Центр управления → Внешний вид → Режим** |
| Изменить цвет выделения | **Центр управления → Внешний вид → Цвет выделения** |
| Экспортировать активную тему | **Центр управления → Внешний вид → Темы → Экспорт темы** |
| Импортировать тему | **Центр управления → Внешний вид → Темы → Импорт темы** |
| Открыть выбор темы с клавиатуры | `SUPER + SHIFT + T` |

## Откуда берутся темы

ARGVUS поставляется с двумя встроенными темами, **ARGVUS Dark** и **ARGVUS Light**, с пакетом `argvus-appearance`. Любая другая официальная тема является отдельным пакетом `argvus-theme-<name>`. Установка пакета темы добавляет его в выбор темы; перезапуск сеанса не требуется. Ваши собственные темы, экспортированные или импортированные, перечислены отдельно как **Пользовательские темы**.

## Подсказки для клавиатуры

Страницы темы Центра управления показывают их клавиши в нижнем колонтитуле:

- `↑` / `↓` — навигация.
- `Enter` — применить или открыть.
- `e` — экспортировать активную тему на странице Темы.
- `i` — импортировать тему на странице Темы.
- `d` — удалить пользовательскую тему.
- `Esc` — вернуться назад.

## Устранение неполадок

- **Установленная тема не отображается.** Подтвердите, что пакет установлен с помощью `pacman -Q argvus-theme-<name>`, затем снова откройте Центр управления. Пакет должен быть установлен с присутствием `argvus-appearance`.
- **Цвет выделения изменился после переключения темы.** Пользовательский цвет выделения сохраняется при смене темы. Используйте **Сбросить к цвету темы по умолчанию**, чтобы вернуть цвет темы.
- **Архив темы не отображается для импорта.** Он должен находиться непосредственно в вашей домашней директории и содержать `<id>/theme.toml`. См. [Импорт и экспорт тем](/docs/components/argvus-themes/import-and-export/).
