Цвет **выделения** — это акцент, используемый для рамок фокуса, выделения и активных состояний на рабочем столе. У каждой темы есть цвет выделения по умолчанию, но вы можете заменить его любым цветом, не меняя тему.

## Изменение цвета выделения

1. Откройте **Панель управления → Внешний вид → Цвет выделения**.
2. Выберите **Изменить цвет выделения**. Текущий цвет отображается рядом с этой опцией.
3. Введите шестизначный цвет в формате RGB, с ведущим `#` или без него. Например, `3590BD` и `#3590BD` принимаются.
4. Нажмите `Enter`, чтобы применить.

Вы также можете вставить цвет в поле. ARGVUS принимает вставленный текст только если это допустимое шестизначное значение RGB. Короткие формы, такие как `#123`, и значения с недопустимыми символами отклоняются с сообщением об ошибке, и цвет не изменяется.

Новый цвет применяется к рабочему столу сразу и сохраняется в вашей конфигурации ARGVUS.

## Вернуться к цвету по умолчанию темы

Чтобы вернуться к цвету, определённому выбранной темой, откройте **Панель управления → Внешний вид → Цвет подсветки** и выберите **Сбросить к настройкам по умолчанию темы**.

## Как цвет подсветки взаимодействует с темами

- Выбранный цвет подсветки является независимым переопределением. Он сохраняется при переключении на другую тему, поэтому выбранный цвет остаётся прежним.
- Тема, применённая после **Сбросить к настройкам по умолчанию темы**, снова задаёт цвет подсветки и использует свой собственный цвет по умолчанию.
- Экспорт активной темы сохраняет цвет подсветки, который активен при экспорте, как акцент палитры новой темы. См. [Импорт и экспорт тем](/docs/components/argvus-themes/import-and-export/).

## Где хранится значение

Цвет выделения является частью вашей конфигурации ARGVUS, в `$XDG_CONFIG_HOME/argvus/config.json` (обычно `~/.config/argvus/config.json`). Не редактируйте сгенерированные файлы в `$XDG_CONFIG_HOME/argvus/data/generated`: ARGVUS переписывает их из конфигурации.
