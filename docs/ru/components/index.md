---
title: Компоненты
description: Компоненты ARGVUS, которые задокументированы на этом сайте, и где находятся их заметки разработчиков.
---
Эти компоненты были объединены в рабочее пространство `argvus`. Их пользовательские страницы перечислены здесь; заметки разработчиков находятся в `docs/internal/`.

| Компонент | Команда | Страница |
| --- | --- | --- |
| Учетные записи | `argvus accounts` | [Учетные записи](/docs/components/argvus-accounts/) |
| Центр управления | `argvus control-center` | [Центр управления](/docs/components/argvus-control-center/) |
| Приветствие ARGVUS | `argvus welcome` | [Приветствие ARGVUS](/docs/components/argvus-control-center/#argvus-welcome) |
| Интернационализация | `argvus i18n` | [Интернационализация](/docs/components/argvus-i18n/) |
| Терминал | `argvus terminal` | [Терминал](/docs/components/argvus-terminal/) |
| Монитор системы | `argvus system-monitor` | [Монитор системы](/docs/components/argvus-system-monitor/) |
| Анализатор использования диска | `argvus du` | [ARGVUS Анализатор использования диска](/docs/components/argvus-du/) |
| Сеть и Bluetooth | `argvus network`, `argvus bluetooth` | [Сеть и Bluetooth](/docs/components/argvus-network/) |
| Вход (greetd) | `argvus greeter` | [Приветствие](/docs/components/argvus-greeter/) |
| Календарь | `argvus taskbar-calendar` | [Календарь](/docs/components/argvus-taskbar-calendar/) |
| Съемные устройства | `argvus removable-devices` | [Съемные устройства](/docs/components/argvus-removable-devices/) |
| Фокус (Помодоро) | `argvus focus` | [ARGVUS Фокус](/docs/components/argvus-focus/) |
| Часы, таймеры и будильники | `argvus clock` | [ARGVUS Часы](/docs/components/argvus-clock/) |
| Темы | `argvus theme-switch` | [Темы](/docs/components/argvus-themes/) |
| Клавиши | `argvus keys`, `argvus gpg` | [Клавиши](/docs/components/argvus-keys/) |
| Проекты | `argvus projects` | [Проекты](/docs/components/argvus-projects/) |
| Виджет телеметрии | `argvus widget-telemetry` | [Виджет телеметрии](/docs/components/argvus-widget-telemetry/) |
| Наложение загрузки | `argvus loading-theme` | [Наложение загрузки](/docs/components/argvus-loading-theme/) |
| Змейка | `argvus game-snake` | [Змейка](/docs/argvus-games/snake/) |
| AI Агенты | `argvus-ai menu` | [AI Агенты](/docs/argvus-ai/) |

Справочник команд находится в [Командной строке](/docs/reference/command-line/).

См. [Снимок](/docs/components/argvus-control-center/#snapshot) для корневых снимков Btrfs.
