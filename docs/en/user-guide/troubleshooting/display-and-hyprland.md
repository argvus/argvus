---
title: Display and Hyprland troubleshooting
description: Diagnose monitor layouts and compositor configuration.
---

Use `argvus-displayctl --status` and `argvus-displayctl --apply` to distinguish saved display state from the active Hyprland layout. Inspect the packaged Hyprland configuration under `/usr/share/argvus/hyprland/` and user overrides under the ARGVUS configuration directory.
