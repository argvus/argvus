Use this table when you know what you want to change but not which ARGVUS surface owns it.

| I want to… | Go to… |
| --- | --- |
| Choose a theme or mode | **Control Center → Appearance → Themes** |
| Change the accent color | **Control Center → Appearance → Accents** |
| Change the wallpaper | **Control Center → Appearance → Wallpapers** |
| Enable or disable visual effects | **Control Center → Appearance → Effects**, **Control Center → Appearance → Launchers**, **Control Center → Configuration**, **Taskbar**, **Widget Telemetry** or **Control Panel** |
| Change taskbar position or utility grouping | **Control Center → Appearance → Spaces, Borders & Position** |
| Customize taskbar JSONC or CSS | [Waybar and taskbar overrides](/docs/argvus-waybar/) |
| Change window gaps or borders | **Control Center → Appearance → Spaces, Borders & Position** |
| Choose visible Control Panel cards | **Control Center → Appearance → Control Panel** |
| Change keyboard shortcuts | **Control Center → Locale & Region → Keyboard shortcuts** |
| Add an advanced Hyprland rule, monitor setting or new keybinding | [Hyprland overrides](/docs/argvus-hyprland/hyprland-overrides/) |
| Change mouse or touchpad behavior | **Control Center → Locale & Region → Mouse & Touchpad** |
| Change fonts | **Control Center → Fonts** |
| Choose default applications | **Control Center → Default applications** |
| Change display settings | **Control Center → Displays** or the Control Panel display card |
| Check or change network connections | Control Panel network card; permanent network configuration is provided by the installed network tools |
| Change volume or mute quickly | Control Panel volume card or the media keys |
| Change brightness quickly | Control Panel brightness card or the brightness keys |
| Lock, log out, suspend or power off | Control Panel session/power cards |
| Configure language, time zone or regional settings | **Control Center → Locale & Region** |

## Configuration or quick action?

The Control Center is the place to look when you want a setting to remain part of your desktop configuration. The Control Panel is the place to look when you want to inspect status or perform a frequent action now. Some Control Panel cards open the same underlying providers used by Control Center, but the panel is not a second settings database.

If a setting is not listed, use the Control Center's home search. Its search registry includes user-facing appearance routes and the keyboard, input, display, network and session domains.
