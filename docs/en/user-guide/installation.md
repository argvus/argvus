---
title: Installation
description: Install the ARGVUS packages on Arch Linux.
---

ARGVUS is distributed as signed Arch Linux packages. The public installer configures the ARGVUS package repository; the package set then installs the desktop components.

See [requirements](./installation/requirements/), follow the [installation steps](./installation/install/), and finish with [first session](./installation/first-session/).

The package repository and the `argvus` metapackage are maintained separately from the desktop component packages. See the developer [package matrix](../reference/package-matrix/) for ownership.
