This section walks you through everything needed to go from a bare Arch Linux install to a running ARGVUS desktop.

If you just want the shortest path, see [Quick Start](/docs/quick-start/) instead.

## Steps

1. Check the [requirements](/docs/getting-started/installation/requirements/) for your hardware and graphics stack.
2. Follow [Install ARGVUS](/docs/getting-started/installation/install/) to add the package repository and install the packages.
3. Finish with [First session](/docs/getting-started/installation/first-session/) to start your graphical or TTY session for the first time.

Once ARGVUS is running, the [User Guide](/docs/user-guide/) covers day-to-day configuration: appearance, sessions, applications, hardware and more.
