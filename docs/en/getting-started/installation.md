---
title: Installation
description: Install the ARGVUS packages on Arch Linux.
---

ARGVUS is distributed as signed Arch Linux packages. The public installer configures the ARGVUS package repository; the package set then installs the desktop components.

See [requirements](/docs/getting-started/installation/requirements/), follow the [installation steps](/docs/getting-started/installation/install/), and finish with [first session](/docs/getting-started/installation/first-session/).

The package repository and the `argvus` metapackage are maintained separately from the desktop component packages. See the developer [package matrix](/docs/reference/package-matrix/) for ownership.
