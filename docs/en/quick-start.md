---
title: Quick Start
description: Get ARGVUS running in one command.
---

The fastest way to try ARGVUS on a fresh Arch Linux installation, straight from a TTY:

```sh
curl -fsSL https://argvus.github.io/install.sh | sh
```

This single command imports and signs the ARGVUS repository key, configures the package repository, updates the package database and installs the `argvus` package with its dependencies.

Log out, select **ARGVUS** from your display manager (or start a TTY session), and you are in.
