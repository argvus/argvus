UI packages include `argvus-control-center`, `argvus-control-panel`, `argvus-taskbar`, `argvus-taskbar-calendar`, `argvus-widget-telemetry`, `argvus-launcher`, `argvus-terminal`, `argvus-system-monitor` and `argvus-removable-devices`.

Their user-facing behavior is documented by feature; this page records package ownership.
