---
title: UI components
description: ARGVUS user-interface packages.
---

UI packages include `argvus-control-panel`, `argvus-taskbar` and `argvus-launcher`, and the `argvus` subcommands `argvus control-center` (helper in `argvus-gtk`), `argvus taskbar-calendar`, `argvus widget-telemetry`, `argvus terminal`, `argvus system-monitor` and `argvus removable-devices`.

Their user-facing behavior is documented by feature; this page records package ownership.
