---
title: Assets and packages
description: ARGVUS asset and packaging projects.
---

`argvus-appearance` owns theme and accent state, the theme orchestrators and the adapters for external consumers. Generated visual consumers are owned by `argvus-config`. `argvus-branding` provides the ARGVUS logo and wordmark. `argvus-wallpapers`, `argvus-fonts` and `argvus-icons` provide assets. `argvus-app-profiles` provides application profiles. `argvus-waybar` packages the patched Waybar binary.
