---
title: Development environment
description: Prepare a checkout for ARGVUS development.
---

The workspace contains independent repositories under `de/`. Inspect the target repository's `Cargo.toml`, `PKGBUILD`, Makefile and packaging helpers before building. Keep source configuration, package payload and active installed configuration distinct.

The documentation site is under `web/site-src` and uses Astro, Starlight and `starlight-versions`.
