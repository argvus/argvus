---
title: Traductions
description: Maintenir les catalogues de localisation ARGVUS partagés.
---
`argvus-i18n` possède les catalogues partagés et le module QML. Mettez à jour les catalogues anglais et portugais ensemble lors de la modification du texte visible par l'utilisateur, puis exécutez :

```sh
argvus i18n validate
```
Les consommateurs incluent des applications Rust natives, des composants de shell et des assistants de session.
