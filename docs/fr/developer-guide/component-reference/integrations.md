---
title: Intégrations
description: Compositor, connexion, verrouillage et intégrations de portail.
---
`argvus-hyprland` empaquette la configuration du compositeur ; `argvus-portal` empaquette l'intégration du portail XDG ; `argvus-greeter` intègre greetd ; `argvus-lock` intègre Hyprlock ; la superposition de chargement fournie dans `argvus` intègre les visuels de chargement de session ; et `argvus-boot-splash` intègre les visuels de démarrage.
