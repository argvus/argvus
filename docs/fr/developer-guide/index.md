ARGVUS est une collection de projets empaquetés de manière indépendante, reliés par une configuration partagée, des services utilisateurs systemd, des contrats Wayland/Hyprland et une i18n commune.

- [Architecture](/docs/developer-guide/architecture/overview/)
- [Sous-systèmes](/docs/developer-guide/subsystems/session-and-systemd/)
- [Développement](/docs/developer-guide/development/environment/)
- [Référence](/docs/reference/)

Les dépôts sources sous `de/` sont autoritaires. Les manifestes des paquets et les unités installées définissent la limite d'exécution ; les fichiers README sont complémentaires.
