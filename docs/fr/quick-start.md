---
title: Démarrage rapide
description: Faire fonctionner ARGVUS en une seule commande.
---
La façon la plus rapide d'essayer ARGVUS sur une nouvelle installation d'Arch Linux, directement depuis un TTY :

```sh
curl -fsSL https://argvus.github.io/install.sh | sh
```
Cette seule commande importe et signe la clé du dépôt ARGVUS, configure le dépôt de paquets, met à jour la base de données des paquets et installe le paquet `argvus` avec ses dépendances.

Déconnectez-vous, sélectionnez **ARGVUS** depuis votre gestionnaire d'affichage (ou démarrez une session TTY), et vous êtes connecté.
