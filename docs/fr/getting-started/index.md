Cette section vous guide à travers tout ce qui est nécessaire pour passer d'une installation minimale d'Arch Linux à un bureau ARGVUS fonctionnel.

Si vous voulez juste le chemin le plus court, voyez [Quick Start](/docs/quick-start/) à la place.

## Étapes

1. Vérifiez les [requirements](/docs/getting-started/installation/requirements/) pour votre matériel et votre pile graphique.
2. Suivez [Install ARGVUS](/docs/getting-started/installation/install/) pour ajouter le dépôt de paquets et installer les paquets.
3. Terminez avec [First session](/docs/getting-started/installation/first-session/) pour démarrer votre session graphique ou TTY pour la première fois.

Une fois ARGVUS en fonctionnement, le [User Guide](/docs/user-guide/) couvre la configuration quotidienne : apparence, sessions, applications, matériel et plus.
