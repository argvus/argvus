title: Applications
description: Utilisez les applications intégrées dans ARGVUS.
---
ARGVUS expose des applications courantes via le répartiteur `argvus` et des paquets ciblés.

- [Launcher](/docs/argvus-launcher/)
- [Terminal](/docs/components/argvus-terminal/)
- [Calendar](/docs/components/argvus-taskbar-calendar/)
- [ARGVUS Focus](/docs/components/argvus-focus/) (sessions Pomodoro et de concentration)
- [ARGVUS Clock](/docs/components/argvus-clock/) (horloge, horloges mondiales, chronomètre, minuterie et alarmes)
- [Games](/docs/argvus-games/) (y compris [Snake](/docs/argvus-games/snake/))
- [System monitor](/docs/components/argvus-system-monitor/)
- [Default applications](/docs/components/argvus-control-center/)
- [Removable devices](/docs/components/argvus-removable-devices/)

Le Centre de Contrôle s'ouvre avec `argvus --control-center` ; sa page Applications gère les applications par défaut.
