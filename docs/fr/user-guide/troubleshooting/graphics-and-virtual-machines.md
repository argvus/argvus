---
title: Graphiques et machines virtuelles
description: Diagnostiquer les échecs de rendu dans les sessions Hyprland.
---
Inspectez l'environnement de session et les journaux du compositeur. Dans les machines virtuelles, vérifiez les variables de compatibilité exportées par `argvus start`. Ne forcez pas le rendu logiciel sur le matériel physique sans confirmer que la pile graphique l'exige.
