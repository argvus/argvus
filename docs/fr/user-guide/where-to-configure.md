## Configuration ou action rapide ?

Le Centre de contrôle est l'endroit à consulter lorsque vous voulez qu'un réglage fasse partie intégrante de la configuration de votre bureau. Le Panneau de configuration est l'endroit à consulter lorsque vous voulez inspecter l'état ou effectuer une action fréquente immédiatement. Certaines cartes du Panneau de configuration ouvrent les mêmes fournisseurs sous-jacents utilisés par le Centre de contrôle, mais le panneau n'est pas une deuxième base de données de paramètres.

Si un paramètre n'est pas répertorié, utilisez la recherche du centre de contrôle. Son registre de recherche inclut les chemins d'apparence destinés aux utilisateurs ainsi que les domaines clavier, saisie, affichage, réseau et session.
