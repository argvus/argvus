description: सामान्य ARGVUS सेटिंग्स खोजने के लिए एक त्वरित सूचकांक।

इस तालिका का उपयोग तब करें जब आप जानते हों कि आप क्या बदलना चाहते हैं लेकिन यह नहीं कि यह किस ARGVUS सतह का स्वामी है।

मुख्य डेस्कटॉप क्षेत्रों की निर्देशित समीक्षा के लिए, `argvus welcome` के साथ या **कंट्रोल सेंटर → टूल्स और डायग्नोस्टिक्स** से **ARGVUS वेलकम** खोलें।

| मैं चाहता हूँ... | पर जाएँ… |
| --- | --- |
| कोई थीम या मोड चुनें | **नियंत्रण केंद्र → प्रकटन → थीम** |
| उच्चारण का रंग बदलें | **नियंत्रण केंद्र → दिखावट → उच्चारण** |
| वॉलपेपर बदलें | **नियंत्रण केंद्र → दिखावट → वॉलपेपर** |
| दृश्य प्रभावों को सक्षम या अक्षम करें | **नियंत्रण केंद्र → प्रकटन → प्रभाव**, **नियंत्रण केंद्र → प्रकटन → लॉन्चर**, **नियंत्रण केंद्र → कॉन्फ़िगरेशन**, **टास्कबार**, **विजेट टेलीमेट्री** या **नियंत्रण कक्ष** |
| टास्कबार की स्थिति, ऊंचाई, बॉर्डर या उपयोगिता समूह बदलें | **नियंत्रण केंद्र → उपस्थिति → टास्कबार → स्थिति**, **ऊंचाई**, **सीमा** और **प्रतीक** |
| टास्कबार JSONC या CSS को अनुकूलित करें | [वेबार और टास्कबार ओवरराइड](/docs/argvus-waybar/) |
| विंडो गैप या बॉर्डर बदलें | **नियंत्रण केंद्र → डेस्कटॉप और इनपुट → हाइप्रलैंड → विंडोज → स्पेस** और **बॉर्डर** |
| विंडो छाया बदलें | **नियंत्रण केंद्र → डेस्कटॉप और इनपुट → हाइप्रलैंड → बॉर्डर → छाया** |
| दृश्यमान नियंत्रण कक्ष कार्ड चुनें | **नियंत्रण केंद्र → उपस्थिति → नियंत्रण कक्ष** |
| कीबोर्ड शॉर्टकट बदलें | **नियंत्रण केंद्र → स्थान और क्षेत्र → कीबोर्ड शॉर्टकट** |
| एक उन्नत हाइप्रलैंड नियम, मॉनिटर सेटिंग या नई कीबाइंडिंग जोड़ें | [हाइपरलैंड ओवरराइड्स](/docs/argvus-hyprland/hyprland-overrides/) |
| माउस या टचपैड व्यवहार बदलें | **नियंत्रण केंद्र → स्थान और क्षेत्र → माउस और टचपैड** |
| फ़ॉन्ट बदलें | **नियंत्रण केंद्र →फ़ॉन्ट** |
| डिफ़ॉल्ट एप्लिकेशन चुनें | **नियंत्रण केंद्र → डिफ़ॉल्ट एप्लिकेशन** |
| प्रदर्शन सेटिंग बदलें | **कंट्रोल सेंटर → डिस्प्ले** या कंट्रोल पैनल डिस्प्ले कार्ड |
| नेटवर्क कनेक्शन जांचें या बदलें | नियंत्रण कक्ष नेटवर्क कार्ड; स्थायी नेटवर्क कॉन्फ़िगरेशन स्थापित नेटवर्क टूल द्वारा प्रदान किया जाता है |
| वॉल्यूम बदलें या तुरंत म्यूट करें | नियंत्रण कक्ष वॉल्यूम कार्ड या मीडिया कुंजियाँ |
| चमक जल्दी से बदलें | नियंत्रण कक्ष चमक कार्ड या चमक कुंजियाँ |
| लॉक करें, लॉग आउट करें, निलंबित करें या बिजली बंद करें | नियंत्रण कक्ष सत्र/पावर कार्ड |
| भाषा, समय क्षेत्र या क्षेत्रीय सेटिंग्स कॉन्फ़िगर करें | **नियंत्रण केंद्र → स्थान और क्षेत्र** |

## कॉन्फ़िगरेशन या त्वरित कार्रवाई?

जब आप चाहते हैं कि कोई सेटिंग आपके डेस्कटॉप कॉन्फ़िगरेशन का हिस्सा बनी रहे तो नियंत्रण केंद्र देखने का स्थान है। जब आप स्थिति का निरीक्षण करना चाहते हैं या अब लगातार कार्रवाई करना चाहते हैं तो नियंत्रण कक्ष देखने का स्थान है। कुछ नियंत्रण कक्ष कार्ड नियंत्रण केंद्र द्वारा उपयोग किए गए समान अंतर्निहित प्रदाताओं को खोलते हैं, लेकिन पैनल दूसरा सेटिंग डेटाबेस नहीं है।

यदि कोई सेटिंग सूचीबद्ध नहीं है, तो नियंत्रण केंद्र की होम खोज का उपयोग करें। इसकी खोज रजिस्ट्री में उपयोगकर्ता-सामना वाले उपस्थिति मार्ग और कीबोर्ड, इनपुट, डिस्प्ले, नेटवर्क और सत्र डोमेन शामिल हैं।
