description: ARGVUS को इंस्टॉल करें, अपडेट करें, हटाएं और कॉन्फ़िगर करें।
---

ARGVUS को आधिकारिक ARGVUS पैकेज रिपॉजिटरी के माध्यम से आर्क लिनक्स पैकेज के रूप में वितरित किया जाता है।

## स्थापित करने से पहले

ARGVUS स्थापित करने से पहले आधिकारिक आर्क लिनक्स `multilib` रिपॉजिटरी को सक्षम करें। `/etc/pacman.conf` संपादित करें और `[multilib]` अनुभाग और इसकी `Include` लाइन दोनों को अनटिप्पणी करें:

```ini
[multilib]
Include = /etc/pacman.d/mirrorlist
```

फिर पैकेज डेटाबेस को सिंक्रनाइज़ करें और पूर्ण सिस्टम अपग्रेड करें:

```sh
sudo pacman -Syu
```

त्वरित इंस्टॉलर ARGVUS रिपॉजिटरी को कॉन्फ़िगर करता है, लेकिन आपके लिए `multilib` को सक्षम नहीं करता है।

## त्वरित स्थापना

एक ताज़ा आर्क लिनक्स इंस्टॉलेशन पर, आप पहले किसी अन्य डेस्कटॉप वातावरण को इंस्टॉल किए बिना सीधे TTY से ARGVUS इंस्टॉल कर सकते हैं।

चलाएँ:

```sh
curl -fsSL https://argvus.github.io/install.sh | sh
```

इंस्टॉलर:

1. आयात और स्थानीय रूप से ARGVUS रिपॉजिटरी हस्ताक्षर कुंजी पर हस्ताक्षर करता है।
2. ARGVUS पैकेज रिपॉजिटरी को कॉन्फ़िगर करता है।
3. पैकेज डेटाबेस को अद्यतन करता है।
4. `argvus` पैकेज और उसकी निर्भरताएँ स्थापित करता है।

इंस्टालेशन के बाद, लॉग आउट करें और अपने डिस्प्ले मैनेजर से **ARGVUS** चुनें।

> **ध्यान दें:** त्वरित इंस्टॉलर को `curl`, `sudo` और मानक आर्क लिनक्स पैकेज-प्रबंधन टूल की आवश्यकता होती है।

## केवल रिपॉजिटरी को कॉन्फ़िगर करें

डेस्कटॉप स्थापित किए बिना ARGVUS पैकेज रिपॉजिटरी को कॉन्फ़िगर करने के लिए, चलाएँ:

```sh
curl -fsSL https://argvus.github.io/repo-install.sh | sh
```

बाद में मैन्युअल रूप से ARGVUS स्थापित करें:

```sh
sudo pacman -Syu argvus
```

## मैन्युअल स्थापना

यदि आप रिपॉजिटरी को चरण दर चरण कॉन्फ़िगर करना पसंद करते हैं, तो निम्न कमांड का उपयोग करें।

### 1. रिपॉजिटरी साइनिंग कुंजी डाउनलोड करें

```sh
curl -fsSLo /tmp/argvus.gpg https://argvus.github.io/packages/arch/argvus.gpg
```

### 2. हस्ताक्षर कुंजी आयात करें

```sh
sudo pacman-key --add /tmp/argvus.gpg
```

### 3. कुंजी पर स्थानीय रूप से हस्ताक्षर करें

```sh
ARGVUS_KEY="$(gpg --show-keys --with-colons /tmp/argvus.gpg | grep '^pub:' | head -n1 | cut -d: -f5)"
sudo pacman-key --lsign-key "$ARGVUS_KEY"
```

### 4. ARGVUS रिपॉजिटरी को कॉन्फ़िगर करें

```sh
curl -fsSL https://argvus.github.io/packages/arch/argvus.conf \
  | sudo tee /etc/pacman.d/argvus.conf
```

रिपॉजिटरी कॉन्फ़िगरेशन को `/etc/pacman.conf` में जोड़ें:

```sh
echo "Include = /etc/pacman.d/argvus.conf" \
  | sudo tee -a /etc/pacman.conf
```

रिपॉजिटरी कॉन्फ़िगरेशन SigLevel = Required TrustedOnly के साथ `argvus` और `argvus-extras` सहित ARGVUS रिपॉजिटरी को सक्षम बनाता है। पैकमैन केवल तभी पैकेज स्वीकार करता है जब उनके हस्ताक्षर वैध हों और स्थानीय कीरिंग द्वारा विश्वसनीय हों।

### 5. ARGVUS स्थापित करें

```sh
sudo pacman -Syu argvus
```

इंस्टालेशन के बाद, लॉग आउट करें और अपने डिस्प्ले मैनेजर से **ARGVUS** चुनें।

## अद्यतन

बाकी आर्क लिनक्स के साथ ARGVUS को अपडेट करें:

```sh
sudo pacman -Syu
```

केवल ARGVUS पैकेज को अद्यतन करने के लिए:

```sh
sudo pacman -S argvus
```

> **सिफारिश:** आर्क लिनक्स आम तौर पर अलग-अलग पैकेजों को अपडेट करने के बजाय  `SigLevel = Required TrustedOnly` `sudo pacman -Syu` के साथ पूर्ण सिस्टम अपग्रेड की सिफारिश करता है।

## ARGVUS को हटाएँ

अन्य स्थापित पैकेजों के लिए अभी भी आवश्यक निर्भरताएँ बनाए रखते हुए ARGVUS को हटाएँ:

```sh
sudo pacman -R argvus
```

ARGVUS और निर्भरताएँ हटाएँ जिनकी अब किसी भी स्थापित पैकेज को आवश्यकता नहीं है:

```sh
sudo pacman -Rns argvus
```

### ARGVUS रिपोजिटरी हटाएँ

यदि आप भी पैकेज रिपॉजिटरी को हटाना चाहते हैं, तो इसका कॉन्फ़िगरेशन हटा दें:

```sh
sudo rm /etc/pacman.d/argvus.conf
```

फिर `/etc/pacman.conf` से संबंधित पंक्ति को हटा दें:

```text
Include = /etc/pacman.d/argvus.conf
```

आप फ़ाइल को इसके साथ संपादित कर सकते हैं:

```sh
sudo nano /etc/pacman.conf
```

### हस्ताक्षर कुंजी हटाएँ

पैक्मैन कीरिंग से ARGVUS रिपॉजिटरी साइनिंग कुंजी को हटाने के लिए, पहले कुंजियों को सूचीबद्ध करें:

```sh
sudo pacman-key --list
```

फिर ARGVUS कुंजी को उसकी कुंजी आईडी से हटा दें:

```sh
sudo pacman-key --delete KEY_ID
```

`KEY_ID` को ARGVUS साइनिंग-कुंजी आईडी से बदलें।

> **चेतावनी:** इस कुंजी को तभी हटाएं जब आप ARGVUS रिपॉजिटरी को भी हटा रहे हों। अन्य रिपॉजिटरी के लिए अभी भी आवश्यक कुंजियाँ न हटाएँ।

## उपयोगकर्ता कॉन्फ़िगरेशन

पैकेज इंस्टॉलेशन `$HOME` में कॉन्फ़िगरेशन नहीं लिखता है। ARGVUS `/usr/share/argvus` से पैकेज्ड डिफॉल्ट्स को पढ़ता है और उन्हें आपके होम डायरेक्टरी में कॉपी किए बिना काम करता है।

रनटाइम कॉन्फ़िगरेशन इस सामान्य प्राथमिकता का अनुसरण करता है:

```text
~/.config/argvus/data/generated/<app>  ->  ~/.config/argvus/data/<component>/<app>  ->  $XDG_CONFIG_HOME/<app>  ->  /usr/share/argvus/<app>  ->  upstream defaults
```

`argvus-config` एकमात्र घटक है जो `~/.config/argvus/data/generated/` लिखता है, और वह प्रक्षेपण सक्रिय परत है: एक प्रबंधित या मूल प्रतिलिपि केवल तभी प्रभावी होती है जब संबंधित उत्पन्न फ़ाइल अनुपस्थित होती है।ARGVUS-प्रबंधित कॉन्फ़िगरेशन `~/.config/argvus/` के अंतर्गत रहता है। एक वैकल्पिक `$XDG_CONFIG_HOME/<app>` ओवरराइड उन अनुप्रयोगों के लिए उपलब्ध रहता है जो मूल उपयोगकर्ता कॉन्फ़िगरेशन का समर्थन करते हैं।

`argvus --setup` डिस्पैचर वैकल्पिक है और स्पष्ट मैनुअल के लिए है
ओवरराइड करता है, पुनर्प्राप्ति नहीं. यदि `~/.config/argvus` हटा दिया गया है, तो `SUPER + SHIFT + R`
सामान्य के माध्यम से विहित प्रोफ़ाइल और उत्पन्न रनटाइम स्थिति को फिर से बनाता है
पाइपलाइन पुनः लोड करें.

```sh
argvus --setup --copy foot-tui
argvus --setup --copy kitty-tui
argvus --setup --copy-all
```

`--copy-all` समर्थित TUI प्रोफ़ाइल फ़ाइलों की एक स्पष्ट अनुमति सूची है; यह
`/usr/share/argvus` को क्लोन नहीं करता है और स्क्रिप्ट, सेवाओं, संपत्तियों की प्रतिलिपि नहीं बनाता है।
जेनरेट की गई फ़ाइलें या `config.json`। करंट देखने के लिए `argvus --setup --help` चलाएँ
विकल्प. एक बार कॉपी हो जाने पर, फ़ाइलें उपयोगकर्ता के स्वामित्व वाली ओवरराइड और पैकेज बन जाती हैं
उन्नयन उन्हें प्रतिस्थापित नहीं करता.

मौजूदा कॉपी किए गए कॉन्फ़िगरेशन को बदलने के लिए, `--force` का उपयोग करें। ARGVUS इसे बदलने से पहले एक टाइमस्टैम्प्ड बैकअप बनाता है:

```sh
argvus --setup --copy <app> --force
```

## हाइप्रलैंड उपयोगकर्ता ओवरराइड करता है

पूर्ण Hyprland ओवरराइड गाइड के लिए, जिसमें पूर्ण मूल कॉन्फ़िगरेशन और इनक्रिमेंटल ARGVUS फ्रैगमेंट के बीच का अंतर शामिल है, देखें [हाइपरलैंड ओवरराइड्स](/docs/argvus-hyprland/hyprland-overrides/).

```sh
mkdir -p ~/.config/argvus/data/hypr
nano ~/.config/argvus/data/hypr/user.lua
```

### वर्चुअल-मशीन फ़ॉलबैक

कुछ वर्चुअल मशीनें हाइप्रलैंड, किटी, या क्विकशेल के साथ रेंडरिंग समस्याओं का अनुभव कर सकती हैं। ARGVUS `vmwgfx` ग्राफ़िक्स ड्राइवर का उपयोग करके वर्चुअल मशीनों का पता लगाता है और आवश्यकता पड़ने पर सॉफ़्टवेयर रेंडरिंग सक्षम करता है।

यदि आपके वर्चुअल मशीन पर डिटेक्शन काम नहीं करता है, तो `user.lua` में मैन्युअल रूप से फ़ॉलबैक सक्षम करें:

```lua
-- Virtual machine compatibility
hl.env("LIBGL_ALWAYS_SOFTWARE", "1")
```

`user.lua` बनाने या संशोधित करने के बाद, हाइप्रलैंड से लॉग आउट करें और फिर से लॉग इन करें ताकि वेरिएबल सत्र द्वारा लॉन्च किए गए एप्लिकेशन पर लागू हो।

इसे इसके साथ सत्यापित करें:

```sh
echo $LIBGL_ALWAYS_SOFTWARE
```

अपेक्षित आउटपुट है:

```text
1
```

> **ध्यान दें:** `LIBGL_ALWAYS_SOFTWARE=1` मेसा/ओपनजीएल अनुप्रयोगों को आमतौर पर `llvmpipe` के माध्यम से सॉफ़्टवेयर रेंडरिंग का उपयोग करने के लिए बाध्य करता है। यह ग्राफिकल प्रदर्शन को कम कर सकता है और इसे प्रभावित वर्चुअल मशीनों के लिए फ़ॉलबैक के रूप में उपयोग किया जाना चाहिए।
