---
title: Schnellstart
description: Führen Sie ARGVUS mit einem Befehl aus.
---
Der schnellste Weg, ARGVUS auf einer frischen Arch-Linux-Installation direkt von einem TTY aus auszuprobieren:

```sh
curl -fsSL https://argvus.github.io/install.sh | sh
```
Dieser einzelne Befehl importiert und signiert den ARGVUS-Repository-Schlüssel, konfiguriert das Paket-Repository, aktualisiert die Paketdatenbank und installiert das Paket `argvus` mit seinen Abhängigkeiten.

Melden Sie sich ab, wählen Sie **ARGVUS** aus Ihrem Display-Manager (oder starten Sie eine TTY-Sitzung), und Sie sind drin.

- Etwas funktioniert nicht? Überprüfen Sie [Fehlerbehebung](/docs/user-guide/troubleshooting/).
