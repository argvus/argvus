`argvus-hyprland` paketiert Compositor-Konfiguration; `argvus-portal` paketiert XDG-Portal-Integration; `argvus-greeter` integriert greetd; `argvus-lock` integriert Hyprlock; das in `argvus` gelieferte Lade-Overlay integriert Sitzungs-Lade-Visuals; und `argvus-boot-splash` integriert Boot-Visuals.
