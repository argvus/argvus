---
title: Installation
description: Installieren Sie die ARGVUS-Pakete auf Arch Linux.
---
ARGVUS wird als signierte Arch-Linux-Pakete verteilt. Der öffentliche Installer konfiguriert das ARGVUS-Paket-Repository; das Paket-Set installiert dann die Desktop-Komponenten.

Siehe [requirements](/docs/getting-started/installation/requirements/)], folgen Sie den [Installationsschritten](/docs/getting-started/installation/install/)] und beenden Sie mit [erste Sitzung](/docs/getting-started/installation/first-session/)].

Das Paket-Repository und das `argvus`-Metapaket werden getrennt von den Desktop-Komponenten-Paketen gepflegt. Siehe die Entwickler-[Paketmatrix](/docs/reference/package-matrix/)] für die Zuständigkeit.
