---
title: ARGVUS ディスク使用量解析ツール
description: テーマ付きの Kitty ウィンドウで ncdu を使ってディスク使用量を対話形式で確認します。
---
アプリケーションランチャーから **ARGVUS Disk Usage Analyzer** を開くか、次を実行してください:

```sh
argvus du
```
アナライザーは専用の中央配置されたKittyウィンドウを開き、そのARGVUSフレーム内に実際のncduインターフェースを埋め込みます。`$HOME`で開始します。ディレクトリパスを編集するか、**ブラウズ**を選択して設定されたファイルマネージャを開きます。Superfileでは、ディレクトリに移動して**スペース**を押して選択します；`q`または`Esc`でキャンセルします。他の設定されたファイルマネージャは通常通り開きますが、選択したディレクトリを返さない場合があるため、アナライザーにパスを入力または貼り付けてください。

ディレクトリ、オプション、アクション間の移動にはTabキーまたは方向キーを使用します。グラフ、パーセンテージ、ダークカラースキーム、ディレクトリ優先の並び順はデフォルトで有効になっています。残りのスキャンおよび表示オプションは、**分析**を選択する前に切り替えることができます。結果では、ncduのキーボード操作を使用します；`q`はフォームに戻り、`Esc`はスキャンを停止します。`d`を押すと、選択したファイルまたはディレクトリを削除します。ncduは確認を求めます；削除は永久で、現在のユーザーの権限を使用します。昇格した権限は要求されません。

外部インターフェースはアクティブなARGVUSテーマおよびロケールに従います。Kittyおよびncduが必要です；`argvus-devtools`パッケージはncduを提供します。Kittyまたはncduがない場合、アプリケーションは不足している依存関係を報告します。
