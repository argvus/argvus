---
title: 温度センサー
description: lm_sensors JSON によってサポートされるライブ温度の概要。
---
`argvus sensors` は、タスクバーの CPU 温度ポップアップで使用される進行中の Ratatui パネルを開きます。これは `sensors -j` を実行し、チップ名とハードウェアによって報告されたラベルで測定値をグループ化し、2 秒ごとに更新します。GPU の監視は `argvus system-monitor --gpu` によって処理されます。

測定値は摂氏で表示されます。パネルには、lm_sensors が提供する場合、`max`、`crit`、およびアラーム状態が表示されます。正の制限が利用可能な場合のみゲージが表示されます。`lm_sensors` の欠落、コマンドの失敗、無効な JSON、空の測定値は回復可能な状態として引き続き表示され、次のサイクルでポーリングが再試行されます。

`q` または `Esc` を押して閉じます。タスクバーは `argvus tui-terminal` を通じて Kitty でパネルを開き、ローカライズされた下部タブのタイトルに閉じるヒントを表示します。このコマンドは CPU 温度の詳細を管理し、GPU 温度のアイコンは GPU 専用の btop モニターを開きます。タスクバー パッケージはすでに `lm_sensors` に依存しているため、別途パッケージや依存関係は必要ありません。
