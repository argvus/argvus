title: ARGVUSフォーカス

---
ARGVUS Focusは、休憩ごとに分けられたフォーカスセッションで作業するためのGTK 4アプリケーションです。タスクバーの横にポップアップとして開きます。起動方法は、ランチャーから、タスクバーのインジケーターをクリックする、**SUPER + Shift + F**キーを使う、または以下の方法です：

```sh
argvus focus              # open the popup near the pointer
argvus focus --toggle     # hide the popup if it is visible, show it otherwise
argvus focus --toggle --x 1600 --y 30  # open next to a taskbar click position
argvus focus --start      # start or resume the current phase without opening the window
argvus focus --pause      # pause the running phase
argvus focus status --waybar         # print one Waybar JSON status and exit
argvus focus status --waybar --follow  # stream status changes for Waybar
```
タスクバーはルートクリックの座標を渡すため、ポップアップはクリックされたモニターを使用し、バーに合わせて配置されます。座標なしで起動した場合は、ポインタ位置が使用されます。ポインタが5秒間ポップアップ外にあると、自動的に閉じます。ポインタをポップアップ内に移動すると、そのカウントダウンはキャンセルされます。メインページでの **Esc** は依然として即座に非表示にし、サブページでの **Esc** は前のページに戻ります。タスクバーのインジケーターは、アイドル中はアイコンのみを表示し、フェーズ中は残り時間 `MM:SS` とフェーズカラーを表示します。フェーズが一時停止している場合、残り時間を保持し、一時停止状態を追加します。`status` コマンドは GTK を起動せずに `argvus` 内で実行されます。`argvus --focus` はエイリアスです。セッションごとに Focus のインスタンスは1つだけ実行されます。2回目の起動は、そのオプションを既に動作中のインスタンスに渡します。

ARGVUS Focus、ARGVUS Clock、およびコントロールパネルは同じ画面端を共有します。Focusを開くと、まずClockとコントロールパネルが閉じます；それらのいずれかのサーフェスを開くと、Focusが閉じます。

## セッション

- **ポモドーロ** モードは集中時間と短い休憩を交互に行い、各サイクルの最後に長い休憩を取ります。デフォルトの時間は、それぞれ25分、5分、15分で、集中セッションを4回行った後に長い休憩があります。
- **単一セッション** モードは、休憩なしで独自の長さ（デフォルトは45分）の集中セッションを1回行います。
- ウィンドウにはフェーズ（集中、短い休憩、長い休憩、それぞれ異なる色で表示）、進行リング内の残り時間、サイクル内の位置、今日の合計が表示されます。
- **集中開始 / 休憩開始**、**一時停止**、**再開**、**セッションキャンセル**（フェーズを中止し、何も記録しません）、**今すぐ完了**（集中セッションを早めに終了し、実際に費やした時間を記録します）。休憩中は**休憩をスキップ**で集中に戻ります。
- フェーズが終了すると、次のフェーズはあなたを待ちます。ただし、**休憩を自動で開始**または**休憩後に自動で集中開始**がオンの場合を除きます。

キーボード: **Space** で開始または一時停止、**Ctrl+,** で設定を開く、**Ctrl+H** で履歴、**Esc** で戻る、**Ctrl+W** でウィンドウを非表示、**Ctrl+Q** で終了します。

## 設定

プリセット（クラシック 25/5/15、拡張 50/10/30、ディープワーク 90/20/30）は時間を設定し、編集可能です。設定には長い休憩前のセッション数、自動開始、フェーズ終了時の通知、そして**セッション音**が含まれます：独自の音量で鳴る短いベルと**テスト音**ボタン。これらの音は [ARGVUS Clock](/docs/components/argvus-clock/)] のアラーム音とは別です。

## 履歴

完了した集中セッションは開始、終了、経過時間とともに記録され、休憩やキャンセルされたセッションは記録されません。履歴ページには今日のセッションと分数、合計および最近のセッションが表示されます。365日より古い記録は削除されます。**履歴を消去** は確認を求めます。

## ウィンドウ、背景および一時停止

- サイクル中にウィンドウを閉じても、単に非表示になるだけで、セッションは続行され、フェーズが終了すると通知されます。進行中の項目がない場合は、閉じると終了します。
- フェーズ実行中にシステムがサスペンドされた場合、サスペンドされた瞬間にフェーズは一時停止され、システムがどれくらいスリープしていたかのメッセージが表示されます。スリープ時間はフォーカスタイムにカウントされません。
- セッションは、変更があるたびおよび30秒ごとに保存されます。フェーズ中にARGVUS Focusが閉じられた場合（ログアウト、クラッシュ、**Ctrl+Q**）、次回起動時にはその時点で一時停止した状態で復帰します。通知できない間にタイマーが動き続けたふりはしません。
- 時間はシステムの起動時間クロックで計測されるため、壁時計やタイムゾーンを変更してもフェーズの長さは変わりません。

## パス

| パス | 内容 |
| --- | --- |
| `$XDG_CONFIG_HOME/argvus/data/focus/settings.json` | 設定 |
| `$XDG_DATA_HOME/argvus/focus/history.json` | 完了したセッション |
| `$XDG_STATE_HOME/argvus/focus/session.json` | 現在のセッションのチェックポイント |
| `/usr/share/argvus/sounds/argvus-bell.oga` | セッションベル |

ファイルは原子単位で書き込まれます。読み取れないファイルは `<name>.corrupt-<time>` に名前が変更され、デフォルトが使用されます。どこに移動したかを知らせるメッセージが表示されます。

色はアクティブな ARGVUS テーマおよびハイライト色（テーマ消費者 `time`）に従います。文字列は `focus` および `time` の翻訳ドメインから取得されます。

タスクバーのカレンダー、ARGVUS フォーカス、ARGVUS クロック、およびコントロールパネルは相互に排他的です：1つを開くと他は閉じます。
