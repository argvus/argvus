## カタログおよび寄稿内容

ソースは`resources/locales/<locale>/<domain>.json`で、`argvus`リポジトリにあります。インストールされたカタログは`/usr/share/argvus/i18n/`に存在します。それらはマスター`argvus`パッケージに同梱されています。`locale.json`は識別子とネイティブ/表示名を提供します。POカタログやオンライン翻訳プラットフォームは必要ありません。

セマンティックキーを使用し、プレースホルダー名、コマンド、オプション、パス、キーボードショートカットを保持してください。文を断片を組み合わせて翻訳するのではなく、メッセージ全体を翻訳してください。新しい標準キーは10言語すべてに翻訳が必要です。各ドメイン内で用語を一貫して使用し、特に認証、権限、破壊的操作に関して、文脈内で翻訳を確認してください。

```sh
argvus i18n list
argvus i18n locale
argvus i18n get common welcome name=Alice
argvus i18n validate
```
`ARGVUS_I18N_DIR` は、開発およびステージングパッケージチェックのために代替のカタログルートを選択します。検証はドメイン、キー、文字列値、プレースホルダー、空の翻訳、およびロケール固有の整数複数形をチェックします。検証は言語的正確性ではなく構造的整合性を証明します。

## Unicode とフォント

`argvus-fonts` は、ラテン文字、記号、および絵文字ファミリーに加えて Noto CJK フォントを必要とします。Fontconfig は、ユーザーの選択した主要なフォントファミリーを置き換えることなく、中国語、日本語、ハングルのフォールバックを提供します。アプリケーションとターミナルは、それでもフォントのフォールバックを有効にする必要があります。

共有 Ratatui テキストヘルパーは、端末のセルを測定し、切り捨て時に拡張グラフェムクラスターを保持し、幅の広いテキストを折り返します。テキストエディタは、グラフェム全体を移動および削除します。極端に狭い領域では、1つのセルに2セル分のグリフを表示できません。この場合、ハードラップヘルパーは代替文字を使用します。絵文字や曖昧な幅の文字は、端末やフォントの実装により依然として異なる場合があります。端末の幅のポリシーは、Ratatui の通常の Unicode 幅と一致するべきです。

言語の選択は、入力方式のインストールやキーボードのレイアウト変更を行いません。中国語、日本語、韓国語を入力する場合は、Wayland 互換の入力方式を使用してください。
