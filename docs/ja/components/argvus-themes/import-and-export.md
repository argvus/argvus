---
title: テーマのインポートとエクスポート
description: アクティブなテーマを自分のテーマとしてエクスポートし、テーマアーカイブをインポートして適用し、削除します。
---
エクスポートとインポートは**テーマ**で行い、公式テーマと同じ形式です。エクスポートは、アクティブなテーマをハイライトカラーや壁紙とともに新しい自分用のテーマとして保存します。インポートは、テーマアーカイブを自分のテーマの中にインストールします。どちらも**コントロールセンター → 外観 → テーマ**にあり、あなたのテーマは**カスタムテーマ**に表示されます。

## エクスポートしたテーマに含まれるもの

アーカイブ`argvus-theme-<id>.tar.gz`には1つのテーマディレクトリが含まれており、公式テーマと同様のレイアウトになっています:

```text
<id>/theme.toml        the manifest (schema 2): name, category, palette, wallpaper
<id>/appearance.json  your visual settings, including layout, effects, fonts and panel presentation
<id>/effects.conf     per-surface effect values for the active theme, when present
<id>/overrides/...     the overrides of the theme it was made from, if any
<id>/wallpaper.<ext>   the wallpaper on screen when you exported
```
マニフェストはアクティブなテーマに基づいており、あなたの名前、新しいID、パレットのアクセントとしてのハイライトカラー、その隣に壁紙が含まれます。外観プロファイルは、ARGVUSで現在適用されている視覚設定（ウィンドウ間隔、境界線、タスクバーの余白、パネル表示、色、エフェクト、フォントなど）を保持します。カスタム壁紙とアクセントカラーはテーマに保存されます。テーマを適用すると、そのテーマの完全なプロファイル（プロファイルが存在しない場合はARGVUSのデフォルト）を再適用し、最後に適用されてから行った独立した視覚的変更を置き換えます。StickyまたはSpacedを切り替えると、そのモードのウィンドウおよびタスクバーの設定が常に再適用されます。個人の設定を保持したい場合は、カスタムテーマとしてエクスポートして保存してください。オーディオ、キーボード、ネットワークの設定など、非視覚的な設定はテーマの一部ではありません。

適用された外観は、セッションの再起動やリロード後も持続します。セッションの準備では、元のテーマのジオメトリを復元することなく、現在の設定から必要なファイルを再構築します。

テーマを適用した後に変更された設定は、次回のテーマまたはモードの変更時には一時的です。現在の視覚設定を保持するには、**コントロールセンター → 外観 → テーマ → テーマのエクスポート** からテーマをエクスポートし、後でそのエクスポートしたテーマを適用することで復元できます。

あなたのテーマは `~/.local/share/argvus/themes/<id>/` にインストールされています。そこでアーカイブを展開すると、テーマもインストールされます。

## アクティブなテーマをエクスポートする

1. **コントロールセンター → 外観 → テーマ** を開きます。
2. テーマページで **テーマのエクスポート** を選択するか、`e` を押します。
3. テーマの名前を入力します。フィールドには書き込まれるファイル名が表示されます。
4. `Enter` を押します。

ID は名前から作られます：小文字の文字、数字、ハイフンです。ID がすでにインストール済みのテーマやホームディレクトリ内のアーカイブで使用されている場合は、`-2`、`-3` のように番号が追加されます。アーカイブはホームディレクトリに書き込まれます。例えば `~/argvus-theme-my-theme.tar.gz` です。ARGVUS は書き込む前にテーマをチェックします：マニフェストが読み込まれ、すべてのコンポーネントが両方のモードでレンダリングされる必要があります。

## テーマのインポート

1. `.tar.gz` アーカイブをホームディレクトリ（`~`）にコピーします。ARGVUS はテーマを含むアーカイブを一覧表示します。
2. **コントロールセンター → 外観 → テーマ → テーマのインポート** を開くか、テーマページで `i` を押します。
3. アーカイブを選択して `Enter` を押します。

ARGVUSは、インストール前にアーカイブをチェックします。アーカイブには、`theme.toml` を含む単一のディレクトリのみを保持する必要があります。相対パスのみで（`..`やリンクは不可）、最大128エントリ、各ファイルにはサイズ制限があります。IDはディレクトリと一致する必要があり、壁紙はアーカイブ内に存在し、すべてのコンポーネントは両方のモードでレンダリングされなければなりません。含まれる外観プロファイルは、サポートされているセクションと有効なJSONを使用する必要があります。チェックに失敗した場合、何もインストールされません。

テーマは**カスタムテーマ**に追加されます。インポートは適用されないため、適用するタイミングは自分で選択します。

### 名前の衝突

- あなたのテーマのIDが既存のテーマと同じ場合、ARGVUSは**同じIDのテーマを置き換えますか？**と尋ねます。置き換える場合は**置き換え**を選択し、自分のテーマを保持する場合は`Esc`を押してください。置き換えられたテーマは、新しいテーマがインストールされるまでバックアップとして保持されます。
- 公式テーマのIDを持つアーカイブは拒否されます。別の名前で再度エクスポートしてください。

## カスタムテーマを適用する

1. **コントロールセンター → 外観 → テーマ → カスタムテーマ** を開きます。
2. テーマを選択して `Enter` を押します。

テーマの完全なエクスポート済み設定が適用されます。壁紙、間隔、境界線、アクセントカラー、エフェクト、フォント、パネル表示を含みます。ビジュアル設定は現在の設定を置き換えます。ARGVUS はその後、タスクバー、Hyprland のリロードサービス、壁紙、コントロールパネルを再起動し、各画面でカスタムテーマが使われるようにします。

## カスタムテーマの削除

1. **コントロールセンター → 外観 → テーマ → カスタムテーマ** を開きます。
2. テーマを選択して `d` を押します。
3. `y` で確認するか、`n` または `Esc` を押してキャンセルします。

テーマのディレクトリは `~/.local/share/argvus/themes` から削除されます。アクティブなテーマであった場合、ARGVUS はまず **ARGVUS Dark** に切り替えます。

## 以前のバージョンのプロファイル

以前のバージョンでは、見た目の設定のコピーである*テーマプロファイル*（`profile.tar.gz`）がエクスポートされていました。テーマページが初めて開かれると、`~/.local/share/argvus/themes/<name>/`内の各プロファイルが、ベーステーマを元に作成されたテーマに変換され、そのハイライトカラーと壁紙が適用されます。元のプロファイルと古い`custom-themes.json`リストは`~/.config/argvus/data/backups/theme-profiles-<seconds>/`に移動され、ステータスラインに変換が報告されます。ベーステーマがインストールされていないプロファイルはバックアップにのみ移動されます。

## テーマを共有する

エクスポートされたテーマは通常のアーカイブです。別のマシンでARGVUSを実行している場合は、それをコピーし、そこでインポートしてください。

## トラブルシューティング

- **アーカイブがリストにありません。** ホームディレクトリの直下にあり、`.tar.gz`で終わり、`<id>/theme.toml`を含む必要があります。
- **インポートが拒否されました。** ステータス行に理由が表示されます：同じIDの公式テーマがある、壁紙が欠落している、マニフェストが読み込まれない、またはコンポーネントがレンダリングされないなど。
- **エクスポートが拒否されました。** 名前には少なくとも1文字または1桁が必要で、アクティブなテーマがインストールされている必要があります。
