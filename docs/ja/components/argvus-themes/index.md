ARGVUS のテーマは、デスクトップ全体で使用される色、表面、壁紙のデフォルト、レイアウトのジオメトリを設定します：Hyprland、Waybar、コントロールパネル、タスクバー、ロック画面、通知、そして ARGVUS アプリケーションです。このガイドでは、ユーザーとしてテーマを扱うために必要なすべてをカバーします。

## テーマに含まれるもの

各公式テーマは、2 つのモードを持つ完全なビジュアルアイデンティティです：

- **Sticky** — コンパクトなレイアウトで、窓の間隔は小さく、外側の余白はなく、タスクバーは画面端に近い位置にあります。
- **Spaced** — より広々としたレイアウトで、間隔が大きく、角が丸く、タスクバーやシェルの表面の周りにマージンがあります。

テーマを選択してもそのアイデンティティは変わりません：パレット、デフォルトのハイライトカラー、壁紙の関連付けはモード間で同じままです。モードは別の設定です。[公式テーマ](/docs/components/argvus-themes/official-themes/)を参照してください。

## クイックリファレンス

| タスク | 場所 |
| --- | --- |
| テーマを選ぶ | **コントロールセンター → 外観 → テーマ → 公式テーマ** |
| StickyとSpacedを切り替える | **コントロールセンター → 外観 → モード** |
| ハイライトカラーを変更する | **コントロールセンター → 外観 → ハイライトカラー** |
| 現在のテーマをエクスポート | **コントロールセンター → 外観 → テーマ → テーマのエクスポート** |
| テーマをインポート | **コントロールセンター → 外観 → テーマ → テーマのインポート** |
| キーボードからテーマセレクターを開く | `SUPER + SHIFT + T` |

## テーマの入手先

ARGVUSには、`argvus-appearance`パッケージと共に、2つの組み込みテーマ、**ARGVUS Dark** と **ARGVUS Light** が付属しています。その他の公式テーマはすべて別の`argvus-theme-<name>`パッケージです。テーマパッケージをインストールすると、テーマセレクターに追加され、セッションの再起動は不要です。エクスポートまたはインポートした自分のテーマは、**カスタムテーマ** として別に表示されます。

## キーボードのヒント

コントロールセンターのテーマページでは、フッターにキーが表示されます：

- `↑` / `↓` — ナビゲート。
- `Enter` — 適用または開く。
- `e` — アクティブなテーマをエクスポート、テーマページ上で。
- `i` — テーマをインポート、テーマページ上で。
- `d` — カスタムテーマを削除。
- `Esc` — 戻る。

## トラブルシューティング

- **インストールしたテーマが表示されません。** `pacman -Q argvus-theme-<name>`でパッケージがインストールされていることを確認し、コントロールセンターを再度開いてください。パッケージは`argvus-appearance`が存在する状態でインストールされている必要があります。
- **テーマを切り替えた後にハイライト色が変わった。** カスタムハイライト色はテーマの切り替え後も保持されます。**テーマのデフォルトにリセット**を使用して、テーマ固有の色に戻してください。
- **インポート用のテーマアーカイブが表示されない。** それはホームディレクトリ直下にあり、`<id>/theme.toml`を含んでいる必要があります。詳細は[テーマのインポートとエクスポート](/docs/components/argvus-themes/import-and-export/)を参照してください。
