title: アルグヴス時計
description: 時計、世界時計、ストップウォッチ、カウントダウンタイマー、音付きアラーム。
---
ARGVUS Clockは、現在の時刻と時間ツール（ワールドクロック、ストップウォッチ、カウントダウンタイマー、アラーム）を備えたGTK 4アプリケーションです。ランチャーから、タスクバーの時刻をクリックして、**SUPER + Shift + C**で、または次の方法で開くことができます:

```sh
argvus clock                     # open the popup near the pointer
argvus clock --toggle            # hide the popup if it is visible, show it otherwise
argvus clock --toggle --x 1600 --y 30  # open next to a taskbar click position
argvus clock --page alarms       # open on a page: clock, world, stopwatch, timer, alarms
argvus clock --background        # run without a window, to keep alarms active
```
ARGVUS Clockは、タスクバーに揃ったポップアップとして開き、4ピクセルの隙間があります。タスクバーはルートクリックの座標を渡すため、ポップアップはクリックされたモニターを使用します。座標なしで起動すると、ポインター位置が使用されます。ポインターがポップアップ外に5秒間留まると、自動的に閉じます。ポインターをポップアップ内に移動すると、カウントダウンがキャンセルされます。メインタブで**Esc**を押すと、すぐに非表示になります。全画面表示で**Esc**を押すと、前のタブに戻ります。`argvus --clock`はエイリアスです。タスクバーの日付をクリックしてもカレンダーは開き、ARGVUS Clockはイベントを表示しません。

ARGVUS Focus、ARGVUS Clock、そしてコントロールパネルは同じ画面端を共有します。Clockを開くと、まずFocusとコントロールパネルが閉じます。いずれかのサーフェスを開くと、Clockが閉じます。

## ページ

- **時計**：大きな数字で表示される時間（デフォルトは24時間表示、設定で12時間表示、秒はオプション）、現地の日付、現地のタイムゾーンとそのUTCオフセット、次のアラーム。
- **ワールド**：都市やIANAタイムゾーンを検索して追加（アクセントや大文字小文字は無視）。各都市の時間、現地時間との差、および「昨日」「今日」「明日」を表示。夏時間はIANAタイムゾーンデータベースに基づくもので、固定オフセットから計算されるものではありません。都市は並べ替えや削除が可能。
- **ストップウォッチ**：開始、一時停止、再開、リセット、ラップ（ラップタイムと合計）
- **タイマー**：時間、分、秒、またはプリセットの5、10、15、25、30、60分。停止、一時停止、再開、再スタート、キャンセル。終了時はアラームのように鳴ります。このタイマーはARGVUS Focusセッションとは独立しています。
- **アラーム**: アラームを作成、編集、オン・オフの切り替え、削除できます。各アラームには時間、オプションで名前、繰り返す曜日（なしの場合は一度だけ鳴ります）、音、スヌーズの長さがあります。

キーボード: **Ctrl+1** から **Ctrl+5** でページを切り替え、**Ctrl+N** でアラームを作成、**Ctrl+,** で設定を開き、**Esc** で戻り、**Ctrl+W** でウィンドウを閉じ、**Ctrl+Q** で終了します。

## アラーム音

アラームは、応答するまで実際の音を再生します:

- サウンド：**Chime**（デフォルト）と**Beacon**、`/usr/share/argvus/sounds/`に同梱。
- **アラーム音量**（10～100、デフォルト80）および**アラーム音を聴く**は設定で行える。エディタには選択したサウンドをテストするボタンがある。
- 鳴っているアラームは、他のウィンドウの上に画面上部にカードとして表示され、通知も表示される。どちらも**スヌーズ**と**解除**がある。カードがフォーカスされている場合、**Enter**で解除、**S**でスヌーズ。
- スヌーズはアラームのスヌーズ時間（1～60分、デフォルト10）後に再度鳴る。
- 応答されなかったアラームは、**鳴動停止まで**（5、10、15、30分、デフォルト10）で停止し、通知を残す。
- 2つのアラームが同時に鳴っている場合は両方リストに表示され、後のアラームが最初のアラームを消音することはない。
- サウンドが再生できない場合、カードとウィンドウにエラーと共に表示され、エラーが記録される。ARGVUS Clockは再生されなかったサウンドを報告しない。

再生はGTKのメディアサポート（GStreamer）を使用しているため、PipeWire、PulseAudio、またはALSAで動作します。このパッケージは`gst-plugins-base`（Ogg Vorbis）および`gst-plugins-good`（オーディオ出力）に依存しています。

## アラームが鳴るとき

アラームは、ARGVUS Clockがセッションで実行されている間のみ鳴ります。

- ウィンドウを閉じても、アラーム、実行中のタイマー、または実行中のストップウォッチが必要な場合はARGVUS Clockは動作し続けます（**ウィンドウを閉じても実行を続ける**［デフォルトでオン］）。保留中のものがなければ終了します。
- **セッションと共に開始** は、ユーザーユニット`argvus-clock.service`を有効にし、ログイン後に`argvus clock --background`を実行します。デフォルトではオフです。
- ログアウト中、コンピュータの電源がオフになっている場合、またはサスペンド中はアラームは鳴りません。
- アラームは最大5分遅れて通知されても鳴ります。それ以上遅れる場合（時計が動いていない、またはシステムがスリープ中またはオフの場合）は鳴らず、通知やアラームページでは**見逃し**として報告されます。繰り返しアラームは翌日に続き、1回限りのアラームはオフになります。  
- 各発生は鳴る前に処理済みとして保存されるため、ARGVUS Clockを再度開いても同じアラームが二度鳴ることはなく、セッションごとに1つのインスタンスのみが実行されます。  
- 繰り返しアラームは選択された曜日の現地時間で計算されるため、サマータイムの変更後も時刻を維持します。春の変更でスキップされた時刻はギャップ直後の最初の分に鳴り、2回発生する時刻は最初に鳴ります。  
- タイマーはサスペンド中もカウントを続けます。システムがスリープ中に終了した場合、起動時に鳴り、遅れた時間を表示します。ARGVUS Clockを閉じた後、動作中のタイマーやストップウォッチは一時停止状態で復帰します。  

## パス

| パス | 内容 |
| --- | --- |
| `$XDG_CONFIG_HOME/argvus/data/clock/settings.json` | 設定とワールドクロック |
| `$XDG_DATA_HOME/argvus/clock/alarms.json` | アラーム |
| `$XDG_STATE_HOME/argvus/clock/timers.json` | タイマーとストップウォッチのチェックポイント |
| `/usr/lib/systemd/user/argvus-clock.service` | セッションと共に開始 |
| `/usr/share/argvus/sounds/` | パッケージ化されたサウンド |

ファイルは原子的に書き込まれます。読み取れないファイルは `<name>.corrupt-<time>` にリネームされ、デフォルトが使用されます。色はアクティブな ARGVUS テーマとハイライトカラー（テーマコンシューマー `time`）に従います。文字列は `clock` および `time` 翻訳ドメインから取得されます。

タスクバーのカレンダー、ARGVUS フォーカス、ARGVUS クロック、およびコントロールパネルは相互に排他的です：1 つを開くと、他のものは閉じられます。
