---
title: クイックスタート
description: ARGVUSを一つのコマンドで実行する。
---
新しい Arch Linux インストールで、TTY から直接 ARGVUS を試す最も速い方法:

```sh
curl -fsSL https://argvus.github.io/install.sh | sh
```
この 1 つのコマンドにより、ARGVUS リポジトリ キーのインポートと署名、パッケージ リポジトリの構成、パッケージ データベースの更新、`argvus` パッケージとその依存関係のインストールが行われます。

ログアウトし、ディスプレイ マネージャーから **ARGVUS** を選択します (または TTY セッションを開始します)。
