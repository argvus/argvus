---
title: 仮想マシン
description: 仮想グラフィックハードウェアでARGVUSを実行します。
---
`argvus start` は仮想化を検出し、対象となるセッションの互換設定をエクスポートします。これには、検出された環境で必要とされる場合のソフトウェアレンダリングおよびカーソル/修飾キーのフォールバックが含まれます。

仮想マシンでまだレンダリングに失敗する場合は、オーバーライドを追加する前にセッション環境とログを確認してください。[graphics troubleshooting](/docs/user-guide/troubleshooting/graphics-and-virtual-machines/) を参照してください。

仮想化が検出されると、`argvus start` はセッション用の互換変数をエクスポートします。これには、ソフトウェアレンダリング、ソフトウェアカーソル、および修飾キーのフォールバックが含まれます。これにより、通常のログインパスを最初に試すことが容易になります。デスクトップが VM で実行されているという理由だけで、恒久的なオーバーライドを追加しないでください。

検出が十分でない場合は、診断用のフォールバックとしてユーザの Hyprland オーバーライドを使用してください:

```sh
mkdir -p ~/.config/argvus/data/hypr
nano ~/.config/argvus/data/hypr/user.lua
```
これは、VMのグラフィックススタックが必要とする場合にのみ追加してください：

```lua
hl.env("LIBGL_ALWAYS_SOFTWARE", "1")
```
セッション環境を変更した後、ログアウトして再度ログインしてください。`echo $LIBGL_ALWAYS_SOFTWARE`でアクティブな値を確認してください。ソフトウェアレンダリングはデスクトップを使用可能にすることがありますが、パフォーマンスが低下する可能性があります。
