表に表示される色は、そのファミリーが選択されたときや **テーマのデフォルトにリセット** を使用したときに `config.json` に書き込まれる値です。手動で選択された6桁のRGBアクセントカラーは、次のテーマ切り替えまで適用され、その際に選択されたテーマのデフォルトに置き換えられます。

**Sticky** はコンパクトレイアウトです：タイル状のウィンドウは小さな内部ギャップを使用し、外側のギャップはゼロで、タスクバーは画面端に近接します。**Spaced** はより大きなギャップ、丸みを帯びた角、影、タスクバーやシェル面の周囲の余白を追加します。

既存の `float` レイアウト値および `-float` テーマ識別子は、Spaced のレガシー名として認識されます。新しいレイアウト値および解決されたテーマ識別子は、`spaced` および `-spaced` を使用します。

モードはジオメトリと表面処理を変更します；6番目のカラーファミリーを作成するものではありません。選択については [Themes](/docs/user-guide/appearance/) を、タスクバーおよびウィンドウの配置については [Desktop](/docs/user-guide/desktop/) を参照してください。

## ウィンドウの揺れ

**デスクトップ & 入力 → Hyprland → アニメーション → ウィンドウ**を開き、
**Wobble（揺れ）**のコントロールを使用します。`wobble`を検索するか、ページを直接開いてください:

```sh
argvus control-center hyprland animations windows
```
Wobbleはデフォルトで無効になっています。ARGVUSのデフォルトは、剛性`100`、減衰`10`、質量`1`、強度`1`、メッシュ解像度`8`です。剛性と質量は`0.0001–1000`、減衰`0–1000`、強度`0–2`を受け入れ、メッシュは整数`2–32`を受け入れます。メッシュ解像度が高いほどレンダリングコストが増加します。矢印キーで値を調整するか、Enterキーで入力してください。**Wobbleのデフォルトを復元** はドラフトを変更します。**適用** は保留中のアニメーション編集をすべて保存し、セッションを再起動せずにHyprlandを一度リロードします。Animations内で戻ると、共有ドラフトは保持されます。

グローバルのAnimationsスイッチは個別設定を保持したままWobbleを抑制します。標準値はARGVUS状態の`effects.wobble_*`に存在します。`hypr/state.lua`は生成されるもので、手動編集してはいけません。

これは Hyprland **0.57.0 以降** が必要であり、`argvus-hyprland` のパッケージ依存によって強制されています。バージョン 0.56 はこの構成ではサポートされていません。強度の最大値は [リリースされた 0.57.0 のソース](https://github.com/hyprwm/Hyprland/blob/v0.57.0/src/config/values/ConfigValues.cpp) に従っており、`2` に制限されています。新しいドキュメントでは `3` と表示されている場合がありますが、これは対象外です。
