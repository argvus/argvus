変更したいものは分かっているが、どのARGVUSの画面が担当しているか分からない場合は、この表を使用してください。

主なデスクトップエリアのガイド付きレビューを行うには、`argvus welcome` で **ARGVUS Welcome** を開くか、**コントロールセンター → ツールと診断** から開いてください。

| したいこと | 行く先… |
| --- | --- |
| テーマやモードを選ぶ | **コントロールセンター → 外観 → テーマ** |
| アクセントカラーを変更する | **コントロールセンター → 外観 → アクセント** |
| 壁紙を変更する | **コントロールセンター → 外観 → 壁紙** |
| ビジュアルエフェクトを有効または無効にする | **コントロールセンター → 外観 → エフェクト**, **コントロールセンター → 外観 → ランチャー**, **コントロールセンター → 設定**, **タスクバー**, **ウィジェットテレメトリ** または **コントロールパネル** |
| タスクバーの位置、高さ、境界線、ユーティリティグループを変更する | **コントロールセンター → 外観 → タスクバー → 位置**, **高さ**, **境界線** および **アイコン** |
| タスクバーの JSONC または CSS をカスタマイズ | [Waybar とタスクバーのオーバーライド](/docs/argvus-waybar/)] |
| ウィンドウの隙間や境界線を変更 | **コントロールセンター → デスクトップと入力 → Hyprland → ウィンドウ → スペース** および **境界線** |
| ウィンドウの影を変更 | **コントロールセンター → デスクトップと入力 → Hyprland → 境界線 → 影** |
| 表示するコントロールパネルカードを選択 | **コントロールセンター → 外観 → コントロールパネル** |
| キーボードショートカットを変更 | **コントロールセンター → ロケールと地域 → キーボードショートカット** |
| 高度な Hyprland ルール、モニター設定、または新しいキー割り当てを追加 | [Hyprland オーバーライド](/docs/argvus-hyprland/hyprland-overrides/)] |
| マウスやタッチパッドの動作を変更 | **コントロールセンター → ロケールと地域 → マウスとタッチパッド** |
| フォントを変更 | **コントロールセンター → フォント** |
| デフォルトアプリケーションを選択 | **コントロールセンター → デフォルトアプリケーション** |
| ディスプレイ設定を変更 | **コントロールセンター → ディスプレイ** または コントロールパネルのディスプレイカード |
| ネットワーク接続を確認または変更 | コントロールパネルのネットワークカード; 永続的なネットワーク構成はインストールされたネットワークツールによって提供されます |
| ボリュームを変更またはすばやくミュート | コントロールパネルのボリュームカードまたはメディアキー |
| 明るさをすばやく変更 | コントロールパネルの明るさカードまたは明るさキー |
| ロック、ログアウト、一時停止、または電源オフ | コントロールパネルのセッション/電源カード |
| 言語、タイムゾーン、地域設定を構成 | **コントロールセンター → ロケールと地域** |

## 設定またはクイックアクション?

デスクトップ構成の一部として設定を保持したい場合は、コントロールセンターを確認するのが適しています。現在の状態を確認したり頻繁な操作を実行したい場合は、コントロールパネルを見るのが適しています。一部のコントロールパネルカードは、コントロールセンターで使用される同じ基盤プロバイダーを開きますが、パネル自体は第二の設定データベースではありません。

設定がリストにない場合は、コントロールセンターのホーム検索を使用してください。その検索レジストリには、ユーザー向けの外観のルートや、キーボード、入力、ディスプレイ、ネットワーク、セッションのドメインが含まれています。
