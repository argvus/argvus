---
title: D-Busインターフェース
description: ARGVUS統合で使用されるD-Bus契約。
---
ARGVUS は、デスクトップ全体のバスを公開するのではなく、システムの D-Bus API を利用します。重要な利用者には、コントロールセンターやグリーターでの BlueZ と logind、リムーバブルデバイスでの UDisks2、ハードウェア設定での ratbagd があります。

正確なインターフェースはプロバイダーまたは上流サービスに属します。メソッドやプロパティに依存する前に、所有しているリポジトリとインストール済みのイントロスペクションデータを確認してください。
