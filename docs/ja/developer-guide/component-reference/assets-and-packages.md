---
title: アセットとパッケージ
description: ARGVUS の資産およびパッケージングプロジェクト。
---
`argvus-appearance`はテーマとアクセント状態、テーマオーケストレーター、および外部利用者向けのアダプターを所有しています。生成されたビジュアル利用者は`argvus-config`が所有しています。`argvus-branding`はARGVUSのロゴとワードマークを提供します。`argvus-wallpapers`、`argvus-fonts`、および`argvus-icons`はアセットを提供します。`argvus-app-profiles`はアプリケーションプロファイルを提供します。`argvus-waybar`はパッチ済みのWaybarバイナリをパッケージ化します。
