---
title: 貢献する
description: ARGVUSプロジェクトおよびドキュメントの貢献範囲。
---
変更を行う前に、すべての消費するリポジトリを通して機能を追跡してください。共有状態の契約、パッケージ所有権、サービス所有権、および両方のローカリゼーションカタログを保持してください。

`argvus-config` は `data/generated/` の唯一の書き手です。消費者ファイルを追加または変更する場合は、`crates/argvus-config/src/project.rs` およびその `project/` 下のサブモジュール（`project/hyprland_projection.rs` 内の Hyprland ファイル）で行い、シェルヘルパーでは行わないでください。消費者アプリケーションが `config.json` を読み取れない場合は、所有パッケージにアダプタを追加し、正規のコミット後にオーケストレーターから呼び出してください。`data/generated/` を削除し、`argvus config apply` を実行して、ツリーが `config.json` からバイト単位で再構築されていることを確認してください。ソース、パッケージのペイロード、およびライブセッションの動作を個別に検証してください。ソースビルドだけでは、インストールされた Wayland セッションが新しいファイルを使用していることの証明にはなりません。
