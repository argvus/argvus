---
title: インストール
description: Arch LinuxにARGVUSパッケージをインストールする。
---
ARGVUSは署名されたArch Linuxパッケージとして配布されます。公式インストーラーはARGVUSパッケージリポジトリを設定し、その後パッケージセットがデスクトップコンポーネントをインストールします。

[requirements](/docs/getting-started/installation/requirements/)を参照し、[installation steps](/docs/getting-started/installation/install/)に従い、最後に[first session](/docs/getting-started/installation/first-session/)で終了してください。

パッケージリポジトリおよび`argvus`メタパッケージは、デスクトップコンポーネントパッケージとは別に管理されています。所有権については開発者の[package matrix](/docs/reference/package-matrix/)を参照してください。
