---
title: 要件
description: ARGVUS のシステム要件と前提条件。
---
ARGVUS は Arch Linux を対象としており、Wayland 対応のグラフィックススタック、Hyprland およびパッケージによって取得されるランタイム依存関係が必要です。ディスプレイマネージャはオプションです：ARGVUS は greetd を介したグラフィカルログインフローと手動 TTY フローの両方をサポートします。

インストール前に、次のことを確認してください：

- システムが `pacman` で完全に更新されていること；
- 動作するカーネルとグラフィックスドライバがインストールされていること；
- ユーザーが Wayland セッションを実行できること；
- パッケージリポジトリが設定されている場合にネットワークが利用可能であること。

仮想マシンでは [Virtual machines](/docs/user-guide/virtual-machines/) に記載された互換性設定が必要な場合があります。
