このセクションでは、最低限のArch Linuxインストールから動作するARGVUSデスクトップに至るまでに必要なすべての手順を説明します。

最短ルートを知りたい場合は、代わりに[Quick Start](/docs/quick-start/)を参照してください。

## 手順

1. ハードウェアおよびグラフィックスタックの[requirements](/docs/getting-started/installation/requirements/)を確認します。
2. [Install ARGVUS](/docs/getting-started/installation/install/)に従ってパッケージリポジトリを追加し、パッケージをインストールします。
3. [First session](/docs/getting-started/installation/first-session/)で初めてのグラフィカルまたはTTYセッションを開始します。

ARGVUSが動作したら、[User Guide](/docs/user-guide/)で日常的な設定（外観、セッション、アプリケーション、ハードウェアなど）について説明します。
