## Locais

A documentação é traduzida em dois locais:

- **Inglês** (raiz) — em `src/content/docs/docs/`.
- **Português** (`pt`) — em `src/content/docs/pt/docs/`, exibido como `pt-BR`.

## Sidebar

A sidebar é configurada em `astro.config.mjs` com entradas `translations`, de modo que os rótulos aparecem no idioma ativo do leitor.
