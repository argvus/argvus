---
title: তাপমাত্রা সেন্সর
description: লাইভ তাপমাত্রা ওভারভিউ lm_sensors JSON দ্বারা সমর্থিত।
---

`argvus sensors` টাস্কবার CPU তাপমাত্রা পপআপ দ্বারা ব্যবহৃত ইন-প্রসেস Ratatui প্যানেলটি খোলে। এটি `sensors -j` চালায়, হার্ডওয়্যার দ্বারা রিপোর্ট করা চিপের নাম এবং লেবেলগুলির দ্বারা গ্রুপ রিডিং, এবং প্রতি দুই সেকেন্ডে রিফ্রেশ করে৷ GPU পর্যবেক্ষণ `argvus system-monitor --gpu` দ্বারা পরিচালিত হয়।

রিডিং সেলসিয়াস ব্যবহার করে। প্যানেল `max`, `crit`, এবং অ্যালার্ম অবস্থা দেখায় যখন lm_sensors তাদের প্রদান করে। একটি ইতিবাচক সীমা উপলব্ধ হলেই একটি গেজ দেখানো হয়৷ অনুপস্থিত `lm_sensors`, কমান্ড ব্যর্থতা, অবৈধ JSON, এবং খালি রিডিংগুলি পুনরুদ্ধারযোগ্য অবস্থা হিসাবে দৃশ্যমান থাকে; পরবর্তী চক্রে পোলিং পুনরায় চেষ্টা করে।

বন্ধ করতে `q` বা `Esc` টিপুন। টাস্কবার `argvus tui-terminal` এর মাধ্যমে কিটিতে প্যানেলটি খোলে; এর স্থানীয়কৃত নীচের ট্যাব শিরোনামটি বন্ধ ইঙ্গিত দেখায়। এই কমান্ডটি CPU তাপমাত্রার বিবরণের মালিক; GPU তাপমাত্রা আইকন GPU-শুধুমাত্র btop মনিটর খোলে। টাস্কবার প্যাকেজ ইতিমধ্যেই `lm_sensors` এর উপর নির্ভর করে, তাই আলাদা প্যাকেজ বা নির্ভরতার প্রয়োজন নেই।
