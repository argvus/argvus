---
title: নেটওয়ার্কিং এবং ব্লুটুথ
description: ARGVUS এর মাধ্যমে নেটওয়ার্ক ম্যানেজার এবং ব্লুটুথ পরিচালনা করুন।
---

`argvus network ` সাবকমান্ড নেটওয়ার্ক ম্যানেজার রিপোর্ট করে এবং নিয়ন্ত্রণ করে এবং ` argvus bluetooth ` ব্লুটুথ অ্যাডাপ্টারের অবস্থা এবং উপলব্ধতা রিপোর্ট করে এবং নিয়ন্ত্রণ করে। উভয়ই ` argvus ` এর ভিতরে প্রক্রিয়াধীন চালায়; ` networkctl ` এবং ` bluetoothctl` উপনাম হিসাবে রয়ে গেছে। কন্ট্রোল প্যানেল এবং ওয়েবার এই কমান্ডগুলিকে কল করে।

ইনস্টল করা সাবকমান্ডের জন্য উভয় কমান্ডে `--help` ব্যবহার করুন। নেটওয়ার্ক এবং ব্লুটুথ UI ইন্টিগ্রেশন ব্লুম্যানের মতো ঐচ্ছিক উন্নত পরিচালকদের থেকে আলাদা৷

কন্ট্রোল সেন্টার কনফিগারেশন পৃষ্ঠাগুলি থেকে নেটওয়ার্ক স্থিতি আলাদা করে: **নেটওয়ার্ক → স্থিতি** বর্তমান অবস্থার সংক্ষিপ্ত বিবরণ দেয়, যখন ইন্টারফেস, ওয়াই-ফাই, ইথারনেট, ভিপিএন, ডিএনএস, প্রক্সি এবং ফায়ারওয়াল পৃথক রুট হয় যখন তাদের প্রদানকারী উপলব্ধ থাকে। **ব্লুটুথ → স্টেট**, **ডিভাইস** এবং **পেয়ার** অ্যাডাপ্টারের অবস্থা এবং ডিভাইস অ্যাকশন কভার করে। এই পৃষ্ঠাগুলি প্রদানকারী-সমর্থিত সিস্টেম ক্রিয়া সম্পাদন করে; টাস্কবার এবং কন্ট্রোল প্যানেল দ্রুত স্থিতি/অ্যাকশন পৃষ্ঠকে প্রকাশ করে।

নেটওয়ার্ক এবং ব্লুটুথ পরিবর্তনের জন্য অনুমোদনের প্রয়োজন হতে পারে এবং নেটওয়ার্ক ম্যানেজার বা ব্লুটুথ পরিষেবার মাধ্যমে অবিলম্বে আবেদন করতে পারে। তারা ARGVUS টাস্কবার সূচক পরিবর্তন করার মত নয়।

কন্ট্রোল সেন্টার `--ask` সহ স্ট্যান্ডার্ড ইনপুটের মাধ্যমে nmcli-তে Wi-Fi পাসওয়ার্ড পাঠায়; পাসওয়ার্ডগুলি প্রসেস আর্গুমেন্ট থেকে বাদ দেওয়া হয় এবং প্রত্যাবর্তিত কমান্ড ত্রুটিগুলি থেকে সংশোধন করা হয়।

## কমান্ড-লাইন নেটওয়ার্ক ব্যবস্থাপনা

গ্রাফিকাল ইন্টারফেস ছাড়াই নেটওয়ার্কিং অনুসন্ধান এবং নিয়ন্ত্রণ করতে `argvus networkctl` ব্যবহার করুন:

```sh
# Show network status
argvus networkctl status

# Toggle networking on/off
argvus networkctl enable
argvus networkctl disable

# Wi-Fi control
argvus networkctl wifi on
argvus networkctl wifi off

# Open the network manager
argvus networkctl manager
```

## কমান্ড-লাইন ব্লুটুথ ব্যবস্থাপনা

ব্লুটুথ অ্যাডাপ্টারের জন্য `argvus bluetoothctl` ব্যবহার করুন:

```sh
# Show the adapter state (key=value lines)
argvus bluetoothctl status

# Exit 0 when an adapter is available, 1 otherwise
argvus bluetoothctl available

# Turn the adapter on or off, or toggle it
argvus bluetoothctl enable
argvus bluetoothctl disable
argvus bluetoothctl toggle

# Open the Bluetooth manager (Blueman)
argvus bluetoothctl manager
```

যখন কার্নেল `/sys/class/bluetooth `-এ কোন কন্ট্রোলার তালিকাভুক্ত করে না, তখন  ` status ` ` status=no-controller ` ` bluetoothctl` জিজ্ঞাসা না করে status অবিলম্বে উত্তর দেয় (যা অন্যথায় পরিষেবা বন্ধ করার সময় BlueZ এর জন্য অপেক্ষা করবে)। টাস্কবার মডিউল এবং কন্ট্রোল প্যানেল কার্ড একই অবস্থা পড়ে।

আপনার ইনস্টল করা সংস্করণের জন্য নির্দিষ্ট অতিরিক্ত বিকল্প এবং সাবকমান্ড দেখতে উভয় কমান্ডে `--help` ব্যবহার করুন।

Wi-Fi পাসওয়ার্ড ডায়ালগ খোলা থাকাকালীন, স্ক্যান আপডেটগুলি নির্বাচিত SSID এবং সুরক্ষা প্রকার সংরক্ষণ করে৷ যদি সেই নেটওয়ার্কটি অদৃশ্য হয়ে যায় বা এর নিরাপত্তা পরিবর্তন হয়, নিশ্চিতকরণ একটি ত্রুটির সাথে বন্ধ হয়ে যায় এবং একটি নতুন নির্বাচনের প্রয়োজন হয়৷

ম্যানুয়াল DNS সমাধানকারী ফাইল আপডেট করার আগে IPv4 এবং IPv6 সার্ভারকে তাদের নিজ নিজ NetworkManager সেটিংসে পাঠায়। পরিষেবা-পরিচালিত সমাধানকারী সিমলিঙ্কগুলি ফাইল প্রতিস্থাপন প্রত্যাখ্যান করে সংরক্ষণ করা হয়। স্বয়ংক্রিয় DNS-এ একটি সফল প্রত্যাবর্তন ব্যাকআপ পুনরুদ্ধার করে এবং সরিয়ে দেয়, তাই পরবর্তী ম্যানুয়াল চক্র বর্তমান সমাধানকারী অবস্থা সংরক্ষণ করে।

নেটওয়ার্ক প্রোফাইল এডিটর বন্ধ করা তার বর্তমান কাজ শেষ হওয়ার সময় অপেক্ষা করে, তাই এডিটর বাতিল করে প্রোফাইল সেভ করা বা মুছে ফেলাকে বাধা দেওয়া যাবে না। পটভূমি রিফ্রেশ বাতিলযোগ্য থাকে।

Wi-Fi সংযোগের অনুরোধগুলি নেটওয়ার্ক অ্যাকশন গার্ড ভাগ করে: অন্য মিউটেশন শুরু হওয়ার আগে একটি চলমান অ্যাকশন বা প্রোফাইল-এডিটর কাজ সম্পূর্ণ হয়। অগ্রগতি এবং সমাপ্তির বার্তা নির্বাচিত ভাষা অনুসরণ করে।

ব্লুটুথ অপসারণ নিশ্চিতকরণ ডিভাইসের তালিকা রিফ্রেশ করলেও আসল ডিভাইসের ঠিকানা রাখে। ব্লুটুথসিটিএল থেকে ব্যাটারি শতাংশ স্বীকৃত, এবং ডিভাইসের বিশদ প্রশ্নগুলি আবদ্ধ একযোগে এবং পৃথক টাইমআউটের সাথে সঞ্চালিত হয়।

Wi-Fi পাসওয়ার্ড, ম্যানুয়াল DNS এবং নেটওয়ার্ক অনুসন্ধান ক্ষেত্রগুলি বন্ধনীযুক্ত পেস্ট গ্রহণ করে। আটকানো নিয়ন্ত্রণ এবং লাইন বিরতি বাদ দেওয়া হয়েছে। অসমর্থিত শুধুমাত্র Ctrl বা Alt-শুধুমাত্র অক্ষর শর্টকাট অক্ষর সন্নিবেশ করে না। সম্পাদকরা Ctrl+Alt হিসাবে এনকোড করা মুদ্রণযোগ্য AltGr ইভেন্টগুলি গ্রহণ করে; Ctrl+S শুধুমাত্র Alt ছাড়াই সংরক্ষণ করে। শেয়ার্ড টেক্সট এডিটর ভিজ্যুয়াল কলামে উল্লম্ব নেভিগেশন রাখে এবং প্রশস্ত অক্ষরের জন্য অনুভূমিক স্ক্রলিং সারিবদ্ধ করে।টাস্কবার নেটওয়ার্ক সূচক `argvus networkctl waybar --follow ` ব্যবহার করে নেটওয়ার্ক ম্যানেজার ইভেন্টগুলি অনুসরণ করে, একটি প্রাথমিক স্ন্যাপশট এবং স্বয়ংক্রিয় মনিটর পুনরায় সংযোগ সহ। এটি আর 10-সেকেন্ডের ভোটের ব্যবধানের জন্য অপেক্ষা করে না। সংযুক্ত, সীমিত ইন্টারনেট অ্যাক্সেস এবং সংযোগ বিচ্ছিন্ন স্বতন্ত্র অবস্থা থেকে যায়। ওয়াই-ফাই স্ট্যাটাস স্ক্যানের অনুরোধ না করেই ক্যাশ করা অ্যাক্সেস পয়েন্ট পড়ে। ` argvus networkctl waybar` একটি একক Waybar JSON স্ন্যাপশট নির্গত করে৷
