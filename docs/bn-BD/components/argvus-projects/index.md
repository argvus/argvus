`argvus projects ` আপনার প্রকল্পগুলিকে তালিকাভুক্ত করে এবং খোলে। এটি ` argvus`-এর একটি ইন-প্রসেস কমান্ড
প্যাকেজ, এবং `SUPER + O` পিকার খোলে।

## কমান্ড

```text
argvus projects                    pick a project (SUPER + O)
argvus projects open SELECTOR      open a project by position, full path or unique name
argvus projects add [--root] DIR   add a project, or a root holding projects
argvus projects remove DIR         remove a project or root
argvus projects list               print configured roots and paths
argvus projects pick [PROMPT]      print the path picked from the list, for other tools
```

## একটি প্রকল্প কি

একটি প্রকল্প হল কনফিগারেশনে তালিকাভুক্ত একটি ডিরেক্টরি (`/projects/paths`), বা এর একটি সাবডিরেক্টরি
`/projects/roots` এ তালিকাভুক্ত একটি রুট। সর্বাধিক নয়টি প্রকল্প তালিকাভুক্ত করা হয়েছে: এর সংখ্যা
`SUPER + CTRL + N` শর্টকাট। একটি প্রকল্প খোলা তার Hyprland কর্মক্ষেত্র ফোকাস. প্রথমবার ক
প্রকল্প খোলে, ARGVUS একটি টার্মিনাল শুরু করে এবং এর ভিতরে `/projects/editor` এ সম্পাদক সেট করে।

কনফিগারেশন `argvus config` এর মাধ্যমে পড়া এবং লেখা হয়, তাই নিয়ন্ত্রণ কেন্দ্র এবং
শেল একই তালিকা দেখুন।

## প্রকল্পের ওয়ার্কস্পেস এবং টাস্কবার

প্রকল্পগুলি সাধারণ নামের হাইপ্রল্যান্ড ওয়ার্কস্পেস ব্যবহার করে, বিশেষ ওয়ার্কস্পেস নয়। `SUPER + O ` প্রকল্প নম্বর, ডিরেক্টরি এবং সরাসরি ` SUPER + CTRL + N ` শর্টকাট দেখায়। উভয় এন্ট্রি পয়েন্ট একই কর্মক্ষেত্র ফোকাস. একটি ` Project: name` লেবেল, সক্রিয় অবস্থা এবং সম্পূর্ণ পথ এবং শর্টকাট সহ একটি টুলটিপ সহ টাস্কবারে শুধুমাত্র খোলা ওয়ার্কস্পেসগুলি উপস্থিত হয়৷ এটিতে ফিরে যেতে ওয়ার্কস্পেস বোতামে ক্লিক করুন। টাস্কবার ওয়ার্কস্পেস এর মনিটর অনুসরণ করে।

ক্যানোনিকাল ডিরেক্টরি পাথ একটি স্থিতিশীল ওয়ার্কস্পেস পরিচয় নির্ধারণ করে; তালিকার ক্রম পরিবর্তন করলে শর্টকাট পরিবর্তন হয়, কর্মক্ষেত্র নয়। একই ডিরেক্টরি নামের প্রকল্পগুলি আলাদা থাকে এবং একই ডিরেক্টরির প্রতীকী লিঙ্কগুলি অনুরূপ করা হয়। টার্মিনাল এবং সম্পাদক লঞ্চগুলি স্পষ্টভাবে প্রকল্পের কর্মক্ষেত্রকে লক্ষ্য করে। যে সম্পাদকরা একটি বিদ্যমান প্রক্রিয়া/উইন্ডো পুনঃব্যবহার করেন তারা সেই অ্যাপ্লিকেশনটির নিজস্ব কর্মক্ষেত্রের আচরণ ধরে রাখতে পারেন।

আপডেটের আগে খোলা ওয়ার্কস্পেস তাদের বিদ্যমান উইন্ডো এবং নেটিভ নাম রাখে। আপডেটের পরে একটি প্রকল্প খোলা তার নতুন পাথ-প্রাপ্ত পরিচয় ব্যবহার করে; সুবিধাজনক হলে পুরানো প্রজেক্ট উইন্ডো বন্ধ করুন। কোনো স্বয়ংক্রিয় সংযোগ বা আন্দোলনের চেষ্টা করা হয় না কারণ একটি পুরানো নাম নির্ভরযোগ্যভাবে ডিরেক্টরিটিকে সনাক্ত করে না। ডুপ্লিকেট ডিরেক্টরি নামের সাথে, একটি অস্পষ্ট নামের পরিবর্তে চয়নকারী, একটি সংখ্যা বা সম্পূর্ণ ক্যানোনিকাল পাথ ব্যবহার করুন।

একটি প্রকল্প খোলার ফলে কনফিগার করা প্রকল্প তালিকা এবং অনুবাদগুলি থেকে পরমাণুভাবে `$XDG_RUNTIME_DIR/argvus/project-workspaces.json ` পুনরায় তৈরি হয়। এটি ওয়ার্কস্পেস লেবেল এবং টুলটিপগুলির জন্য সেশন মেটাডেটা, কনফিগারেশন নয়; এটা সম্পাদনা করবেন না একটি প্রকল্পের লেবেল রিফ্রেশ করতে তালিকা বা ভাষা পরিবর্তন করার পরে পুনরায় খুলুন। এই ইন্টিগ্রেশনের জন্য ` argvus ` এবং ` argvus-waybar `, প্লাস ` argvus-taskbar` কনফিগারেশন উভয়ই আপডেট করুন৷
