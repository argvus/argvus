ARGVUS একটি আর্চ লিনাক্স প্যাকেজ হিসাবে অফিসিয়াল ARGVUS প্যাকেজ সংগ্রহস্থলের মাধ্যমে বিতরণ করা হয়।

## ইন্সটল করার আগে

ARGVUS ইনস্টল করার আগে অফিসিয়াল Arch Linux `multilib` সংগ্রহস্থল সক্ষম করুন৷ `/etc/pacman.conf` সম্পাদনা করুন এবং `[multilib]` বিভাগ এবং এর `Include` লাইন উভয়ই মন্তব্য করুন:

```ini
[multilib]
Include = /etc/pacman.d/mirrorlist
```

তারপর প্যাকেজ ডাটাবেস সিঙ্ক্রোনাইজ করুন এবং একটি সম্পূর্ণ সিস্টেম আপগ্রেড সঞ্চালন করুন:

```sh
sudo pacman -Syu
```

দ্রুত ইনস্টলারটি ARGVUS সংগ্রহস্থল কনফিগার করে, কিন্তু আপনার জন্য `multilib` সক্ষম করে না।

## দ্রুত ইনস্টল করুন

একটি নতুন আর্চ লিনাক্স ইনস্টলেশনে, আপনি প্রথমে অন্য ডেস্কটপ পরিবেশ ইনস্টল না করে সরাসরি একটি TTY থেকে ARGVUS ইনস্টল করতে পারেন।

চালান:

```sh
curl -fsSL https://argvus.github.io/install.sh | sh
```

ইনস্টলার:

1. ARGVUS রিপোজিটরি সাইনিং কী আমদানি করে এবং স্থানীয়ভাবে স্বাক্ষর করে।
2. ARGVUS প্যাকেজ সংগ্রহস্থল কনফিগার করে।
3. প্যাকেজ ডাটাবেস আপডেট করে।
4. `argvus` প্যাকেজ এবং এর নির্ভরতা ইনস্টল করে।

ইনস্টলেশনের পরে, লগ আউট করুন এবং আপনার ডিসপ্লে ম্যানেজার থেকে **ARGVUS** নির্বাচন করুন।

> **দ্রষ্টব্য:** দ্রুত ইনস্টলারের প্রয়োজন `curl`, `sudo`, এবং আদর্শ আর্ক লিনাক্স প্যাকেজ-ব্যবস্থাপনা টুল।

## শুধুমাত্র সংগ্রহস্থল কনফিগার করুন

ডেস্কটপ ইনস্টল না করে ARGVUS প্যাকেজ সংগ্রহস্থল কনফিগার করতে, চালান:

```sh
curl -fsSL https://argvus.github.io/repo-install.sh | sh
```

পরে ম্যানুয়ালি ARGVUS ইনস্টল করুন:

```sh
sudo pacman -Syu argvus
```

## ম্যানুয়াল ইনস্টলেশন

আপনি যদি ধাপে ধাপে সংগ্রহস্থল কনফিগার করতে পছন্দ করেন তবে নিম্নলিখিত কমান্ডগুলি ব্যবহার করুন।

### 1. রিপোজিটরি সাইনিং কী ডাউনলোড করুন

```sh
curl -fsSLo /tmp/argvus.gpg https://argvus.github.io/packages/arch/argvus.gpg
```

### 2. সাইনিং কী আমদানি করুন

```sh
sudo pacman-key --add /tmp/argvus.gpg
```

### 3. স্থানীয়ভাবে কীটিতে স্বাক্ষর করুন

```sh
ARGVUS_KEY="$(gpg --show-keys --with-colons /tmp/argvus.gpg | grep '^pub:' | head -n1 | cut -d: -f5)"
sudo pacman-key --lsign-key "$ARGVUS_KEY"
```

### 4. ARGVUS সংগ্রহস্থল কনফিগার করুন

```sh
curl -fsSL https://argvus.github.io/packages/arch/argvus.conf \
  | sudo tee /etc/pacman.d/argvus.conf
```

`/etc/pacman.conf` এ রিপোজিটরি কনফিগারেশন যোগ করুন:

```sh
echo "Include = /etc/pacman.d/argvus.conf" \
  | sudo tee -a /etc/pacman.conf
```

সংগ্রহস্থল কনফিগারেশন SigLevel = Required TrustedOnly সহ `argvus` এবং `argvus-extras` সহ ARGVUS সংগ্রহস্থলগুলিকে সক্ষম করে৷ Pacman প্যাকেজ গ্রহণ করে তখনই যখন তাদের স্বাক্ষর বৈধ এবং স্থানীয় কীরিং দ্বারা বিশ্বস্ত হয়।

### 5. ARGVUS ইনস্টল করুন

```sh
sudo pacman -Syu argvus
```

ইনস্টলেশনের পরে, লগ আউট করুন এবং আপনার ডিসপ্লে ম্যানেজার থেকে **ARGVUS** নির্বাচন করুন।

## আপডেট

আর্ক লিনাক্সের বাকি অংশের সাথে একসাথে ARGVUS আপডেট করুন:

```sh
sudo pacman -Syu
```

শুধুমাত্র ARGVUS প্যাকেজ আপডেট করতে:

```sh
sudo pacman -S argvus
```

> **প্রস্তাবিত:** আর্চ লিনাক্স সাধারণত পৃথক প্যাকেজ আপডেট করার পরিবর্তে  `SigLevel = Required TrustedOnly` `sudo pacman -Syu` এর সাথে একটি সম্পূর্ণ সিস্টেম আপগ্রেড করার সুপারিশ করে।

## ARGVUS সরান

অন্যান্য ইনস্টল করা প্যাকেজগুলির দ্বারা এখনও প্রয়োজনীয় নির্ভরতাগুলি রাখার সময় ARGVUS সরান:

```sh
sudo pacman -R argvus
```

ARGVUS এবং নির্ভরতাগুলি সরান যা আর কোনো ইনস্টল করা প্যাকেজের জন্য প্রয়োজন হয় না:

```sh
sudo pacman -Rns argvus
```

### ARGVUS সংগ্রহস্থল সরান

আপনি যদি প্যাকেজ সংগ্রহস্থলটিও সরাতে চান তবে এর কনফিগারেশনটি সরান:

```sh
sudo rm /etc/pacman.d/argvus.conf
```

তারপর `/etc/pacman.conf` থেকে সংশ্লিষ্ট লাইনটি সরান:

```text
Include = /etc/pacman.d/argvus.conf
```

আপনি এর সাথে ফাইলটি সম্পাদনা করতে পারেন:

```sh
sudo nano /etc/pacman.conf
```

### সাইনিং কীটি সরান

প্যাকম্যান কীরিং থেকে ARGVUS সংগ্রহস্থল সাইনিং কী অপসারণ করতে, প্রথমে কীগুলি তালিকাভুক্ত করুন:

```sh
sudo pacman-key --list
```

তারপরে ARGVUS কীটি এর কী আইডি দিয়ে সরান:

```sh
sudo pacman-key --delete KEY_ID
```

`KEY_ID` ARGVUS সাইনিং-কী আইডি দিয়ে প্রতিস্থাপন করুন।

> **সতর্কতা:** আপনি যখন ARGVUS সংগ্রহস্থলটি মুছে ফেলছেন শুধুমাত্র তখনই এই কীটি সরান৷ অন্যান্য সংগ্রহস্থলের জন্য প্রয়োজনীয় কীগুলি সরিয়ে ফেলবেন না।

## ব্যবহারকারী কনফিগারেশন

প্যাকেজ ইনস্টলেশন `$HOME`-এ কনফিগারেশন লেখে না। ARGVUS `/usr/share/argvus` থেকে প্যাকেজ করা ডিফল্টগুলি পড়ে এবং সেগুলিকে আপনার হোম ডিরেক্টরিতে অনুলিপি না করে কাজ করে৷

রানটাইম কনফিগারেশন এই সাধারণ অগ্রাধিকার অনুসরণ করে:

```text
~/.config/argvus/data/generated/<app>  ->  ~/.config/argvus/data/<component>/<app>  ->  $XDG_CONFIG_HOME/<app>  ->  /usr/share/argvus/<app>  ->  upstream defaults
```

`argvus-config` হল একমাত্র উপাদান যা `~/.config/argvus/data/generated/` লেখে, এবং সেই অভিক্ষেপ হল সক্রিয় স্তর: একটি পরিচালিত বা নেটিভ কপি শুধুমাত্র কার্যকর হয় যখন সংশ্লিষ্ট উত্পন্ন ফাইলটি অনুপস্থিত থাকে।ARGVUS-পরিচালিত কনফিগারেশন `~/.config/argvus/` এর অধীনে থাকে। একটি ঐচ্ছিক `$XDG_CONFIG_HOME/<app>` ওভাররাইড একটি স্থানীয় ব্যবহারকারী কনফিগারেশন সমর্থন করে এমন অ্যাপ্লিকেশনগুলির জন্য উপলব্ধ থাকে৷

`argvus --setup` প্রেরণকারী ঐচ্ছিক এবং স্পষ্ট ম্যানুয়াল জন্য
ওভাররাইড করে, পুনরুদ্ধার নয়। যদি `~/.config/argvus` মুছে ফেলা হয়, `SUPER + SHIFT + R`
স্বাভাবিকের মাধ্যমে ক্যানোনিকাল প্রোফাইল এবং জেনারেট করা রানটাইম অবস্থা পুনরায় তৈরি করে
পাইপলাইন পুনরায় লোড করুন।

```sh
argvus --setup --copy foot-tui
argvus --setup --copy kitty-tui
argvus --setup --copy-all
```

`--copy-all` হল সমর্থিত TUI প্রোফাইল ফাইলগুলির একটি সুস্পষ্ট অনুমোদিত তালিকা; এটা
`/usr/share/argvus` ক্লোন করে না এবং স্ক্রিপ্ট, পরিষেবা, সম্পদ কপি করে না,
জেনারেটেড ফাইল বা `config.json`। বর্তমান দেখতে `argvus --setup --help` চালান
বিকল্প একবার অনুলিপি করা হলে, ফাইলগুলি ব্যবহারকারীর মালিকানাধীন ওভাররাইড এবং প্যাকেজ হয়ে যায়
আপগ্রেড তাদের প্রতিস্থাপন না.

একটি বিদ্যমান অনুলিপি করা কনফিগারেশন প্রতিস্থাপন করতে, `--force` ব্যবহার করুন৷ ARGVUS এটি প্রতিস্থাপন করার আগে একটি টাইমস্ট্যাম্পড ব্যাকআপ তৈরি করে:

```sh
argvus --setup --copy <app> --force
```

## হাইপ্রল্যান্ড ব্যবহারকারী ওভাররাইড করে

সম্পূর্ণ স্থানীয় কনফিগারেশন এবং ক্রমবর্ধমান ARGVUS খণ্ডের মধ্যে পার্থক্য সহ সম্পূর্ণ হাইপ্রল্যান্ড ওভাররাইড গাইডের জন্য, [হাইপ্রল্যান্ড ওভাররাইড](/docs/argvus-hyprland/hyprland-overrides/) দেখুন।

```sh
mkdir -p ~/.config/argvus/data/hypr
nano ~/.config/argvus/data/hypr/user.lua
```

### ভার্চুয়াল-মেশিন ফলব্যাক

কিছু ভার্চুয়াল মেশিন হাইপ্রল্যান্ড, কিটি বা কুইকশেলের সাথে রেন্ডারিং সমস্যা অনুভব করতে পারে। ARGVUS `vmwgfx` গ্রাফিক্স ড্রাইভার ব্যবহার করে ভার্চুয়াল মেশিন সনাক্ত করে এবং প্রয়োজনে সফ্টওয়্যার রেন্ডারিং সক্ষম করে।

সনাক্তকরণ আপনার ভার্চুয়াল মেশিনে কাজ না করলে, `user.lua`-এ ম্যানুয়ালি ফলব্যাক সক্ষম করুন:

```lua
-- Virtual machine compatibility
hl.env("LIBGL_ALWAYS_SOFTWARE", "1")
```

`user.lua` তৈরি বা সংশোধন করার পরে, হাইপ্রল্যান্ড থেকে লগ আউট করুন এবং আবার লগ ইন করুন যাতে ভেরিয়েবলটি সেশন দ্বারা চালু হওয়া অ্যাপ্লিকেশনগুলিতে প্রয়োগ করা হয়।

এটি দিয়ে যাচাই করুন:

```sh
echo $LIBGL_ALWAYS_SOFTWARE
```

প্রত্যাশিত আউটপুট হল:

```text
1
```

> **দ্রষ্টব্য:** `LIBGL_ALWAYS_SOFTWARE=1` মেসা/ওপেনজিএল অ্যাপ্লিকেশনগুলিকে সফ্টওয়্যার রেন্ডারিং ব্যবহার করতে বাধ্য করে, সাধারণত `llvmpipe` এর মাধ্যমে। এটি গ্রাফিকাল কর্মক্ষমতা হ্রাস করতে পারে এবং প্রভাবিত ভার্চুয়াল মেশিনগুলির জন্য একটি ফলব্যাক হিসাবে ব্যবহার করা উচিত।
