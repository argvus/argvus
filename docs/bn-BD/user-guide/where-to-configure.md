এই টেবিলটি ব্যবহার করুন যখন আপনি জানেন যে আপনি কি পরিবর্তন করতে চান কিন্তু কোন ARGVUS পৃষ্ঠ এটির মালিক তা নয়।

প্রধান ডেস্কটপ এলাকাগুলির একটি নির্দেশিত পর্যালোচনার জন্য, `argvus welcome` এর সাথে **ARGVUS স্বাগতম** খুলুন বা **কন্ট্রোল সেন্টার → টুলস অ্যান্ড ডায়াগনস্টিকস** থেকে।

| --- | --- |
| একটি থিম বা মোড নির্বাচন করুন | **নিয়ন্ত্রণ কেন্দ্র → চেহারা → থিম** |
| উচ্চারণের রঙ পরিবর্তন করুন | **নিয়ন্ত্রণ কেন্দ্র → চেহারা → উচ্চারণ** |
| ওয়ালপেপার পরিবর্তন করুন | **নিয়ন্ত্রণ কেন্দ্র → চেহারা → ওয়ালপেপার** |
| চাক্ষুষ প্রভাব সক্ষম বা নিষ্ক্রিয় করুন | **নিয়ন্ত্রণ কেন্দ্র → উপস্থিতি → প্রভাব**, **নিয়ন্ত্রণ কেন্দ্র → উপস্থিতি → লঞ্চার**, **নিয়ন্ত্রণ কেন্দ্র → কনফিগারেশন**, **টাস্কবার**, **উইজেট টেলিমেট্রি** বা **কন্ট্রোল প্যানেল** |

| টাস্কবার JSONC বা CSS কাস্টমাইজ করুন | [ওয়েবার এবং টাস্কবার ওভাররাইড](/docs/argvus-waybar/) |
| উইন্ডোর ফাঁক বা সীমানা পরিবর্তন করুন | **কন্ট্রোল সেন্টার → ডেস্কটপ এবং ইনপুট → হাইপ্রল্যান্ড → উইন্ডোজ → স্পেস** এবং **সীমান্ত** |
| জানালার ছায়া বদলান | **নিয়ন্ত্রণ কেন্দ্র → ডেস্কটপ এবং ইনপুট → হাইপ্রল্যান্ড → সীমানা → ছায়া** |
| দৃশ্যমান কন্ট্রোল প্যানেল কার্ড নির্বাচন করুন | **নিয়ন্ত্রণ কেন্দ্র → উপস্থিতি → নিয়ন্ত্রণ প্যানেল** |
| কীবোর্ড শর্টকাট পরিবর্তন করুন | **নিয়ন্ত্রণ কেন্দ্র → লোকেল ও অঞ্চল → কীবোর্ড শর্টকাট** || একটি উন্নত হাইপ্রল্যান্ড নিয়ম, মনিটর সেটিং বা নতুন কীবাইন্ডিং যোগ করুন | [হাইপ্রল্যান্ড ওভাররাইড করে](/docs/argvus-hyprland/hyprland-overrides/) |
| মাউস বা টাচপ্যাড আচরণ পরিবর্তন করুন | **নিয়ন্ত্রণ কেন্দ্র → লোকেল ও অঞ্চল → মাউস এবং টাচপ্যাড** |
| হরফ পরিবর্তন করুন | **নিয়ন্ত্রণ কেন্দ্র → ফন্ট** |
| ডিফল্ট অ্যাপ্লিকেশন নির্বাচন করুন | **নিয়ন্ত্রণ কেন্দ্র → ডিফল্ট অ্যাপ্লিকেশন** |
| ডিসপ্লে সেটিংস পরিবর্তন করুন | **কন্ট্রোল সেন্টার → ডিসপ্লে** বা কন্ট্রোল প্যানেল ডিসপ্লে কার্ড |
| নেটওয়ার্ক সংযোগ চেক করুন বা পরিবর্তন করুন | কন্ট্রোল প্যানেল নেটওয়ার্ক কার্ড; স্থায়ী নেটওয়ার্ক কনফিগারেশন ইনস্টল করা নেটওয়ার্ক টুল দ্বারা প্রদান করা হয় |
| ভলিউম পরিবর্তন করুন বা দ্রুত নিঃশব্দ করুন | কন্ট্রোল প্যানেল ভলিউম কার্ড বা মিডিয়া কী |
| দ্রুত উজ্জ্বলতা পরিবর্তন করুন | কন্ট্রোল প্যানেলের উজ্জ্বলতা কার্ড বা উজ্জ্বলতা কী |
| লক, লগ আউট, সাসপেন্ড বা পাওয়ার অফ | কন্ট্রোল প্যানেল সেশন/পাওয়ার কার্ড |
| ভাষা, সময় অঞ্চল বা আঞ্চলিক সেটিংস কনফিগার করুন | **নিয়ন্ত্রণ কেন্দ্র → লোকেল ও অঞ্চল** |

## কনফিগারেশন বা দ্রুত পদক্ষেপ?

কন্ট্রোল সেন্টার হল সেই জায়গা যেখানে আপনি কোন সেটিং আপনার ডেস্কটপ কনফিগারেশনের অংশ হিসেবে থাকতে চান। কন্ট্রোল প্যানেল হল সেই জায়গা যেখানে আপনি যখন স্ট্যাটাস পরিদর্শন করতে চান বা এখন ঘন ঘন অ্যাকশন করতে চান। কিছু কন্ট্রোল প্যানেল কার্ড কন্ট্রোল সেন্টার দ্বারা ব্যবহৃত একই অন্তর্নিহিত প্রদানকারী খোলে, কিন্তু প্যানেলটি দ্বিতীয় সেটিংস ডাটাবেস নয়।

যদি একটি সেটিং তালিকাভুক্ত না থাকে, তাহলে কন্ট্রোল সেন্টারের হোম অনুসন্ধান ব্যবহার করুন। এর অনুসন্ধান রেজিস্ট্রিতে ব্যবহারকারী-মুখী উপস্থিতি রুট এবং কীবোর্ড, ইনপুট, প্রদর্শন, নেটওয়ার্ক এবং সেশন ডোমেন অন্তর্ভুক্ত রয়েছে।
