---
title: ভার্চুয়াল মেশিন
description: ভার্চুয়াল গ্রাফিক্স হার্ডওয়্যার সহ ARGVUS চালান।
---

`argvus start` ভার্চুয়ালাইজেশন সনাক্ত করে এবং সনাক্ত করা পরিবেশের প্রয়োজনে সফ্টওয়্যার-রেন্ডারিং এবং কার্সার/মোডিফায়ার ফলব্যাক সহ প্রভাবিত সেশনগুলির জন্য সামঞ্জস্যতা সেটিংস রপ্তানি করে।

যদি একটি ভার্চুয়াল মেশিন এখনও রেন্ডার করতে ব্যর্থ হয়, একটি ওভাররাইড যোগ করার আগে সেশন পরিবেশ এবং লগগুলি পরিদর্শন করুন। দেখুন [গ্রাফিক্স সমস্যা সমাধান](/docs/user-guide/troubleshooting/graphics-and-virtual-machines/)।

যখন ভার্চুয়ালাইজেশন সনাক্ত করা হয়, `argvus start` সফ্টওয়্যার-রেন্ডারিং, সফ্টওয়্যার-কারসার এবং মডিফায়ার ফলব্যাক সহ সেশনের জন্য সামঞ্জস্য ভেরিয়েবল রপ্তানি করে। এটি সাধারণ লগইন পাথকে চেষ্টা করার প্রথম জিনিস করে তোলে; একটি স্থায়ী ওভাররাইড যোগ করবেন না কারণ ডেস্কটপ একটি VM এ চলছে।

সনাক্তকরণ যথেষ্ট না হলে, ডায়াগনস্টিক ফলব্যাক হিসাবে একটি ব্যবহারকারী হাইপ্রল্যান্ড ওভাররাইড ব্যবহার করুন:

```sh
mkdir -p ~/.config/argvus/data/hypr
nano ~/.config/argvus/data/hypr/user.lua
```

VM গ্রাফিক্স স্ট্যাকের প্রয়োজন হলেই এটি যোগ করুন:

```lua
hl.env("LIBGL_ALWAYS_SOFTWARE", "1")
```

সেশন পরিবেশ পরিবর্তন করার পরে লগ আউট করুন এবং ফিরে যান। `echo $LIBGL_ALWAYS_SOFTWARE` দিয়ে সক্রিয় মান নিশ্চিত করুন; সফ্টওয়্যার রেন্ডারিং ডেস্কটপকে ব্যবহারযোগ্য করে তুলতে পারে তবে কর্মক্ষমতা হ্রাস করতে পারে।
