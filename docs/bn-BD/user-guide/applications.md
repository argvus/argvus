description: ARGVUS-এ সমন্বিত অ্যাপ্লিকেশনগুলি ব্যবহার করুন৷
---

ARGVUS `argvus` প্রেরণকারী এবং ফোকাসড প্যাকেজের মাধ্যমে সাধারণ অ্যাপ্লিকেশনগুলিকে প্রকাশ করে৷

- [লঞ্চার](/docs/argvus-launcher/)
- [টার্মিনাল](/docs/components/argvus-terminal/)
- [ক্যালেন্ডার](/docs/components/argvus-taskbar-calendar/)
- [ARGVUS ফোকাস](/docs/components/argvus-focus/) (পোমোডোরো এবং ফোকাস সেশন)
- [ARGVUS ঘড়ি](/docs/components/argvus-clock/) (ঘড়ি, বিশ্ব ঘড়ি, স্টপওয়াচ, টাইমার এবং অ্যালার্ম)
- [গেমস](/docs/argvus-games/) ([Snake](/docs/argvus-games/snake/) সহ)
- [সিস্টেম মনিটর](/docs/components/argvus-system-monitor/)
- [ডিফল্ট অ্যাপ্লিকেশন](/docs/components/argvus-control-center/)
- [অপসারণযোগ্য ডিভাইস](/docs/components/argvus-removable-devices/)

কন্ট্রোল সেন্টার `argvus --control-center` দিয়ে খোলা হয়েছে; এর অ্যাপস পৃষ্ঠা ডিফল্ট অ্যাপ্লিকেশন পরিচালনা করে।
