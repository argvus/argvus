---
title: UI উপাদান
description: ARGVUS ইউজার-ইন্টারফেস প্যাকেজ।
---

UI প্যাকেজগুলো অন্তর্ভুক্ত করে`argvus-control-panel`, `argvus-taskbar` and `argvus-launcher`, এবং `argvus` subcommands `argvus control-center` (সাহায্যকারী মধ্যে `argvus`), `argvus taskbar-calendar`, `argvus widget-telemetry`, `argvus terminal`, `argvus system-monitor`, `argvus removable-devices`, `argvus focus` and `argvus clock`. ক্যালেন্ডার, ফোকাস এবং ঘড়ি সাধারণ ব্যবহার করে`argvus-taskbar-popup`লেয়ার-শেল অবস্থান নির্ধারণ এবং বাতিল করার জন্য crate; ফোকাস এর ইন-প্রসেসের মাধ্যমে এর ওয়েবার স্ট্যাটাস রিডারও প্রকাশ করে`argvus focus status` route.

তাদের ব্যবহারকারী-মুখী আচরণ বৈশিষ্ট্য দ্বারা নথিভুক্ত করা হয়; এই পৃষ্ঠাটি প্যাকেজ মালিকানা রেকর্ড করে।
