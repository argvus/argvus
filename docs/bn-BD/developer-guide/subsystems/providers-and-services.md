---
title: প্রদানকারী এবং পরিষেবা
description: প্রোভাইডার প্যাকেজ এবং তাদের সিস্টেম ইন্টারফেস।
---

প্রদানকারী প্রকল্পগুলি UI গ্রাহকদের কাছে ফোকাসড ইন্টারফেস প্রকাশ করে:

- `argvus network` এবং `argvus bluetooth` নেটওয়ার্ক ম্যানেজার এবং ব্লুটুথ সাহায্যকারীকে একীভূত করে;
- `argvus-display` হাইপ্রল্যান্ডের সাথে মনিটর স্টেটকে একীভূত করে;
- `argvus-power` নিষ্ক্রিয়, লক এবং পাওয়ার ক্রিয়াগুলিকে একীভূত করে;
- `argvus-firewall` `argvus-firewall.service` পরিচালনা করে;
- `argvus removable-devices` সহায়তাকারী `argvus` UDisks2 ব্যবহার করে;
- `argvus control-center` সহায়তাকারী `argvus` প্রদানকারী API এবং সিস্টেম D-Bus ইন্টারফেস ব্যবহার করে।

কন্ট্রোল সেন্টার এই প্রদানকারীদের একটি ক্লায়েন্ট, তাদের প্রতিস্থাপন নয়।
