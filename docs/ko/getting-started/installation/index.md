---
title: 설치
description: Arch Linux에 ARGVUS 패키지를 설치하세요.
---
ARGVUS는 서명된 Arch Linux 패키지로 배포됩니다. 공개 설치 프로그램은 ARGVUS 패키지 저장소를 구성하며, 이후 패키지 세트가 데스크톱 구성 요소를 설치합니다.

[requirements](/docs/getting-started/installation/requirements/)를 참조하고, [installation steps](/docs/getting-started/installation/install/)를 따라 설치를 진행한 후, [first session](/docs/getting-started/installation/first-session/)로 마무리하세요.

패키지 저장소와 `argvus` 메타패키지는 데스크톱 구성 요소 패키지와 별도로 관리됩니다. 소유권에 대해서는 개발자 [package matrix](/docs/reference/package-matrix/)를 참조하세요.
