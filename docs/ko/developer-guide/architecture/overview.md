---
title: 아키텍처 개요
description: ARGVUS가 통합 데스크톱 환경을 형성하는 방법.
---
ARGVUS에는 다섯 가지 런타임 계층이 있습니다:

1. `argvus`의 진입점 및 디스패치;
2. `argvus-session`의 세션 라이프사이클;
3. `argvus-hyprland`, `argvus-waybar`, `argvus-taskbar` 및 `argvus-control-panel`의 합성기 및 셸 표면;
4. 제어 센터, 캘린더 및 시스템 모니터와 같은 사용자 애플리케이션;
5. 디스플레이, 네트워크, 전원, 외관, 계정 및 알림을 위한 제공자 및 자산.

공유 상태는 이러한 계층을 연결합니다. `argvus-config`는 기본 문서를 보유하고 있으며 `data/generated/`를 쓰는 유일한 작성자이므로, 테마나 효과 변경 시 여러 패키지에서 사용하는 파일이 하나의 트랜잭션으로 재생성됩니다; 세션 서비스는 각 구성 요소 구현의 소유권을 가져가지 않고 라이프사이클 소유권을 제공합니다.

## 책임 경계

| 계층 | 주요 책임 | 예시 |
| --- | --- | --- |
| 진입점 및 디스패치 | 데스크톱 애플리케이션을 시작하고 ARGVUS 프로필을 해결합니다. | `argvus`, `argvus-app-profiles` |
| 세션 수명 주기 | 환경을 준비하고, Hyprland를 실행하며, 사용자 서비스 환경을 동기화하고 자체 세션 종료를 관리합니다. | `argvus-session`, `argvus sessionctl` |
| 컴포지터 및 셸 | 창 동작과 보이는 데스크톱 표면을 정의합니다. | `argvus-hyprland`, `argvus-waybar`, `argvus-taskbar`, `argvus-control-panel` |
| 구성 | `config.json`, 경로 모델 및 모든 생성된 소비자 파일을 관리합니다. | `argvus-config` |
| 애플리케이션 | 설정과 집중된 데스크톱 워크플로우를 제공합니다. | 제어판, 달력, 런처, 시스템 모니터 및 이동식 장치 |
| 공급자 및 자산 | 도메인 운영과 공유 시각 자료를 구현합니다. | 디스플레이, 네트워크, 전원, 알림, 외형, 글꼴 및 배경화면 |

`argvus` 패키지는 설치 대상이자 조정자이지만, 단일 실행 환경(runtime)은 아닙니다. 집중 패키지(Focused package)는 자신의 바이너리, 구성 및 서비스를 소유합니다. 세션 관리자는 구현을 흡수하지 않고 그래픽 세션의 적절한 시점에서 이를 시작합니다.

이 구분은 디버깅 시 중요합니다. 세션 실패는 우선 `argvus-session`에 속하며, 작업 표시줄 실패는 `argvus-taskbar`/`argvus-waybar`에 속하고, 생성된 테마나 배경화면 실패는 외관 및 세션 구성 경로에 속합니다.
