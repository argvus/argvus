# ARGVUS 국제화

ARGVUS는 영어(`en-US`), 브라질 포르투갈어(`pt-BR`), 스페인어(`es-ES`), 프랑스어(`fr-FR`), 이탈리아어(`it-IT`), 독일어(`de-DE`), 러시아어(`ru-RU`), 간체 중국어(`zh-CN`), 일본어(`ja-JP`) 및 한국어(`ko-KR`)를 제공합니다. 영어는 표준 카탈로그이자 대체 언어입니다. 나머지 8개 번역은 기계 번역 지원과 기술적 수정을 통해 제작되었으며, 독립적인 원어민 검토는 인증되지 않았습니다.

## 언어 선택

제어 센터 열기 > 환경설정 > 언어 및 지역 > 언어, 또는 설정 > 언어. 이 페이지는 설치된 카탈로그를 찾아 해당 언어명을 표시합니다. `LANG`를 `$XDG_CONFIG_HOME/locale.conf`에 저장합니다(기본값 `~/.config/locale.conf`). 먼저 시스템 로케일에서 해당 UTF-8 로케일을 활성화하세요. 예시는 `es_ES.UTF-8`, `zh_CN.UTF-8`, `ja_JP.UTF-8` 및 `ko_KR.UTF-8`입니다.

이 환경설정은 `/etc/locale.conf`를 수정하지 않습니다. 코멘트와 지역 카테고리 설정은 그대로 유지됩니다. 저장 후에는 제어판이 재시작되며, 세션 전체에 언어를 적용하려면 로그아웃 후 다시 로그인해야 합니다. 설정되지 않은 사용자는 영어를 사용합니다. 상속된 환경 변수와 기존 ARGVUS 언어 파일은 이 환경설정을 대체하지 않습니다. 로그인 인사 화면은 사용자의 환경설정이 적용되기 전에 실행되며, 기본적으로 자체 서비스 계정 언어인 영어를 유지합니다.

지역 변형은 정확한 카탈로그가 없는 경우 설치된 해당 언어 카탈로그를 사용합니다. 예를 들어 `es_MX.UTF-8`는 `es-ES`를 사용합니다. `zh-Hans`는 간체 중국어를 선택합니다. 번체 중국어(`zh-Hant`, `zh-TW`, `zh-HK`, `zh-MO`)는 간체 중국어로 자동 매핑되지 않으며, 영어로 대체됩니다.

## 카탈로그 및 기여

소스는 `resources/locales/<locale>/<domain>.json` 리포지토리의 `argvus`에 있습니다. 설치된 카탈로그는 `/usr/share/argvus/i18n/`에 존재합니다. 이들은 마스터 `argvus` 패키지에 포함되어 있습니다. `locale.json`는 식별자와 기본/표시 이름을 제공합니다. 별도의 PO 카탈로그나 필수 온라인 번역 플랫폼은 없습니다.

의미 키를 사용하고, 플레이스홀더 이름, 명령, 옵션, 경로, 단축키를 그대로 유지하십시오. 번역한 조각을 조합하지 말고 전체 메시지를 번역하십시오. 새로운 표준 키는 모든 10개 언어로 번역이 필요합니다. 각 도메인 내에서 용어 사용을 일관되게 유지하고 특히 인증, 권한, 파괴적 작업과 관련된 번역은 문맥을 검토하십시오.

```sh
argvus i18n list
argvus i18n locale
argvus i18n get common welcome name=Alice
argvus i18n validate
```
`ARGVUS_I18N_DIR`는 개발 및 단계별 패키지 검사를 위해 대체 카탈로그 루트를 선택합니다. 검증은 도메인, 키, 문자열 값, 플레이스홀더, 빈 번역 및 로케일별 정수 복수형을 확인합니다. 검증은 언어적 정확성이 아니라 구조적 무결성을 입증합니다.

## 유니코드 및 글꼴

`argvus-fonts`는 라틴, 기호 및 이모지 계열 외에도 Noto CJK 글꼴이 필요합니다. Fontconfig는 사용자가 선택한 기본 글꼴을 대체하지 않고 중국어, 일본어 및 한글에 대한 대체 글꼴을 제공합니다. 애플리케이션과 터미널은 여전히 글꼴 대체 기능을 활성화해야 합니다.

공유 Ratatui 텍스트 헬퍼는 터미널 셀을 측정하고, 잘림(truncation) 동안 확장 그래프 클러스터를 유지하며, 넓은 텍스트를 줄바꿈합니다. 텍스트 편집기는 전체 그래프를 이동하거나 삭제합니다. 극히 좁은 영역에서는 한 셀에 두 셀짜리 글리프를 표시할 수 없으며, 이 경우 하드 랩(hard-wrap) 헬퍼는 대체 문자를 사용합니다. 이모지와 모호한 너비 문자는 터미널/폰트 구현에 따라 여전히 다를 수 있습니다. 터미널의 너비 정책은 Ratatui의 일반 유니코드 너비와 일치해야 합니다.

언어 선택은 입력기를 설치하거나 키보드 레이아웃을 변경하지 않습니다. 중국어, 일본어 또는 한국어를 입력할 때는 Wayland 호환 입력기를 사용하세요.
