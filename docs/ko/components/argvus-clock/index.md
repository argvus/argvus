ARGVUS 시계는 현재 시간과 시간 도구들인 세계 시계, 스톱워치, 카운트다운 타이머 및 알람을 제공하는 GTK 4 애플리케이션입니다. 런처에서 열거나, 작업 표시줄의 시간을 클릭하거나, **SUPER + Shift + C**를 누르거나 다음 방법으로 열 수 있습니다:

```sh
argvus clock                     # open the popup near the pointer
argvus clock --toggle            # hide the popup if it is visible, show it otherwise
argvus clock --toggle --x 1600 --y 30  # open next to a taskbar click position
argvus clock --page alarms       # open on a page: clock, world, stopwatch, timer, alarms
argvus clock --background        # run without a window, to keep alarms active
```
ARGVUS 시계는 작업 표시줄과 정렬된 팝업으로 열리며 4픽셀 간격이 있습니다. 작업 표시줄은 루트 클릭 좌표를 전달하므로 팝업이 클릭된 모니터를 사용합니다. 좌표 없이 실행하면 포인터 위치를 사용합니다. 포인터가 팝업 외부에 5초 동안 머물면 자동으로 닫히며, 포인터를 팝업 안으로 이동하면 카운트다운이 취소됩니다. 주요 탭에서 **Esc**를 누르면 즉시 숨겨지고, 전체 페이지에서 **Esc**를 누르면 이전 탭으로 돌아갑니다. `argvus --clock`는 별칭입니다. 작업 표시줄에서 날짜를 클릭하면 여전히 달력이 열리며, ARGVUS 시계는 이벤트를 표시하지 않습니다.

ARGVUS Focus, ARGVUS 시계 및 제어판은 동일한 화면 가장자리를 공유합니다. 시계를 열면 먼저 Focus와 제어판이 닫히고, 이들 표면 중 하나를 열면 시계가 닫힙니다.

## 페이지

- **시계**: 큰 숫자로 표시되는 시간(기본 24시간제, 설정에서 12시간제 선택 가능, 초 표시 선택 가능), 현지 날짜, 현지 시간대와 UTC 오프셋, 다음 알람.
- **세계**: 도시 이름이나 IANA 시간대를 검색하여 추가 가능(강세 및 대소문자 무시). 각 도시는 시간, 현지와의 시간 차이, 그리고 어제, 오늘, 내일 여부를 표시합니다. 일광 절약 시간은 IANA 시간대 데이터베이스에서 가져오며, 고정 오프셋으로 계산되지 않습니다. 도시는 순서를 바꾸거나 제거할 수 있습니다.
- **스톱워치**: 시작, 일시정지, 재개, 초기화, 랩 기록(랩 시간과 총 시간).
- **타이머**: 시간, 분, 초 설정 또는 미리 설정된 5, 10, 15, 25, 30, 60분 선택 가능. 일시정지, 재개, 다시 시작, 취소 가능. 종료 시 알람처럼 울립니다. 이 타이머는 ARGVUS Focus 세션과 독립적입니다.
- **알람**: 알람을 생성, 편집, 켜기 및 끄기, 삭제할 수 있습니다. 각 알람에는 시간, 선택적인 이름, 반복 요일(없으면 한 번만 울림), 소리, 스누즈 길이가 있습니다.

키보드: **Ctrl+1**에서 **Ctrl+5**까지 페이지 전환, **Ctrl+N** 알람 생성, **Ctrl+,** 설정 열기, **Esc** 뒤로 가기, **Ctrl+W** 창 닫기, **Ctrl+Q** 종료.

## 알람 소리

알람은 사용자가 확인할 때까지 실제 소리가 재생됩니다:

- 소리: **Chime**(기본값) 및 **Beacon**, `/usr/share/argvus/sounds/`에 포함.
- **알람 볼륨**(10에서 100, 기본값 80) 및 **알람 소리 듣기**는 설정에서 가능; 편집기에는 선택한 소리를 테스트할 수 있는 버튼이 있음.
- 울리는 알람은 화면 상단, 다른 창 위에 카드와 알림을 표시하며, 둘 다 **스누즈**와 **해제** 기능이 있음. 카드가 선택된 상태에서 **Enter**는 해제, **S**는 스누즈.
- 스누즈는 알람의 스누즈 시간(1~60분, 기본값 10분) 후 다시 울림.
- 응답하지 않은 알람은 **알람 중지 시간**(5, 10, 15, 30분 중 하나, 기본값 10분) 후 멈추고 알림을 남김.
- 동시에 두 개의 알람이 울려도 둘 다 목록에 표시되며, 두 번째 알람이 첫 번째 알람을 끄지는 않음.
- 소리를 재생할 수 없으면 카드와 창에 오류와 함께 표시되며, 오류가 기록됨. ARGVUS Clock은 재생되지 않은 소리를 보고하지 않음.

재생은 GTK의 미디어 지원(GStreamer)을 사용하므로 PipeWire, PulseAudio 또는 ALSA와 함께 작동합니다. 이 패키지는 `gst-plugins-base`(Ogg Vorbis) 및 `gst-plugins-good`(오디오 출력)에 의존합니다.

## 알람이 울릴 때

알람은 ARGVUS Clock이 세션에서 실행 중일 때만 울립니다:

- 창을 닫아도 알람, 실행 중인 타이머 또는 실행 중인 스톱워치가 필요할 때 ARGVUS Clock은 계속 실행됩니다 (**창을 닫아도 실행 유지**, 기본값으로 켜짐). 대기 중인 항목이 없으면 종료됩니다.
- **세션 시작 시 실행**은 로그인 후 argvus clock --background를 실행하는 사용자 단위 `argvus-clock.service`를 활성화합니다. 기본값은 꺼짐입니다.
- 사용자가 로그아웃했거나, 컴퓨터가 꺼져 있거나, 절전 모드일 때는 알람이 울릴 수 없습니다.
- 알람은 최대 5분 늦게 감지되어도 여전히 울립니다. 그보다 늦으면(시계가 실행되지 않았거나 시스템이 절전 모드이거나 꺼져 있었던 경우) 울리지 않으며, 알람 페이지와 알림에서 **놓침**으로 표시됩니다. 반복 알람은 다음 날로 계속 진행되며, 일회성 알람은 꺼집니다. 
- 각 알람 발생은 울리기 전에 처리된 것으로 저장되므로, ARGVUS 시계를 다시 열어도 같은 알람이 두 번 울리지 않으며, 세션당 한 번만 실행됩니다.
- 반복 알람은 선택한 요일의 현지 시간으로 계산되므로 서머타임 변경에도 시간을 유지합니다. 봄철 변경으로 건너뛴 시간은 공백 뒤 첫 번째 분에 울리며, 두 번 발생하는 시간은 첫 번째에 울립니다.
- 타이머는 시스템이 일시 중지 상태일 때도 계속 카운트됩니다. 시스템이 절전 모드일 때 종료되었다면, 깨어날 때 울리며 얼마나 늦었는지 표시합니다. ARGVUS 시계를 닫은 후에는 실행 중인 타이머나 스톱워치는 일시 중지 상태로 복귀합니다.

## 경로

| 경로 | 내용 |
| --- | --- |
|  `argvus clock --background` `$XDG_CONFIG_HOME/argvus/data/clock/settings.json` | 설정 및 세계 시계 |
| `$XDG_DATA_HOME/argvus/clock/alarms.json` | 알람 |
| `$XDG_STATE_HOME/argvus/clock/timers.json` | 타이머 및 스톱워치 체크포인트 |
| `/usr/lib/systemd/user/argvus-clock.service` | 세션 시작 시 |
| `/usr/share/argvus/sounds/` | 패키지된 사운드 |

파일은 원자적으로 작성됩니다; 읽을 수 없는 파일은 `<name>.corrupt-<time>`로 이름이 변경되며 기본값이 사용됩니다. 색상은 활성 ARGVUS 테마 및 강조 색상(테마 소비자 `time`)을 따릅니다. 문자열은 `clock` 및 `time` 번역 도메인에서 가져옵니다.

태스크바 달력, ARGVUS 포커스, ARGVUS 시계 및 제어판은 상호 배타적입니다: 하나를 열면 다른 것은 닫힙니다.
