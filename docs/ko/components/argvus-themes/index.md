ARGVUS의 테마는 데스크탑 전반에서 사용되는 색상, 표면, 기본 배경화면 및 레이아웃 구성을 설정합니다: Hyprland, Waybar, 제어판, 작업 표시줄, 잠금 화면, 알림 및 ARGVUS 애플리케이션. 이 가이드는 사용자가 테마를 다루는 데 필요한 모든 내용을 다룹니다.

## 테마에 포함된 내용

각 공식 테마는 두 가지 모드를 가진 완전한 시각적 아이덴티티입니다:

- **Sticky** — 작은 창 간격과 외부 간격이 없는 컴팩트한 레이아웃, 화면 가장가에 가까운 작업 표시줄.
- **Spaced** — 더 넓은 간격, 둥근 모서리, 작업 표시줄과 셸 표면 주변의 여백이 있는 공간감 있는 레이아웃.

테마를 선택한다고 해서 아이덴티티가 변경되는 것은 아닙니다: 팔레트, 기본 강조 색상 및 배경화면 연관은 모드 간에 동일하게 유지됩니다. 모드는 별도의 설정이며, 자세한 내용은 [공식 테마](/docs/components/argvus-themes/official-themes/)를 참조하세요.

## 이 가이드의 페이지

- [테마 설치](/docs/components/argvus-themes/installing-themes/) — 공식 테마가 어디서 오는지와 `pacman`를 사용하여 하나 또는 모든 테마를 설치하는 방법.
- [공식 테마](/docs/components/argvus-themes/official-themes/) — 카탈로그, 각 테마의 기본 강조 색상, 테마와 모드를 선택하는 방법.
- [강조 색상 사용자 지정](/docs/components/argvus-themes/highlight-color/) — 테마와 독립적으로 강조 색상을 변경.
- [테마 가져오기 및 내보내기](/docs/components/argvus-themes/import-and-export/) — 활성 테마를 강조 색상 및 배경화면과 함께 내보내어 나만의 테마로 만들고 다른 컴퓨터에서 가져오기.

| Sticky와 Spaced 전환 | **제어 센터 → 외관 → 모드** |

| 키보드에서 테마 선택기 열기 | `SUPER + SHIFT + T` |

## 테마 출처

ARGVUS는 `argvus-appearance` 패키지와 함께 두 가지 기본 테마, **ARGVUS Dark**와 **ARGVUS Light**를 제공합니다. 다른 모든 공식 테마는 별도의 `argvus-theme-<name>` 패키지입니다. 테마 패키지를 설치하면 테마 선택기에 추가되며, 세션을 다시 시작할 필요는 없습니다. 내보내거나 가져온 사용자 자신의 테마는 **사용자 테마**로 별도로 나열됩니다.

## 키보드 힌트

제어 센터 테마 페이지는 푸터에 키를 표시합니다:

- `↑` / `↓` — 탐색.
- `Enter` — 적용 또는 열기.
- `e` — 활성 테마 내보내기, 테마 페이지에서.
- `i` — 테마 가져오기, 테마 페이지에서.
- `d` — 사용자 테마 삭제.
- `Esc` — 뒤로 가기.

## 문제 해결

- **내가 설치한 테마가 나타나지 않습니다.** `pacman -Q argvus-theme-<name>`로 패키지가 설치되었는지 확인한 다음, 제어 센터를 다시 엽니다. 패키지는 `argvus-appearance`이 있는 상태로 설치되어야 합니다.
- **테마를 전환한 후 강조 색상이 변경되었습니다.** 사용자 지정 강조 색상은 테마 전환 시 유지됩니다. **테마 기본값으로 재설정**을 사용하여 테마 고유의 색상을 되돌리세요.
- **가져오기할 테마 아카이브가 목록에 없습니다.** 홈 디렉토리에 직접 있어야 하며, `<id>/theme.toml`을 포함해야 합니다. [테마 가져오기 및 내보내기](/docs/components/argvus-themes/import-and-export/)를 참조하세요.
