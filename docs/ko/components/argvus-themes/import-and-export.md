수출(import)과 수입(export)은 공식 테마와 동일한 형식의 **테마**와 함께 작동합니다. 내보내기는 활성 테마를 저장하며, 강조 색상과 배경 화면을 포함하여 사용자의 새로운 테마로 저장됩니다. 가져오기는 테마 아카이브를 사용자의 테마에 설치합니다. 둘 다 **제어 센터 → 모양 → 테마**에서 이루어지며, 사용자 테마는 **사용자 테마**에 나열됩니다.

## 내보낸 테마가 포함하는 것

아카이브 `argvus-theme-<id>.tar.gz`은 하나의 테마 디렉터리를 포함하며, 공식 테마처럼 배치되어 있습니다:

```text
<id>/theme.toml        the manifest (schema 2): name, category, palette, wallpaper
<id>/appearance.json  your visual settings, including layout, effects, fonts and panel presentation
<id>/effects.conf     per-surface effect values for the active theme, when present
<id>/overrides/...     the overrides of the theme it was made from, if any
<id>/wallpaper.<ext>   the wallpaper on screen when you exported
```
매니페스트는 활성 테마를 기반으로 하며, 여기에 귀하의 이름, 새로운 ID, 팔레트 강조 색상으로서의 하이라이트 색상, 그리고 그 옆의 배경화면이 포함됩니다. 외관 프로필은 윈도우 간격, 테두리, 작업 표시줄 여백, 패널 표시, 색상, 효과 및 글꼴을 포함하여 현재 ARGVUS에서 적용된 시각적 설정을 그대로 보존합니다. 사용자 지정 배경화면과 강조 색상은 테마와 함께 저장됩니다. 어떤 테마를 적용하면 해당 테마의 전체 프로필(프로필이 없으면 ARGVUS 기본값)이 다시 적용되며, 마지막으로 적용된 이후 독립적으로 변경된 시각적 설정은 교체됩니다. Sticky 또는 Spaced 모드를 전환하면 항상 해당 모드의 창 및 작업 표시줄 배치가 다시 적용됩니다. 개인 배치를 유지하려면 내보낸 사용자 지정 테마에 저장하세요. 오디오, 키보드 및 네트워크 환경과 같은 비시각적 설정은 테마에 포함되지 않습니다.

적용된 외관은 세션 재시작 및 재로드 시에도 유지됩니다. 세션 준비는 원래 테마의 기하학적 구조를 복원하지 않고 현재 구성에서 필요한 파일을 다시 빌드합니다.

테마를 적용한 후 변경한 설정은 다음 테마나 모드 변경 시 일시적으로 유지됩니다. 현재 시각적 구성을 보존하려면 **제어 센터 → 외관 → 테마 → 테마 내보내기**에서 테마를 내보낸 후, 나중에 내보낸 테마를 적용하여 복원할 수 있습니다.

테마는 `~/.local/share/argvus/themes/<id>/`에 설치됩니다. 거기에 아카이브를 추출하면 테마도 설치됩니다.

## 활성 테마 내보내기

1. **제어 센터 → 외관 → 테마**를 엽니다.
2. 테마 페이지에서 **테마 내보내기**를 선택하거나 `e`를 누릅니다.
3. 테마 이름을 입력합니다. 필드에는 작성될 파일이 표시됩니다.
4. `Enter`를 누릅니다.

ID는 이름으로 만들어집니다: 소문자, 숫자 및 하이픈. ID가 이미 설치된 테마나 홈 디렉토리의 아카이브에서 사용 중인 경우, `-2`, `-3` 등과 같이 추가됩니다. 아카이브는 홈 디렉토리에 작성되며, 예를 들어 `~/argvus-theme-my-theme.tar.gz`입니다. ARGVUS는 테마를 작성하기 전에 확인합니다: 매니페스트가 로드되어야 하고, 모든 구성 요소가 두 모드에서 렌더링되어야 합니다. 

## 테마 가져오기

1. `.tar.gz` 아카이브를 홈 디렉토리(`~`)로 복사합니다. ARGVUS는 그곳에서 테마를 포함하는 아카이브를 나열합니다.
2. **제어 센터 → 외관 → 테마 → 테마 가져오기**를 열거나, 테마 페이지에서 `i`를 누릅니다.
3. 아카이브를 선택하고 `Enter`를 누릅니다.

ARGVUS는 설치하기 전에 아카이브를 검사합니다. 아카이브는 `theme.toml`을 포함한 단일 디렉터리를 보유해야 하며, 상대 경로만 허용됩니다(`..` 없음, 링크 없음). 최대 128개의 항목과 각 파일에 대한 크기 제한이 있습니다. ID는 디렉터리와 일치해야 하며, 바탕화면은 아카이브에 있어야 하고 모든 구성 요소는 두 가지 모드에서 렌더링되어야 합니다. 포함된 외형 프로필은 지원되는 섹션을 사용하고 유효한 JSON이어야 합니다. 검사가 실패하면 아무것도 설치되지 않습니다.

테마는 **사용자 테마(Custom Themes)**에 추가됩니다. 가져오기만으로는 적용되지 않으며, 적용 시점을 사용자가 선택합니다.

### 이름 충돌

- 테마 중 하나가 동일한 ID를 가진 경우, ARGVUS는 **같은 ID의 테마를 교체하시겠습니까?**라고 묻습니다. 교체하려면 **교체(Replace)**를 선택하고, 자신의 테마를 유지하려면 `Esc`를 누르세요. 교체된 테마는 새 테마가 설치될 때까지 백업으로 보관됩니다.
- 공식 테마의 ID를 가진 아카이브는 거부됩니다. 다른 이름으로 다시 내보내세요.

## 사용자 테마 적용

1. **제어판 → 모양 → 테마 → 사용자 정의 테마**를 엽니다.
2. 테마를 선택하고 `Enter`를 누릅니다.

테마의 완전한 내보낸 구성(배경 화면, 간격, 테두리, 강조 색상, 효과, 글꼴 및 패널 표시)이 적용됩니다. 시각적 값이 현재 설정을 대체합니다. 그 후 ARGVUS는 작업 표시줄, Hyprland 재시작 서비스, 배경 화면 및 제어판을 다시 시작하여 각 화면에 사용자 정의 테마가 적용되도록 합니다.

## 사용자 정의 테마 삭제

1. **제어판 → 모양 → 테마 → 사용자 정의 테마**를 엽니다.
2. 테마를 선택하고 `d`를 누릅니다.
3. `y`로 확인하거나 `n` 또는 `Esc`를 눌러 취소합니다.

테마 디렉토리가 `~/.local/share/argvus/themes`에서 제거됩니다. 활성 테마인 경우 ARGVUS가 먼저 **ARGVUS Dark**로 전환합니다.

## 이전 버전의 프로필

이전 버전은 *테마 프로필*(`profile.tar.gz`), 즉 모양 설정의 복사본을 내보냈습니다. 테마 페이지가 처음 열릴 때, `~/.local/share/argvus/themes/<name>/`의 각 프로필은 기본 테마에서 만들고 강조 색과 배경 화면을 적용한 테마로 변환됩니다. 원래 프로필과 이전 `custom-themes.json` 목록은 `~/.config/argvus/data/backups/theme-profiles-<seconds>/`로 이동하며, 상태 표시줄에 변환이 보고됩니다. 기본 테마가 설치되지 않은 프로필은 백업으로만 이동됩니다.

## 테마 공유하기

내보낸 테마는 일반 아카이브입니다. 이를 ARGVUS가 실행되는 다른 컴퓨터로 복사하고 그곳에서 가져오면 됩니다.

## 문제 해결

- **아카이브가 나열되지 않았습니다.** 아카이브는 홈 디렉토리 안에 직접 있어야 하며, `.tar.gz`로 끝나고 `<id>/theme.toml`를 포함해야 합니다.
- **가져오기가 거부되었습니다.** 상태 줄에 이유가 나와 있습니다: 동일한 ID를 가진 공식 테마, 누락된 배경화면, 로드되지 않는 매니페스트 또는 렌더링되지 않는 구성 요소.
- **내보내기가 거부되었습니다.** 이름에는 최소한 한 글자 또는 숫자가 있어야 하며, 활성 테마가 설치되어 있어야 합니다.
