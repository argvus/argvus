---
**하이라이트 색상**은 데스크탑 전반에서 포커스 테두리, 선택 및 활성 상태에 사용되는 강조 색상입니다. 모든 테마에는 기본 하이라이트 색상이 있지만, 테마를 변경하지 않고도 원하는 색상으로 대체할 수 있습니다.

## 하이라이트 색상 변경

1. **제어 센터 → 외관 → 하이라이트 색상**을 엽니다.
2. **하이라이트 색상 편집**을 선택합니다. 현재 값은 옵션 옆에 표시됩니다.
3. 선행 `#`가 있든 없든, 여섯 자리 RGB 색상을 입력합니다. 예를 들어 `3590BD`와 `#3590BD` 모두 허용됩니다.
4. 적용하려면 `Enter`을 누릅니다.

색상을 필드에 붙여넣을 수도 있습니다. ARGVUS는 붙여넣은 텍스트가 유효한 여섯 자리 RGB 값일 때만 허용합니다. `#123`와 같은 단축형이나 16진수가 아닌 문자가 포함된 값은 오류 메시지가 표시되며 색상은 변경되지 않습니다.

새 색상은 즉시 데스크탑에 적용되며 ARGVUS 구성에 저장됩니다.

## 테마 기본값으로 되돌리기

선택한 테마에 정의된 색상으로 돌아가려면 **제어 센터 → 모양 → 강조 색상**을 열고 **테마 기본값으로 재설정**을 선택하세요.

## 강조 색상이 테마와 상호 작용하는 방식

- 선택한 강조 색상은 독립적인 재정의입니다. 다른 테마로 전환해도 유지되므로 선택한 색상은 동일하게 유지됩니다.
- **테마 기본값으로 재설정** 후 적용한 테마는 강조 색상을 다시 이어받아 자체 기본값을 사용합니다.
- 활성 테마를 내보내면 새 테마 팔레트의 악센트로 내보낼 때 활성화된 강조 색상이 저장됩니다. [테마 가져오기 및 내보내기](/docs/components/argvus-themes/import-and-export/).

## 값이 저장되는 곳

하이라이트 색상은 `$XDG_CONFIG_HOME/argvus/config.json`(보통 `~/.config/argvus/config.json`)에 있는 ARGVUS 구성의 일부입니다. `$XDG_CONFIG_HOME/argvus/data/generated` 아래의 생성된 파일을 편집하지 마세요: ARGVUS가 구성에서 이들을 다시 작성합니다.
