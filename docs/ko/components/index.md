---
title: 구성 요소
description: 이 사이트에 문서화된 ARGVUS 구성 요소와 해당 개발자 메모가 위치한 곳.
---
이 구성 요소들은 `argvus` 작업 공간으로 통합되었습니다. 그들의 사용자 페이지는 여기에 나와 있으며; 개발자 노트는 `docs/internal/`에 있습니다.

| 구성 요소 | 명령 | 페이지 |
| --- | --- | --- |
| 계정 | `argvus accounts` | [Accounts](/docs/components/argvus-accounts/) |
| 제어 센터 | `argvus control-center` | [Control Center](/docs/components/argvus-control-center/) |
| ARGVUS 환영 | `argvus welcome` | [ARGVUS Welcome](/docs/components/argvus-control-center/#argvus-welcome) |
| 국제화 | `argvus i18n` | [Internationalization](/docs/components/argvus-i18n/) |
| 터미널 | `argvus terminal` | [Terminal](/docs/components/argvus-terminal/) |
| 시스템 모니터 | `argvus system-monitor` | [System monitor](/docs/components/argvus-system-monitor/) |
| 디스크 사용 분석기 | `argvus du` | [ARGVUS Disk Usage Analyzer](/docs/components/argvus-du/) |
| 네트워킹 및 블루투스 | `argvus network`, `argvus bluetooth` | [네트워킹 및 블루투스](/docs/components/argvus-network/) |
| 로그인 (greetd) | `argvus greeter` | [그리터](/docs/components/argvus-greeter/) |
| 달력 | `argvus taskbar-calendar` | [달력](/docs/components/argvus-taskbar-calendar/) |
| 이동식 장치 | `argvus removable-devices` | [이동식 장치](/docs/components/argvus-removable-devices/) |
| 집중 (포모도로) | `argvus focus` | [ARGVUS 집중](/docs/components/argvus-focus/) |
| 시계, 타이머 및 알람 | `argvus clock` | [ARGVUS 시계](/docs/components/argvus-clock/) |
| 테마 | `argvus theme-switch` | [테마](/docs/components/argvus-themes/) |
| 키 | `argvus keys`, `argvus gpg` | [키](/docs/components/argvus-keys/) |
| 프로젝트 | `argvus projects` | [프로젝트](/docs/components/argvus-projects/) |
| 위젯 원격 측정 | `argvus widget-telemetry` | [위젯 원격 측정](/docs/components/argvus-widget-telemetry/) |
| 로딩 오버레이 | `argvus loading-theme` | [로딩 오버레이](/docs/components/argvus-loading-theme/) |
| 스네이크 | `argvus game-snake` | [스네이크](/docs/argvus-games/snake/) |
| AI 에이전트 | `argvus-ai menu` | [AI 에이전트](/docs/argvus-ai/) |

명령 참조는 [명령줄](/docs/reference/command-line/) 에 있습니다.

루트 Btrfs 스냅샷은 [스냅샷](/docs/components/argvus-control-center/#snapshot) 에서 확인하세요.
