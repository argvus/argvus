---
title: 이동식 장치
description: ARGVUS에서 이동식 저장 장치를 마운트하고 관리합니다.
---
`argvus-removable-devices`는 UDisks2를 감시하며 ARGVUS 작업 표시줄 저장소 모듈과 그 장치 메뉴를 제공합니다. 이 메뉴는 별도의 Rofi 스타일 인터페이스로도 제공되므로, 작업 표시줄이나 실행기 워크플로우에서 동일한 장치 작업을 사용할 수 있습니다.

사용 가능한 작업은 `open`, `mount`, `unmount`, `eject`, `poweroff`, `lock`, `unlock` 및 `copy`입니다. `list`, `watch` 및 `menu` 명령은 통합을 위한 해당 상태, 작업 표시줄 스트림 및 메뉴 인터페이스를 노출합니다.

## 작업 표시줄 메뉴

`"mode": "gui"`(시스템 기본값)을 사용하면, 작업 표시줄 저장소 아이콘을 클릭하면 달력 팝업과 유사하게 ARGVUS 작업 표시줄에 첨부된 GTK 메뉴가 열립니다. 작업 표시줄이 화면 상단에 있을 때는 바 아래에, 하단에 있을 때는 위에 표시됩니다. 각 장치 행에는 상태가 허용하는 작업만 포함된 작업 하위 메뉴가 있습니다.

- **포인터:** 장치 행 위에 마우스를 올리거나 클릭하면 하위 메뉴가 열립니다. 포인터가 메뉴 가장자리를 지나거나 메뉴를 벗어나도 하위 메뉴는 열려 있으며, 포인터가 잠시 다른 행에 머물러야만 해당 행의 하위 메뉴로 이동하므로 대각선 경로로 접근해도 메뉴가 닫히지 않습니다. 두 메뉴 외부를 클릭하면 팝업이 닫힙니다.
- **키보드:** `Up`/`Down`는 행을 선택하고, `Right`, `Enter` 또는 `Space`는 하위 메뉴를 열거나 (**새로 고침**/**종료**)를 실행하며, `Enter` 또는 `Space`는 선택된 작업을 실행하고, `Left` 또는 `Escape`는 장치 목록으로 돌아가며, `Escape`는 거기에서 팝업을 닫습니다.

**경로 복사**는 `copy_command` (기본값 `wl-copy`, `wl-clipboard`에서)을 통해 마운트 지점을 클립보드에 복사하므로 메뉴를 닫은 후에도 경로가 남아 있습니다; `show_notification`가 켜져 있으면 알림이 표시됩니다. **잠금**은 모든 잠금 해제된 암호화 볼륨에 제공되며, 필요한 경우 먼저 이를 마운트 해제합니다.

기본 파일 관리자 동작은 ARGVUS 제어 센터에서 선택된 파일 관리자를 따릅니다. 이는 이동식 장치 동작을 사용자의 애플리케이션 기본값과 일관되게 유지합니다.

시스템 구성은 `/etc/argvus/removable-devices/config.json`입니다. ARGVUS로 관리되는 사용자별 프로젝션은 `~/.config/argvus/data/removable-devices/config.json`이며, 그 옆에 일치하는 `theme.css`가 있습니다. 해당 스타일시트는 표준 테마, 강조 색상, 모드에서 `~/.config/argvus/data/generated/removable-devices/theme.css`로도 프로젝션되며, 전용 이동식 장치 자산을 제공하지 않는 테마에는 패밀리/변형 폴백(fallback)을 적용하여 테마 변경 시 수동 단계 없이 모듈을 일관되게 유지합니다. 레거시 구성요소 경로는 마이그레이션 입력이며, 이후 사용자 구성은 시스템 기본값을 재정의합니다.

유용한 설정에는 장치가 없을 때 모듈이 숨겨지는지 여부(`hide_when_empty`), 이름과 용량이 표시되는지 여부, 장치 정렬 순서, 알림 동작, 메뉴 백엔드 및 상태 아이콘이 포함됩니다. 스타일시트는 활성 ARGVUS 테마(테마 빌드의 `removable-devices/theme.css`)에서 렌더링되며, 테마 또는 강조 색상 변경 시마다 패널의 `theme.css`에 복사됩니다.

인터페이스는 $XDG_CONFIG_HOME/locale.conf의 `LANG`에서 사용자의 언어를 사용하며, 구성되지 않은 사용자에 대해서는 기본값으로 영어를 사용합니다. 상속된 로케일 변수는 인터페이스 언어를 선택하지 않습니다.

## 공유 언어 카탈로그

인터페이스는 모든 10개 언어에 대해 공유  `$XDG_CONFIG_HOME/locale.conf` `argvus-i18n` 카탈로그를 사용합니다. 텍스트는 마스터 작업 공간의 `resources/locales/<locale>/removable-devices.json`에 저장되며 `argvus`에 의해 설치됩니다. 영어가 기본 언어이며, 새로운 언어는 더 이상 로컬 이중 언어 사전을 필요로 하지 않습니다.
