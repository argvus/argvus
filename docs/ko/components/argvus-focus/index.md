ARGVUS Focus는 휴식 시간으로 나누어진 집중 세션에서 작업할 수 있는 GTK 4 애플리케이션입니다. 작업 표시줄 옆에 팝업으로 열립니다. 런처에서 열거나, 작업 표시줄 표시기를 클릭하거나, **SUPER + Shift + F**를 사용하거나 다음으로 열 수 있습니다:

```sh
argvus focus              # open the popup near the pointer
argvus focus --toggle     # hide the popup if it is visible, show it otherwise
argvus focus --toggle --x 1600 --y 30  # open next to a taskbar click position
argvus focus --start      # start or resume the current phase without opening the window
argvus focus --pause      # pause the running phase
argvus focus status --waybar         # print one Waybar JSON status and exit
argvus focus status --waybar --follow  # stream status changes for Waybar
```
작업 표시줄은 루트 클릭 좌표를 전달하므로 팝업이 클릭된 모니터를 사용하고 표시줄에 맞춰 정렬됩니다; 좌표 없이 실행하면 포인터 위치를 사용합니다. 포인터가 팝업 외부에 5초 동안 머물면 자동으로 닫히며; 포인터를 팝업 안으로 이동시키면 그 카운트다운이 취소됩니다. 메인 페이지에서 **Esc**를 누르면 여전히 즉시 숨기고, 하위 페이지에서 **Esc**를 누르면 이전 페이지로 돌아갑니다. 작업 표시줄 표시기는 유휴 상태에서는 아이콘만 표시하고, 단계 동안에는 남은 `MM:SS`와 단계 색상을 표시합니다; 일시 정지된 단계는 남은 시간을 유지하고 일시 정지 상태를 추가합니다. `status` 명령은 GTK를 시작하지 않고 `argvus` 내부에서 실행됩니다. `argvus --focus`는 별칭입니다. 한 세션당 Focus 인스턴스는 하나만 실행되며, 두 번째 실행 시 옵션을 이미 실행 중인 인스턴스에 전달합니다.

ARGVUS Focus, ARGVUS Clock 및 제어판은 동일한 화면 가장자리를 공유합니다. Focus를 열면 먼저 Clock과 제어판이 닫히며, 이 중 어느 하나를 열면 Focus가 닫힙니다.

## 세션

- **뽀모도로(Pomodoro)** 모드는 집중과 짧은 휴식을 번갈아 진행하며, 각 사이클이 끝나면 긴 휴식으로 마무리됩니다. 기본 시간은 집중 25분, 짧은 휴식 5분, 긴 휴식 15분이며, 4번의 집중 세션 후에 긴 휴식이 있습니다. 
- **단일 세션** 모드는 휴식 없이 자체 길이(기본 45분)의 집중 세션을 하나 실행합니다.
- 창에는 단계(집중, 짧은 휴식, 긴 휴식, 각각의 색상 표시), 남은 시간(진행 링 안에 표시), 사이클 위치 및 오늘의 총 시간이 표시됩니다.
- **집중 시작 / 휴식 시작**, **일시 정지**, **이어하기**, **세션 취소**(단계를 포기하고 기록하지 않음), **지금 완료**(집중 세션을 조기 종료하고 실제로 보낸 시간을 기록) 기능이 있습니다. 휴식 중에는 **휴식 건너뛰기**를 눌러 집중으로 돌아갈 수 있습니다.
- 단계가 끝나면 다음 단계가 사용자를 기다립니다. 단, **휴식을 자동으로 시작** 또는 **휴식 후 집중을 자동으로 시작** 옵션이 켜져 있는 경우는 제외됩니다.

키보드: **Space**는 시작 또는 일시정지, **Ctrl+,**는 설정 열기, **Ctrl+H**는 기록, **Esc**는 뒤로 가기, **Ctrl+W**는 창 숨기기, **Ctrl+Q**는 종료입니다.

## 설정

프리셋(클래식 25/5/15, 확장 50/10/30, 딥 워크 90/20/30)은 길이를 채우며, 언제든 편집 가능합니다. 설정에는 긴 휴식 전 세션 수, 자동 시작, 단계 종료 시 알림, 그리고 **세션 소리**가 포함되어 있습니다: 짧은 종소리와 자체 볼륨, **테스트 소리** 버튼. 이러한 소리는 [ARGVUS Clock](/docs/components/argvus-clock/)]의 알람 소리와는 별도입니다.

## 기록

완료된 집중 세션은 시작, 종료 및 소요 시간이 기록됩니다; 휴식과 취소된 세션은 기록되지 않습니다. 기록 페이지에는 오늘 세션과 분, 총합, 최근 세션이 표시됩니다. 365일 이전의 기록은 삭제됩니다. **기록 지우기**는 확인을 요청합니다.

## 창, 배경 및 일시정지

- 사이클 중에 창을 닫으면 단순히 숨기는 것뿐입니다: 세션은 계속 진행되며 단계가 끝나면 알림을 줍니다. 진행 중인 작업이 없으면 창을 닫으면 종료됩니다.
- 단계가 실행되는 동안 시스템이 일시 중지되면, 일시 중지 시점에서 단계가 일시 정지되며, 시스템이 얼마나 오래 절전 상태였는지 메시지가 표시됩니다. 절전 상태는 집중 시간으로 계산되지 않습니다.
- 세션은 변경될 때와 30초마다 저장됩니다. 단계 중에 ARGVUS Focus가 종료되면(로그아웃, 크래시, **Ctrl+Q**), 다음에 열 때 해당 지점에서 일시 정지된 상태로 돌아옵니다; 타이머가 알림을 줄 수 없는 동안 계속 실행된 척하지 않습니다.
- 시간은 시스템 부팅 시간 기준 시계로 측정되므로, 벽시계나 시간대를 변경해도 단계의 길이가 줄거나 늘어나지 않습니다.

## 경로

| 경로 | 내용 |
| --- | --- |
| `$XDG_CONFIG_HOME/argvus/data/focus/settings.json` | 설정 |
| `$XDG_DATA_HOME/argvus/focus/history.json` | 완료된 세션 |
| `$XDG_STATE_HOME/argvus/focus/session.json` | 현재 세션의 체크포인트 |
| `/usr/share/argvus/sounds/argvus-bell.oga` | 세션 알림 |

파일은 원자적으로 작성됩니다. 읽을 수 없는 파일은 `<name>.corrupt-<time>`로 이름이 변경되며 기본값이 사용됩니다; 파일이 어디로 갔는지 알려주는 메시지가 표시됩니다.

색상은 활성 ARGVUS 테마와 강조 색상을 따릅니다(테마 소비자 `time`). 문자열은 `focus` 및 `time` 번역 도메인에서 가져옵니다.

작업 표시줄 달력, ARGVUS 집중, ARGVUS 시계 및 제어판은 상호 배타적입니다: 하나를 열면 다른 것들은 닫힙니다.
