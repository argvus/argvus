---
title: 빠른 시작
description: ARGVUS를 한 명령으로 실행하세요.
---
TTY에서 바로 새 Arch Linux 설치에서 ARGVUS를 시도하는 가장 빠른 방법:

```sh
curl -fsSL https://argvus.github.io/install.sh | sh
```
이 단일 명령어는 ARGVUS 저장소 키를 가져오고 서명하며, 패키지 저장소를 구성하고, 패키지 데이터베이스를 업데이트하며, `argvus` 패키지와 해당 종속 항목을 설치합니다.

로그아웃한 후, 디스플레이 관리자에서 **ARGVUS**를 선택하거나 TTY 세션을 시작하면 접속할 수 있습니다.
