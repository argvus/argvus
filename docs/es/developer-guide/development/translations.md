---
title: Traducciones
description: Mantener catálogos de localización compartidos de ARGVUS.
---
`argvus-i18n` posee los catálogos compartidos y el módulo QML. Actualiza los catálogos en inglés y portugués juntos al cambiar el texto visible para el usuario, luego ejecuta:

```sh
argvus i18n validate
```
Los consumidores incluyen aplicaciones nativas de Rust, componentes de shell y ayudantes de sesión.
