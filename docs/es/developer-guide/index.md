ARGVUS es una colección de proyectos empaquetados de manera independiente unidos por configuración compartida, servicios de usuario systemd, contratos Wayland/Hyprland y i18n común.

- [Arquitectura](/docs/developer-guide/architecture/overview/)
- [Subsistemas](/docs/developer-guide/subsystems/session-and-systemd/)
- [Desarrollo](/docs/developer-guide/development/environment/)
- [Referencia](/docs/reference/)

Los repositorios de origen bajo `de/` son los autorizados. Los manifiestos de los paquetes y las unidades instaladas definen el límite de ejecución; los archivos README son complementarios.
