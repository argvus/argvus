---
title: Instalación
description: Instala los paquetes ARGVUS en Arch Linux.
---
ARGVUS se distribuye como paquetes firmados de Arch Linux. El instalador público configura el repositorio de paquetes de ARGVUS; luego, el conjunto de paquetes instala los componentes de escritorio.

Consulte [requirements](/docs/getting-started/installation/requirements/)], siga los [installation steps](/docs/getting-started/installation/install/)], y termine con [first session](/docs/getting-started/installation/first-session/)].

El repositorio de paquetes y el metapaquete `argvus` se mantienen por separado de los paquetes de componentes de escritorio. Consulte la [package matrix](/docs/reference/package-matrix/)] del desarrollador para la propiedad.
