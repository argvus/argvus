Use esta tabla cuando sepas lo que quieres cambiar pero no cuál superficie de ARGVUS lo posee.

Para una revisión guiada de las principales áreas de escritorio, abre **ARGVUS Welcome** con `argvus welcome` o desde **Centro de Control → Herramientas y Diagnósticos**.

## ¿Configuración o acción rápida?

El Centro de Control es el lugar al que acudir cuando quieres que un ajuste permanezca como parte de la configuración de tu escritorio. El Panel de Control es el lugar al que acudir cuando quieres inspeccionar el estado o realizar una acción frecuente de inmediato. Algunas tarjetas del Panel de Control abren los mismos proveedores subyacentes usados por el Centro de Control, pero el panel no es una segunda base de datos de configuraciones.

Si un ajuste no está listado, utiliza la búsqueda de inicio del Centro de Control. Su registro de búsqueda incluye rutas de apariencia visibles para el usuario y los dominios de teclado, entrada, pantalla, red y sesión.
