---
title: Inicio Rápido
description: Haz que ARGVUS funcione con un solo comando.
---
La forma más rápida de probar ARGVUS en una instalación nueva de Arch Linux, directamente desde una TTY:

```sh
curl -fsSL https://argvus.github.io/install.sh | sh
```
Este único comando importa y firma la clave del repositorio ARGVUS, configura el repositorio de paquetes, actualiza la base de datos de paquetes e instala el paquete `argvus` con sus dependencias.

Cierra sesión, selecciona **ARGVUS** en tu gestor de ventanas (o inicia una sesión TTY), y ya estás dentro.
