---
title: Tích hợp
description: Bộ tổng hợp, tích hợp đăng nhập, khóa và cổng thông tin.
---

Cấu hình bộ tổng hợp gói `argvus-hyprland`; Gói `argvus-portal` tích hợp cổng XDG; `argvus-greeter` tích hợp chào mừng; `argvus-lock` tích hợp Hyprlock; lớp phủ tải được cung cấp trong `argvus` tích hợp hình ảnh tải phiên; và `argvus-boot-splash` tích hợp hình ảnh khởi động.
