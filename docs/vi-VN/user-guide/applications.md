- [Trò chơi](/docs/argvus-games/) (bao gồm [Rắn](/docs/argvus-games/snake/))
- [Giám sát hệ thống](/docs/components/argvus-system-monitor/)
- [Ứng dụng mặc định](/docs/components/argvus-control-center/)

Trung tâm điều khiển được mở bằng `argvus --control-center`; trang Ứng dụng của nó quản lý các ứng dụng mặc định.
