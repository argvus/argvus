---
title: Translations
description: الحفاظ على كتالوجات الترجمة ARGVUS المشتركة.
---

تمتلك `argvus-i18n` الكتالوجات المشتركة ووحدة QML. قم بتحديث الكتالوجات الإنجليزية والبرتغالية معًا عند تغيير النص المرئي للمستخدم، ثم قم بتشغيل:

```sh
argvus i18n validate
```

يشمل المستهلكون تطبيقات Rust الأصلية ومكونات الصدفة ومساعدي الجلسة.
