`argvus-hyprland` يحزم تكوين المُركب؛ حزم `argvus-portal` تكامل بوابة XDG؛ `argvus-greeter` يدمج الترحيب؛ `argvus-lock` يدمج Hyprlock؛ يدمج تراكب التحميل الذي يتم شحنه في `argvus` مرئيات تحميل الجلسة؛ و`argvus-boot-splash` يدمج صور التمهيد.
