---
title: مكونات واجهة المستخدم
description: حزم واجهة المستخدم ARGVUS.
---

تتضمن حزم واجهة المستخدم `argvus-control-panel`، و`argvus-taskbar`، و`argvus-launcher`، والأوامر الفرعية `argvus` `argvus control-center` (المساعد في `argvus`)، `argvus taskbar-calendar`، `argvus widget-telemetry`، `argvus terminal`، `argvus system-monitor`، `argvus removable-devices`، `argvus focus` و`argvus clock`. يستخدم التقويم وFocus وClock صندوق `argvus-taskbar-popup` المشترك لتحديد موضع غلاف الطبقة وفصلها؛ يعرض التركيز أيضًا قارئ حالة Waybar الخاص به من خلال مسار `argvus focus status` قيد التشغيل.

يتم توثيق سلوكهم في مواجهة المستخدم من خلال الميزة؛ تسجل هذه الصفحة ملكية الحزمة.
