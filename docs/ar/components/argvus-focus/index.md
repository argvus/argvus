ARGVUS Focus هو تطبيق GTK 4 للعمل في جلسات تركيز مفصولة بفواصل. يتم فتحه كنافذة منبثقة بجوار شريط المهام. افتحه من المشغل، بالنقر فوق مؤشر شريط المهام الخاص به، باستخدام **SUPER + Shift + F**، أو باستخدام:

```sh
argvus focus              # open the popup near the pointer
argvus focus --toggle     # hide the popup if it is visible, show it otherwise
argvus focus --toggle --x 1600 --y 30  # open next to a taskbar click position
argvus focus --start      # start or resume the current phase without opening the window
argvus focus --pause      # pause the running phase
argvus focus status --waybar         # print one Waybar JSON status and exit
argvus focus status --waybar --follow  # stream status changes for Waybar
```

يقوم شريط المهام بتمرير إحداثيات النقر الجذري بحيث تستخدم النافذة المنبثقة الشاشة التي تم النقر عليها وتتماشى مع الشريط؛ الإطلاق بدون إحداثيات يستخدم موضع المؤشر. إذا ظل المؤشر خارج النافذة المنبثقة لمدة 5 ثوانٍ، فسيتم إغلاقه تلقائيًا؛ يؤدي تحريك المؤشر إلى النافذة المنبثقة إلى إلغاء هذا العد التنازلي. لا يزال **Esc** الموجود على الصفحة الرئيسية يخفيه على الفور، ويعود **Esc** الموجود على الصفحة الفرعية إلى الصفحة السابقة. يُظهر مؤشر شريط المهام فقط الرمز الخاص به أثناء الخمول و`MM:SS` المتبقي خلال المرحلة، مع لون المرحلة؛ تحافظ المرحلة المتوقفة مؤقتًا على الوقت المتبقي وتضيف حالة الإيقاف المؤقت. يتم تشغيل الأمر `status` داخل `argvus` دون بدء تشغيل GTK. `argvus --focus` هو اسم مستعار. يتم تشغيل مثيل Focus واحد فقط في كل جلسة: حيث يقوم الإطلاق الثاني بتسليم خياراته إلى المثيل قيد التشغيل.

يشترك كل من ARGVUS Focus وARGVUS Clock ولوحة التحكم في نفس حافة الشاشة. يؤدي فتح التركيز إلى إغلاق الساعة ولوحة التحكم أولاً؛ يؤدي فتح أي من تلك الأسطح إلى إغلاق التركيز.

## الجلسات

- يعمل وضع **بومودورو** على تبديل التركيز والفواصل القصيرة وينهي كل دورة باستراحة طويلة. الأطوال الافتراضية هي 25 و5 و15 دقيقة، مع استراحة طويلة بعد 4 جلسات تركيز.
- يقوم وضع **الجلسة الواحدة** بتشغيل جلسة تركيز واحدة مدتها الخاصة (45 دقيقة افتراضيًا) بدون فترات راحة.
- تعرض النافذة المرحلة (التركيز، استراحة قصيرة، استراحة طويلة، كل منها بلونها الخاص)، والوقت المتبقي داخل حلقة التقدم، والموقع في الدورة وإجمالي اليوم.
- **بدء التركيز / بدء الاستراحة**، **إيقاف مؤقت**، **استئناف**، **إلغاء الجلسة** (ترك المرحلة وعدم تسجيل أي شيء) و **إكمال الآن** (إنهاء جلسة التركيز مبكرًا وتسجيل الوقت المنقضي فعليًا). أثناء فترة الاستراحة، **تخطي الاستراحة** يعود إلى التركيز.
- عندما تنتهي المرحلة، تنتظرك المرحلة التالية، ما لم يتم تشغيل **بدء الفواصل تلقائيًا** أو **بدء التركيز تلقائيًا بعد الاستراحة**.

لوحة المفاتيح: **مسافة** تبدأ أو تتوقف مؤقتًا، **Ctrl+،** تفتح الإعدادات، **Ctrl+H** السجل، **Esc** يعود للخلف، **Ctrl+W** يخفي النافذة و **Ctrl+Q** يخرج.

## التاريخ

يتم تسجيل كل جلسة تركيز مكتملة مع بدايتها ونهايتها والوقت الذي تقضيه؛ فترات الراحة والجلسات الملغاة ليست كذلك. تعرض صفحة السجل جلسات ومحاضر اليوم، والإجماليات والجلسات الأخيرة. يتم إسقاط السجلات الأقدم من 365 يومًا. **مسح السجل** يطلب التأكيد.

## النافذة والخلفية والتعليق

- يؤدي إغلاق النافذة أثناء الدورة إلى إخفائها فقط: تستمر الجلسة ويبلغك عند انتهاء المرحلة. مع عدم وجود أي شيء قيد التنفيذ، يتم إنهاء الإغلاق.
- في حالة توقف النظام أثناء تشغيل مرحلة ما، يتم إيقاف المرحلة مؤقتًا في لحظة الإيقاف، وتظهر رسالة توضح المدة التي نام فيها النظام. لا يتم احتساب النوم ضمن وقت التركيز.
- يتم حفظ الجلسة عند كل تغيير وكل 30 ثانية. إذا تم إغلاق ARGVUS Focus أثناء مرحلة ما (تسجيل الخروج، التعطل، **Ctrl+Q**)، فإنه يعود متوقفًا مؤقتًا عند تلك النقطة في المرة التالية التي يتم فتحه فيها؛ لا يتظاهر أبدًا بأن المؤقت استمر في العمل بينما لم يتمكن من الإخطار.
- يتم قياس الأوقات على ساعة وقت تشغيل النظام، لذا فإن تغيير ساعة الحائط أو المنطقة الزمنية لا يؤدي إلى تقصير أو إطالة المرحلة.## المسارات

| المسار | المحتوى |
| --- | --- |
| `$XDG_CONFIG_HOME/argvus/data/focus/settings.json` | الإعدادات |
| `$XDG_DATA_HOME/argvus/focus/history.json` | الجلسات المكتملة |
| `$XDG_STATE_HOME/argvus/focus/session.json` | نقطة تفتيش الدورة الحالية |
| `/usr/share/argvus/sounds/argvus-bell.oga` | جرس الجلسة |

تتم كتابة الملفات ذريا. تتم إعادة تسمية الملف الذي لا يمكن قراءته إلى `<name>.corrupt-<time>` ويتم استخدام الإعدادات الافتراضية؛ رسالة تخبرك أين ذهبت.

تتبع الألوان سمة ARGVUS النشطة وتسلط الضوء على اللون (مستهلك السمة `time`). تأتي السلاسل من مجالات الترجمة `focus` و`time`.

تقويم شريط المهام وتركيز ARGVUS وساعة ARGVUS ولوحة التحكم يتعارضان: فتح أحدهما يغلق الآخر.
