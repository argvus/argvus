# حاسبة ARGVUS

`argvus calculator` · `SUPER + C` · launcher: **ARGVUS Calculator**

اختر النمط من الإعدادات ← النمط باستخدام ↑/↓ وEnter أو بالنقر على صف. يُحفظ النمط وخياراته فورًا ويُستعاد عند التشغيل التالي. يحتفظ كل نمط بتعبيره أثناء الجلسة. يستبدل Enter أو = التعبير بالنتيجة دون تحديدها مع المؤشر في النهاية.

المعدلات نسب مئوية لكل فترة؛ استخدم الفترة نفسها للمعدل والعدد والدفعة. الدفعات في نهاية الفترة، ويُدعم المعدل صفر. تعيد الفائدة البسيطة والمركبة المجموع المتراكم. التحويل دون اتصال ولا يشمل العملات. يحفظ السجل حتى 100 نتيجة مع النمط والخيارات والمدخلات المالية؛ اختيار نتيجة يستعيد السياق. المسح يفرغ الملف المحفوظ أيضًا.

## الترتيبات

- `s الترتيبات` → **النمط** → أساسي / علمية / البرمجة / مالي / تحويل الوحدات.
- ↑ / ↓ · Enter · Escape / ←.
- **نسخ النتيجة** · **السجل** · **مسح السجل**.
- **أساسي**: 370 × 420; **علمية**: 440 × 640.
- **البرمجة**: 520 × 640; **مالي**: 440 × 640; **تحويل الوحدات**: 440 × 520.

## أساسي / علمية

`+ - * / %` · `50% = 0.5` · `1.5 = 1,5` · `2+2` → Enter → `4` → `+2` → Enter → `6`.

`sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `sqrt`, `log`, `ln`, `exp`, `pi`, `e`, `^`, `(`, `)`.

**وحدة الزاوية**: درجات / راديان. `-2^2 = -4`; `2^3^2 = 512`; `2*pi`.

IEEE 754 / f64 · 15 رقمًا معنويًا · 4096 بايت · 64 مستوى تحليل.

## البرمجة

الافتراضي: عشري، 64 بت بإشارة. تلتف العمليات ضمن عرض الكلمة؛ والإزاحة اليمنى بإشارة تمدد الإشارة. تُقطع القسمة الصحيحة نحو الصفر. القسمة على صفر والإزاحات خارج [0, bits) أخطاء. تستخدم الأعداد بلا بادئة الأساس المختار. تغيير الأساس يحول التعبير الصحيح؛ وتغيير العرض أو الإشارة يعيد تفسير البتات نفسها.

- **الأساس**: 2 / 8 / 10 / 16; **حجم الكلمة (بت)**: 8 / 16 / 32 / 64.
- **بإشارة** / **بلا إشارة** · `0b1010`, `0o12`, `0xA`.
- `+ - * / %`, `AND OR XOR NOT`, `<< >>`, `& | ^ ~`, `(`, `)`.
- `9007199254740993+2 = 9007199254740995`; `0xFF AND 0b1010 = 10` (base 10).
- 8-bit: `255+1 = 0`; `NOT 0 = -1` (بإشارة); `-7/2 = -3`.

## مالي

فائدة بسيطة · فائدة مركبة · دفعة ثابتة · القيمة الحالية · القيمة المستقبلية · التغير النسبي.

- `P`: رأس المال الأولي; `FV`: المبلغ المستقبلي; `A`: الدفعة لكل فترة.
- `r`: المعدل لكل فترة (%) / 100; `n`: عدد الفترات.
- `G=(1+r)^n`; `H=(G-1)/r` (`r=0`: `H=n`).
- فائدة بسيطة: `P*(1+r*n)`; فائدة مركبة: `P*G`.
- دفعة ثابتة: `P*G/H`; القيمة الحالية: `(FV+A*H)/G`; القيمة المستقبلية: `P*G+A*H`.
- التغير النسبي: `(المبلغ النهائي - المبلغ الأصلي) / المبلغ الأصلي * 100`.

## السجل

100 · النمط + `context` · `مسح السجل`.

`$XDG_DATA_HOME/argvus/calculator/history.json` (→ `~/.local/share/argvus/calculator/history.json`).

`$XDG_CONFIG_HOME/argvus/calculator/settings.json` (→ `~/.config/argvus/calculator/settings.json`).

`{"scientific":true}` → `{"profile":"scientific"}`; `{"scientific":false}` → `{"profile":"basic"}`.

`.desktop`: `/usr/share/applications/argvus-calculator.desktop` · `Name=ARGVUS Calculator` · `Exec=argvus calculator`.

يتبع نص التطبيقات Applications Font في Control Center → Appearance → Desktop Style → Fonts. ترث تطبيقات GTK قيمة gtk-font-name مع الحفاظ على أحجام الأرقام والعناوين. يقرأ المشغّل apps_family المولّد ويتابع التغييرات.

يجمع الرأس شارة ARGVUS بلون التمييز مع اسم التطبيق. يظهر التذييل القابل للنقر s Settings في شريط بعرض كامل وخلفية مميزة من السمة بأسلوب Control Center.
