يقوم الأمر الفرعي `argvus network` بالإبلاغ عن NetworkManager والتحكم فيه، ويقوم `argvus bluetooth` بالإبلاغ عن حالة محول Bluetooth ومدى توفره والتحكم فيه. كلاهما قيد التشغيل داخل `argvus`؛ يظل `networkctl` و`bluetoothctl` كأسماء مستعارة. تقوم لوحة التحكم وشريط الطريق باستدعاء هذه الأوامر.

استخدم `--help` في أي من الأمرين للأوامر الفرعية المثبتة. يعد تكامل واجهة مستخدم الشبكة والبلوتوث منفصلاً عن المديرين المتقدمين الاختياريين مثل Blueman.

يفصل مركز التحكم حالة الشبكة عن صفحات التكوين: **الشبكة → الحالة** تلخص الحالة الحالية، في حين أن الواجهات وWi-Fi وEthernet وVPN وDNS والوكيل وجدار الحماية هي مسارات منفصلة عندما يكون مزودوها متاحين. **البلوتوث → الحالة** و**الأجهزة** و**الإقران** تغطي حالة المحول وإجراءات الجهاز. تقوم هذه الصفحات بتنفيذ إجراءات النظام المدعومة من قبل الموفر؛ يعرض شريط المهام ولوحة التحكم سطح الحالة/الإجراء السريع.

قد تتطلب تغييرات الشبكة والبلوتوث تصريحًا وقد يتم تطبيقها على الفور من خلال NetworkManager أو خدمة Bluetooth. إنها ليست مثل تغيير مؤشر شريط المهام ARGVUS.

يرسل مركز التحكم كلمات مرور Wi-Fi إلى nmcli من خلال الإدخال القياسي باستخدام `--ask`؛ يتم استبعاد كلمات المرور من وسيطات العملية ويتم تنقيحها من أخطاء الأوامر التي يتم إرجاعها.

## إدارة شبكة سطر الأوامر

استخدم `argvus networkctl` للاستعلام عن الشبكات والتحكم فيها بدون الواجهة الرسومية:

```sh
# Show network status
argvus networkctl status

# Toggle networking on/off
argvus networkctl enable
argvus networkctl disable

# Wi-Fi control
argvus networkctl wifi on
argvus networkctl wifi off

# Open the network manager
argvus networkctl manager
```

## إدارة البلوتوث عبر سطر الأوامر

استخدم `argvus bluetoothctl` لمحول Bluetooth:

```sh
# Show the adapter state (key=value lines)
argvus bluetoothctl status

# Exit 0 when an adapter is available, 1 otherwise
argvus bluetoothctl available

# Turn the adapter on or off, or toggle it
argvus bluetoothctl enable
argvus bluetoothctl disable
argvus bluetoothctl toggle

# Open the Bluetooth manager (Blueman)
argvus bluetoothctl manager
```

عندما لا تسرد النواة أي وحدة تحكم في `/sys/class/bluetooth`، فإن `status` يجيب على `status=no-controller` على الفور، دون سؤال `bluetoothctl` (والذي سينتظر BlueZ عندما يتم إيقاف الخدمة). تقرأ وحدة شريط المهام وبطاقات لوحة التحكم نفس الحالة.

استخدم `--help` في أي من الأمرين لرؤية الخيارات والأوامر الفرعية الإضافية الخاصة بالإصدار المثبت لديك.

أثناء فتح مربع حوار كلمة مرور Wi-Fi، تحافظ تحديثات المسح الضوئي على SSID ونوع الأمان المحددين. إذا اختفت تلك الشبكة أو تغير أمانها، فسيتوقف التأكيد مع ظهور خطأ ويتطلب تحديدًا جديدًا.

يرسل DNS اليدوي خوادم IPv4 وIPv6 إلى إعدادات NetworkManager الخاصة بها قبل تحديث ملف المحلل. يتم الاحتفاظ بالارتباطات الرمزية للمحلل المُدار بواسطة الخدمة عن طريق رفض استبدال الملف. تؤدي العودة الناجحة إلى DNS التلقائي إلى استعادة النسخة الاحتياطية وإزالتها، لذا فإن دورة يدوية لاحقة تحفظ حالة وحدة الحل الحالية.

يتم انتظار إغلاق محرر ملف تعريف الشبكة حتى تنتهي مهمته الحالية، لذا لا يمكن مقاطعة حفظ ملف التعريف أو حذفه عن طريق تجاهل المحرر. تظل تحديثات الخلفية قابلة للإلغاء.

تشترك طلبات اتصال Wi-Fi في حارس إجراءات الشبكة: يكتمل الإجراء قيد التشغيل أو مهمة محرر الملف الشخصي قبل بدء طفرة أخرى. تتبع رسائل التقدم والإكمال اللغة المحددة.

يحتفظ تأكيد إزالة Bluetooth بعنوان الجهاز الأصلي حتى عند تحديث قائمة الأجهزة. يتم التعرف على نسب البطارية من bluetoothctl، ويتم تشغيل استعلامات تفاصيل الجهاز مع التزامن المحدود والمهلات الفردية.

تقبل كلمة مرور Wi-Fi وحقول DNS اليدوية والبحث عن الشبكة اللصق بين قوسين. تم حذف عناصر التحكم وفواصل الأسطر التي تم لصقها. لا تؤدي اختصارات الأحرف غير المدعومة لـ Ctrl فقط أو Alt فقط إلى إدراج أحرف. يقبل المحررون أحداث AltGr القابلة للطباعة والتي تم ترميزها كـ Ctrl+Alt؛ Ctrl+S يحفظ فقط بدون Alt. يحافظ محرر النص المشترك على التنقل الرأسي في الأعمدة المرئية ويقوم بمحاذاة التمرير الأفقي للأحرف العريضة.يتبع مؤشر شبكة شريط المهام أحداث NetworkManager باستخدام `argvus networkctl waybar --follow`، مع لقطة أولية وإعادة توصيل الشاشة تلقائيًا. لم يعد ينتظر فترة استقصاء مدتها 10 ثوانٍ. يظل الوصول إلى الإنترنت المحدود والمتصل وغير المتصل حالات متميزة. تقرأ حالة Wi-Fi نقاط الوصول المخزنة مؤقتًا دون طلب المسح. يُصدر `argvus networkctl waybar` لقطة Waybar JSON واحدة.
