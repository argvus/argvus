استخدم هذا الجدول عندما تعرف ما تريد تغييره ولكن ليس سطح ARGVUS الذي يمتلكه.

للحصول على مراجعة إرشادية لمناطق سطح المكتب الرئيسية، افتح **ترحيب ARGVUS** باستخدام `argvus welcome` أو من **مركز التحكم → الأدوات والتشخيصات**.

| أريد أن... | اذهب إلى... |
| --- | --- |
| اختر موضوعًا أو وضعًا | **مركز التحكم → المظهر → السمات** |
| تغيير لون التمييز | **مركز التحكم → المظهر → اللهجات** |
| تغيير خلفية الشاشة | **مركز التحكم → المظهر → خلفيات** |
| تمكين أو تعطيل التأثيرات المرئية | **مركز التحكم → المظهر → التأثيرات**، **مركز التحكم → المظهر → المشغلات**، **مركز التحكم → التكوين**، **شريط المهام**، **القياس عن بعد لعنصر واجهة المستخدم** أو **لوحة التحكم** |
| قم بتغيير موضع شريط المهام أو ارتفاعه أو حده أو تجميع الأداة المساعدة | **مركز التحكم → المظهر → شريط المهام → الموضع**، **الارتفاع**، **الحدود** و **الأيقونات** |
| تخصيص شريط المهام JSONC أو CSS | [تجاوزات شريط الطريق وشريط المهام](/docs/argvus-waybar/) |
| تغيير فجوات النوافذ أو حدودها | **مركز التحكم → سطح المكتب والإدخال → Hyprland → Windows → Spaces** و **الحدود** |
| تغيير ظل النافذة | **مركز التحكم → سطح المكتب والإدخال → Hyprland → الحدود → الظل** |
| اختر بطاقات لوحة التحكم المرئية | **مركز التحكم → المظهر → لوحة التحكم** |

| أضف قاعدة Hyprland متقدمة أو إعداد الشاشة أو ربط المفاتيح الجديد | [تجاوزات هايبرلاند](/docs/argvus-hyprland/hyprland-overrides/) |
| تغيير سلوك الماوس أو لوحة اللمس | **مركز التحكم → اللغة والمنطقة → الماوس ولوحة اللمس** |
| تغيير الخطوط | **مركز التحكم → الخطوط** |
| اختر التطبيقات الافتراضية | **مركز التحكم → التطبيقات الافتراضية** |

| فحص أو تغيير اتصالات الشبكة | بطاقة الشبكة بلوحة التحكم؛ يتم توفير التكوين الدائم للشبكة من خلال أدوات الشبكة المثبتة |
| تغيير مستوى الصوت أو كتم الصوت بسرعة | بطاقة حجم لوحة التحكم أو مفاتيح الوسائط |
| تغيير السطوع بسرعة | بطاقة سطوع لوحة التحكم أو مفاتيح السطوع |
| القفل أو تسجيل الخروج أو التعليق أو إيقاف التشغيل | جلسة لوحة التحكم/بطاقات الطاقة |
| تكوين اللغة أو المنطقة الزمنية أو الإعدادات الإقليمية | **مركز التحكم → اللغة والمنطقة** |

## التكوين أو الإجراء السريع؟

يعد مركز التحكم هو المكان الذي يمكنك البحث فيه عندما تريد أن يظل أحد الإعدادات جزءًا من تكوين سطح المكتب لديك. لوحة التحكم هي المكان الذي يجب أن تبحث فيه عندما تريد فحص الحالة أو تنفيذ إجراء متكرر الآن. تفتح بعض بطاقات لوحة التحكم نفس الموفرين الأساسيين الذين يستخدمهم مركز التحكم، لكن اللوحة ليست قاعدة بيانات إعدادات ثانية.

إذا لم يكن الإعداد مدرجًا، فاستخدم البحث الرئيسي في مركز التحكم. يتضمن سجل البحث الخاص به مسارات المظهر التي تواجه المستخدم ومجالات لوحة المفاتيح والإدخال والعرض والشبكة والجلسة.
