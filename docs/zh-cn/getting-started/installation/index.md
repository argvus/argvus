---
title: 安装
description: 在 Arch Linux 上安装 ARGVUS 软件包。
---
ARGVUS 以签名的 Arch Linux 软件包形式分发。公共安装程序会配置 ARGVUS 软件包仓库；然后该软件包集会安装桌面组件。

请参阅 [requirements](/docs/getting-started/installation/requirements/)，按照 [installation steps](/docs/getting-started/installation/install/)，并完成 [first session](/docs/getting-started/installation/first-session/)。

软件包仓库和 `argvus` 元软件包与桌面组件软件包分开维护。有关所有权，请参见开发者的 [package matrix](/docs/reference/package-matrix/)。
