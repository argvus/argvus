本节将引导您完成从一个空的 Arch Linux 安装到运行中的 ARGVUS 桌面的所有步骤。

如果您只想要最短路径，请参阅 [快速开始](/docs/quick-start/)。

## 步骤

1. 检查您的硬件和图形堆栈的 [要求](/docs/getting-started/installation/requirements/)。
2. 按照 [安装 ARGVUS](/docs/getting-started/installation/install/) 添加软件包仓库并安装软件包。
3. 最后按照 [首次会话](/docs/getting-started/installation/first-session/) 首次启动您的图形界面或 TTY 会话。

一旦 ARGVUS 运行，[用户指南](/docs/user-guide/) 覆盖日常配置：外观、会话、应用程序、硬件等。
