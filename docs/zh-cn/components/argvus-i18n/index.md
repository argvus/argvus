# ARGVUS 国际化

ARGVUS 提供英语 (`en-US`)、巴西葡萄牙语 (`pt-BR`)、西班牙语 (`es-ES`)、
法语 (`fr-FR`)、意大利语 (`it-IT`)、德语 (`de-DE`)、俄语 (`ru-RU`)、简体中文 (`zh-CN`)、日语 (`ja-JP`) 和韩语 (`ko-KR`)。英语是权威目录和备用语言。其他八种翻译是通过机器翻译辅助并进行技术修正而生成的；尚未获得独立母语审查认证。

## 选择语言

打开控制中心 > 偏好设置 > 语言与地区 > 语言，或设置 > 语言。页面会发现已安装的目录并显示其本地名称。
它会将 `LANG` 保存到 `$XDG_CONFIG_HOME/locale.conf`（默认 `~/.config/locale.conf`）。
请先在系统语言环境中启用相应的 UTF-8 系统区域设置。示例包括 `es_ES.UTF-8`、`zh_CN.UTF-8`、`ja_JP.UTF-8` 和 `ko_KR.UTF-8`。

该偏好设置不会修改 `/etc/locale.conf`。注释和区域类别设置将被保留。保存后控制面板会重新启动；请注销并重新登录以在整个会话中应用语言。未配置的用户使用英语。继承的环境变量和遗留的 ARGVUS 语言文件不会替换此偏好设置。登录欢迎界面在用户偏好可用之前运行，并保留其自己的服务帐户语言，默认是英语。

区域变体在不存在精确目录的情况下使用其语言的已安装目录；例如 `es_MX.UTF-8` 使用 `es-ES`。`zh-Hans` 选择简体中文。繁体中文（`zh-Hant`, `zh-TW`, `zh-HK`, `zh-MO`）不会被静默映射为简体中文，而是回退到英语。

## 目录和贡献

源是 `resources/locales/<locale>/<domain>.json`，在 `argvus` 仓库中。
已安装的目录位于 `/usr/share/argvus/i18n/`。它们随主 `argvus` 包一起发布。`locale.json` 提供标识符和本地/显示名称。
没有单独的 PO 目录或必需的在线翻译平台。

使用语义键并保留占位符名称、命令、选项、路径和键盘快捷键。翻译完整消息，而不是从翻译片段组装句子。新的规范键需要翻译成所有十种语言。在每个领域内保持术语一致，并在上下文中审核翻译，特别是认证、权限和破坏性操作。

```sh
argvus i18n list
argvus i18n locale
argvus i18n get common welcome name=Alice
argvus i18n validate
```
`ARGVUS_I18N_DIR` 为开发和分阶段的软件包检查选择了一个备用目录根。验证会检查域、键、字符串值、占位符、空翻译以及特定语言环境的整数复数形式。验证证明的是结构完整性，而非语言准确性。

## Unicode 与字体

`argvus-fonts` 除了拉丁字母、符号和表情符号字体系列外，还需要 Noto CJK 字体。Fontconfig 为中文、日文和朝鲜文提供回退字体，而不会替换用户选择的主字体。应用程序和终端仍然需要启用字体回退。

共享的 Ratatui 文本辅助工具可以测量终端单元格，在截断时保留扩展字符群，并换行显示宽文本。文本编辑器可以移动和删除整个字形。在极窄的区域中无法在一个单元格内显示双单元格字形；在这种情况下，硬换行辅助工具会使用替代字符。表情符号和宽度不确定的字符在不同终端/字体实现中仍可能不同。终端的宽度策略应与 Ratatui 的正常 Unicode 宽度一致。

语言选择不会安装输入法或更改键盘布局。输入中文、日文或韩文时，请使用兼容 Wayland 的输入法。
