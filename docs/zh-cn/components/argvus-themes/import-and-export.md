---
title: 导入和导出主题
description: 将活动主题导出为您自己的主题，导入主题存档，应用它并删除它。
---
导出和导入操作适用于**主题**，格式与官方主题相同。导出会将当前主题（包括你的高亮颜色和壁纸）保存为一个属于你自己的新主题。导入则是在你的主题中安装一个主题归档文件。两者都在**控制中心 → 外观 → 主题**中操作，你的主题会列在**自定义主题**下。

## 导出的主题包含什么

归档文件 `argvus-theme-<id>.tar.gz` 包含一个主题目录，其布局与官方主题相同：

```text
<id>/theme.toml        the manifest (schema 2): name, category, palette, wallpaper
<id>/appearance.json  your visual settings, including layout, effects, fonts and panel presentation
<id>/effects.conf     per-surface effect values for the active theme, when present
<id>/overrides/...     the overrides of the theme it was made from, if any
<id>/wallpaper.<ext>   the wallpaper on screen when you exported
```
清单基于当前主题，包含您的姓名、新ID、调色板强调的高亮色，以及旁边的壁纸。外观配置文件保留了当前在 ARGVUS 中应用的视觉设置，包括窗口间距、边框、任务栏边距、面板呈现、颜色、特效和字体。自定义壁纸和强调色随主题存储。应用任何主题都会重新应用其完整的配置文件（或在无配置文件时自动应用 ARGVUS 默认），替换自上次应用以来所做的独立视觉更改。切换粘贴或间距时，始终重新应用该模式的窗口和任务栏几何体;将个人几何体保存在导出的自定义主题中，以便在该主题应用时保持可用。非视觉设置如音频、键盘和网络偏好设置不属于主题。

应用的外观在会话重启和重新加载后仍然存在。会话准备会根据当前配置重新构建必要的文件，而不会恢复原始主题的布局。

在应用主题后更改的设置在下一次主题或模式更改时是临时的。通过 **控制中心 → 外观 → 主题 → 导出主题** 导出主题，可以保存当前的视觉配置，并在以后通过应用导出的主题来恢复。

你的主题安装在 `~/.local/share/argvus/themes/<id>/`。解压缩存档到该位置也会安装主题。

## 导出当前主题

1. 打开 **控制中心 → 外观 → 主题**。
2. 选择 **导出主题**，或者在主题页面上按 `e`。
3. 输入主题名称。该字段显示将要写入的文件。
4. 按 `Enter`。

ID 由名称生成：小写字母、数字和连字符。当 ID 已被已安装的主题或家目录中的归档使用时，会添加 `-2`、`-3` 等。归档将写入您的家目录，例如 `~/argvus-theme-my-theme.tar.gz`。ARGVUS 在写入前会检查主题：清单必须能加载，并且每个组件在两种模式下都能渲染。

## 导入主题

1. 将 `.tar.gz` 归档复制到您的家目录（`~`）。ARGVUS 列出那里包含主题的归档。
2. 打开 **控制中心 → 外观 → 主题 → 导入主题**，或在主题页面上按 `i`。
3. 选择归档并按 `Enter`。

ARGVUS 在安装之前会检查归档文件。它必须只包含一个目录，并且该目录中有 `theme.toml`，且只能使用相对路径（不能有 `..`，不能有链接），最多 128 个条目，每个文件都有大小限制；ID 必须与目录匹配，壁纸必须包含在归档中，每个组件必须在两种模式下都能渲染。包含的外观配置文件必须使用支持的部分，并且是有效的 JSON。如果任何检查失败，将不会安装任何内容。

主题会添加到 **自定义主题** 中。导入不会自动应用主题：由你选择何时应用。

### 名称冲突

- 如果你的某个主题 ID 相同，ARGVUS 会询问 **是否替换相同 ID 的主题？**。选择 **替换** 来替换它，或者按 `Esc` 来保留你的主题。被替换的主题将在新主题安装之前作为备份保留。
- 如果归档的 ID 与官方主题冲突，将被拒绝。请以另一个名称重新导出。

## 应用自定义主题

1. 打开 **控制中心 → 外观 → 主题 → 自定义主题**。
2. 选择主题并按 `Enter`。

主题的完整导出配置将被应用，包括其壁纸、间距、边框、强调色、效果、字体和面板呈现。其视觉数值会替换当前设置。ARGVUS 然后重新启动任务栏、Hyprland 重载服务、壁纸和控制面板，以便每个界面都使用自定义主题。

## 删除自定义主题

1. 打开 **控制中心 → 外观 → 主题 → 自定义主题**。
2. 选择主题并按 `d`。
3. 使用 `y` 进行确认，或按 `n` 或 `Esc` 取消。

主题目录将从 `~/.local/share/argvus/themes` 中移除。如果它是当前活动主题，ARGVUS 会先切换到 **ARGVUS Dark**。

## 早期版本的配置文件

早期版本导出了*主题配置文件*（`profile.tar.gz`），这是外观设置的副本。第一次打开主题页面时，`~/.local/share/argvus/themes/<name>/` 中的每个配置文件都会转换为由其基础主题、突出显示颜色和壁纸组成的主题。原始配置文件和旧的 `custom-themes.json` 列表会移到 `~/.config/argvus/data/backups/theme-profiles-<seconds>/`，并且状态栏会报告转换情况。基础主题未安装的配置文件仅会被移动到备份中。

## 共享主题

导出的主题是常规归档文件。将其复制到运行 ARGVUS 的另一台计算机，并在那里导入。

## 排除故障

- **档案未列出。** 它必须直接位于你的主目录中，以 `.tar.gz` 结尾，并包含 `<id>/theme.toml`。  
- **导入被拒绝。** 状态行会说明原因：具有相同 ID 的官方主题、缺失的壁纸、无法加载的清单或无法呈现的组件。  
- **导出被拒绝。** 名称至少需要一个字母或数字，并且活动主题必须已安装。
