---
title: ARGVUS 磁盘使用分析器
description: 在主题化的 Kitty 窗口中使用 ncdu 交互式浏览磁盘使用情况。
---
从应用启动器打开 **ARGVUS 磁盘使用分析器** 或运行：

```sh
argvus du
```
分析器会打开一个专用的、居中的 Kitty 窗口，并在其 ARGVUS 框架内嵌入真实的 ncdu 界面。它从 `$HOME` 开始。编辑目录路径或选择 **浏览** 以打开已配置的文件管理器。使用 Superfile，导航到一个目录并按 **空格** 选择它；`q` 或 `Esc` 取消。其他已配置的文件管理器会正常打开，但可能无法返回选定的目录，因此请在分析器中输入或粘贴路径。

使用 Tab 键或箭头键在目录、选项和操作之间移动。图表、百分比、深色配色方案和目录优先排序默认启用。其余的扫描和显示选项可以在选择 **Analyze** 之前切换。在结果界面中，使用 ncdu 的键盘控制；`q` 返回表单，`Esc` 停止扫描。按 `d` 可删除选定的文件或目录。ncdu 会要求确认；删除是永久性的，并使用当前用户的权限。不会请求提升权限。

外部界面遵循活动的 ARGVUS 主题和区域设置。需要 Kitty 和 ncdu；`argvus-devtools` 软件包提供 ncdu。如果缺少 Kitty 或 ncdu，应用程序会报告缺失的依赖项。
