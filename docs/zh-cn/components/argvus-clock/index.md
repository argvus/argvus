ARGVUS 时钟是一个 GTK 4 应用程序，提供当前时间和时间工具：世界时钟、秒表、倒计时器和闹钟。可通过启动器打开，点击任务栏上的时间，使用 **SUPER + Shift + C**，或者通过以下方式打开：

```sh
argvus clock                     # open the popup near the pointer
argvus clock --toggle            # hide the popup if it is visible, show it otherwise
argvus clock --toggle --x 1600 --y 30  # open next to a taskbar click position
argvus clock --page alarms       # open on a page: clock, world, stopwatch, timer, alarms
argvus clock --background        # run without a window, to keep alarms active
```
ARGVUS 时钟以一个与任务栏对齐的弹出窗口打开，间隔为 4 像素。任务栏会传递根点击坐标，因此弹出窗口会使用被点击的显示器；如果没有坐标打开，则使用指针位置。如果指针在弹出窗口外停留 5 秒，它会自动关闭；将指针移入弹出窗口会取消倒计时。在主标签页按 **Esc** 仍会立即隐藏窗口，在完整页面按 **Esc** 则返回到前一个标签页。`argvus --clock` 是一个别名。点击任务栏中的日期仍会打开日历；ARGVUS 时钟不会显示事件。

ARGVUS Focus、ARGVUS 时钟和控制面板共享同一个屏幕边缘。打开时钟会先关闭 Focus 和控制面板；打开其中任意一个界面会关闭时钟。

## 页面

- **时钟**：以大数字显示时间（默认24小时制，可在设置中切换为12小时制，秒数可选）、本地化日期、本地时区及其UTC偏移，以及下一个闹钟。
- **世界时钟**：通过搜索城市或IANA时区添加城市（不区分重音符号和大小写）。每个城市显示其时间、与本地时间的差异以及那里的日期是昨天、今天还是明天。夏令时信息来自IANA时区数据库；不使用固定偏移计算。城市可以重新排序和删除。
- **秒表**：开始、暂停、继续、重置及圈数（单圈时间和总时间）。
- **计时器**：以小时、分钟和秒为单位，或使用预设5、10、15、25、30和60分钟。支持暂停、继续、重启和取消。结束时会像闹钟一样响。该计时器独立于ARGVUS Focus会话。
- **闹钟**：创建、编辑、开启和关闭以及删除闹钟。每个闹钟都有时间、可选名称、重复的星期（无表示只响一次）、铃声和贪睡时间。

键盘快捷键：**Ctrl+1** 到 **Ctrl+5** 切换页面，**Ctrl+N** 创建闹钟，**Ctrl+,** 打开设置，**Esc** 返回，**Ctrl+W** 关闭窗口，**Ctrl+Q** 退出。

## 闹钟铃声

闹钟会一直播放真实铃声，直到你响应它：

- 声音：**Chime**（默认）和 **Beacon**，随 `/usr/share/argvus/sounds/` 一起发布。
- **闹钟音量**（10 到 100，默认 80）和 **试听闹钟声音** 在设置中；编辑器有一个测试按钮可用于选择的声音。
- 响铃的闹钟会在屏幕顶部显示一个卡片，位于其他窗口之上，并显示一个通知，卡片和通知都有 **延迟** 和 **关闭** 按钮。在卡片获得焦点时，**Enter** 可关闭，**S** 可延迟。
- 延迟后，闹钟将在延迟时间（1 到 60 分钟，默认 10 分钟）后再次响铃。
- 未被应答的闹钟将在 **停止响铃时间**（5、10、15 或 30 分钟，默认 10 分钟）后停止响铃，并留下通知。
- 同时响铃的两个闹钟都会被列出；第二个闹钟从不静音第一个闹钟。
- 如果无法播放声音，卡片和窗口会显示错误提示，并记录错误。ARGVUS 时钟从不报告未播放的声音。

播放使用 GTK 的媒体支持 (GStreamer)，因此它可以与 PipeWire、PulseAudio 或 ALSA 一起使用。该软件包依赖 `gst-plugins-base`（Ogg Vorbis）和 `gst-plugins-good`（音频输出）。

## 当闹钟响起时

闹钟仅在 ARGVUS 时钟在您的会话中运行时才会响起：

- 关闭窗口会在需要闹钟、计时器或秒表运行时保持 ARGVUS 时钟运行（**关闭窗口时保持运行**，默认开启）。如果没有待处理事项，它将退出。
- **随会话启动** 会启用用户单元 `argvus-clock.service`，该单元会在登录后运行 `argvus clock --background`。默认关闭。
- 当您已注销、计算机已关闭或处于挂起状态时，闹钟无法响起。
- 即便延迟最多 5 分钟才注意到，闹钟仍会响。超过这个时间（时钟未运行，或系统处于睡眠状态或关闭）则不会响：会在通知和闹钟页面上报告为**未响**。重复闹钟会继续到下一天；一次性闹钟则关闭。 
- 每次提醒在响铃前都会保存为已处理，因此重新打开 ARGVUS 时钟不会重复响同一个闹钟，并且每个会话只运行一个实例。 
- 重复闹钟按所选工作日的本地时间计算，因此即使夏令时变化也会保持时间不变。春季跳过的那段时间会在时间间隙后的第一分钟响铃；重复的时间会在第一次响铃。 
- 计时器在系统挂起期间仍会继续计数。如果在系统休眠时结束，它将在唤醒时响铃并显示延迟时间。在关闭 ARGVUS 时钟后，运行中的计时器或秒表会以暂停状态恢复。 

## 路径

| 路径 | 内容 |
| --- | --- |
| `$XDG_CONFIG_HOME/argvus/data/clock/settings.json` | 设置和世界时钟 |
| `$XDG_DATA_HOME/argvus/clock/alarms.json` | 闹钟 |
| `$XDG_STATE_HOME/argvus/clock/timers.json` | 计时器和秒表检查点 |
| `/usr/lib/systemd/user/argvus-clock.service` | 从会话开始 |
| `/usr/share/argvus/sounds/` | 打包声音 |

文件以原子方式写入；无法读取的文件将重命名为 `<name>.corrupt-<time>` 并使用默认值。颜色遵循活动的 ARGVUS 主题和高亮颜色（主题使用者 `time`）。字符串来自 `clock` 和 `time` 翻译域。

任务栏日历、ARGVUS 焦点、ARGVUS 时钟和控制面板是互斥的：打开一个会关闭其他所有。
