---
title: 用户界面组件
description: ARGVUS 用户界面包。
---
UI 包包括 `argvus-control-panel`、`argvus-taskbar` 和 `argvus-launcher`，以及子命令 `argvus` 的 `argvus control-center`（`argvus` 中的辅助工具）、`argvus taskbar-calendar`、`argvus widget-telemetry`、`argvus terminal`、`argvus system-monitor`、`argvus removable-devices`、`argvus focus` 和 `argvus clock`。日历、Focus 和时钟使用共享的 `argvus-taskbar-popup` 包用于层壳定位和关闭；Focus 还通过进程内的 `argvus focus status` 路径公开其 Waybar 状态读取器。

它们面向用户的行为按功能记录；此页面记录软件包的归属。
