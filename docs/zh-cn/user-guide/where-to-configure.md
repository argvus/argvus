当您知道想要更改的内容，但不知道哪个 ARGVUS 界面拥有它时，请使用此表。

要对主要桌面区域进行有指导的查看，请使用 `argvus welcome` 打开 **ARGVUS 欢迎**，或从 **控制中心 → 工具与诊断** 打开。

| 我想… | 去… |
| --- | --- |
| 选择主题或模式 | **控制中心 → 外观 → 主题** |
| 更改强调色 | **控制中心 → 外观 → 强调色** |
| 更改桌面壁纸 | **控制中心 → 外观 → 壁纸** |
| 启用或禁用视觉效果 | **控制中心 → 外观 → 效果**、**控制中心 → 外观 → 启动器**、**控制中心 → 配置**、**任务栏**、**小部件遥测**或**控制面板** |
| 更改任务栏位置、高度、边框或工具分组 | **控制中心 → 外观 → 任务栏 → 位置**、**高度**、**边框**和**图标** |
| 自定义任务栏 JSONC 或 CSS | [Waybar 和任务栏覆盖](/docs/argvus-waybar/)] |
| 更改窗口间隙或边框 | **控制中心 → 桌面与输入 → Hyprland → 窗口 → 空间** 和 **边框** |
| 更改窗口阴影 | **控制中心 → 桌面与输入 → Hyprland → 边框 → 阴影** |
| 选择可见的控制面板卡片 | **控制中心 → 外观 → 控制面板** |
| 更改键盘快捷键 | **控制中心 → 语言与区域 → 键盘快捷键** |
| 添加高级 Hyprland 规则、显示器设置或新的按键绑定 | [Hyprland 覆盖](/docs/argvus-hyprland/hyprland-overrides/)] |
| 更改鼠标或触控板行为 | **控制中心 → 语言与区域 → 鼠标与触控板** |
| 更改字体 | **控制中心 → 字体** |
| 选择默认应用程序 | **控制中心 → 默认应用程序** |
| 更改显示设置 | **控制中心 → 显示器** 或控制面板显示卡片 |
| 检查或更改网络连接 | 控制面板网络卡；已安装的网络工具提供永久网络配置 |
| 快速更改音量或静音 | 控制面板音量卡或媒体按键 |
| 快速调节亮度 | 控制面板亮度卡或亮度按键 |
| 锁定、注销、挂起或关机 | 控制面板会话/电源卡 |
| 配置语言、时区或区域设置 | **控制中心 → 本地化和区域** |

## 配置还是快速操作？

当你希望某个设置成为桌面配置的一部分时，请查看控制中心。当你希望检查状态或立即执行频繁操作时，请查看控制面板。一些控制面板卡会打开与控制中心使用的相同底层提供程序，但控制面板本身不是第二个设置数据库。

如果某个设置未列出，请使用控制中心的主页搜索。其搜索注册表包括面向用户的外观路径以及键盘、输入、显示、网络和会话领域。
