---
title: 快速开始
description: 用一个命令运行 ARGVUS。
---
在全新 Arch Linux 安装上，从 TTY 直接尝试 ARGVUS 的最快方法：

```sh
curl -fsSL https://argvus.github.io/install.sh | sh
```
此单条命令将导入并签署 ARGVUS 仓库密钥，配置软件包仓库，更新软件包数据库，并安装 `argvus` 软件包及其依赖项。

注销，选择 **ARGVUS** 进入显示管理器（或启动 TTY 会话），即可进入系统。
