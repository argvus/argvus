---
title: Avvio rapido
description: Avvia ARGVUS con un solo comando.
---
Il modo più veloce per provare ARGVUS su una nuova installazione di Arch Linux, direttamente da un TTY:

```sh
curl -fsSL https://argvus.github.io/install.sh | sh
```
Questo singolo comando importa e firma la chiave del repository ARGVUS, configura il repository dei pacchetti, aggiorna il database dei pacchetti e installa il pacchetto `argvus` con le sue dipendenze.

Effettua il logout, seleziona **ARGVUS** dal tuo display manager (o avvia una sessione TTY) e sei dentro.
