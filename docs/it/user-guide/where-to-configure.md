Usa questa tabella quando sai cosa vuoi modificare ma non quale superficie ARGVUS ne è proprietaria.

Per una guida alla revisione delle principali aree del desktop, apri **Benvenuto ARGVUS** con `argvus welcome` o da **Centro di Controllo → Strumenti e Diagnostica**.

| Voglio… | Vai a… |
| --- | --- |
| Scegliere un tema o una modalità | **Centro di Controllo → Aspetto → Temi** |
| Cambiare il colore dell'accento | **Centro di Controllo → Aspetto → Accenti** |
| Cambiare lo sfondo | **Centro di Controllo → Aspetto → Sfondi** |
| Attivare o disattivare effetti visivi | **Centro di Controllo → Aspetto → Effetti**, **Centro di Controllo → Aspetto → Avviatori**, **Centro di Controllo → Configurazione**, **Barra delle applicazioni**, **Telemetry Widget** o **Pannello di Controllo** |
| Cambiare posizione, altezza, bordo o raggruppamento delle utilità della barra delle applicazioni | **Centro di Controllo → Aspetto → Barra delle applicazioni → Posizione**, **Altezza**, **Bordo** e **Icone** |
| Personalizzare la barra delle applicazioni JSONC o CSS | [Waybar e override della barra delle applicazioni](/docs/argvus-waybar/) |
| Modificare gli spazi o i bordi delle finestre | **Pannello di Controllo → Desktop e Input → Hyprland → Finestre → Spazi** e **Bordi** |
| Modificare l’ombra delle finestre | **Pannello di Controllo → Desktop e Input → Hyprland → Bordi → Ombra** |
| Scegliere le schede visibili del Pannello di Controllo | **Pannello di Controllo → Aspetto → Pannello di Controllo** |
| Modificare le scorciatoie da tastiera | **Pannello di Controllo → Lingua e Regione → Scorciatoie da tastiera** |
| Aggiungere una regola avanzata di Hyprland, un’impostazione del monitor o una nuova scorciatoia | [Override Hyprland](/docs/argvus-hyprland/hyprland-overrides/) |
| Modificare il comportamento di mouse o touchpad | **Pannello di Controllo → Lingua e Regione → Mouse e Touchpad** |
| Cambiare i font | **Pannello di Controllo → Font** |
| Scegliere le applicazioni predefinite | **Pannello di Controllo → Applicazioni predefinite** |
| Modificare le impostazioni del display | **Pannello di Controllo → Display** o la scheda display del Pannello di Controllo |
| Controllare o modificare le connessioni di rete | Scheda rete del Pannello di Controllo; la configurazione di rete permanente è fornita dagli strumenti di rete installati |
| Modificare il volume o disattivarlo rapidamente | Scheda volume del Pannello di Controllo o i tasti multimediali |
| Modificare la luminosità rapidamente | Scheda luminosità del Pannello di Controllo o i tasti della luminosità |
| Bloccare, disconnettersi, sospendere o spegnere | Schede sessione/energia del Pannello di Controllo |
| Configurare lingua, fuso orario o impostazioni regionali | **Centro di Controllo → Locale e Regione** |

## Configurazione o azione rapida?

Il Centro di Controllo è il posto da consultare quando vuoi che un'impostazione rimanga parte della configurazione del tuo desktop. Il Pannello di Controllo è il posto da consultare quando vuoi verificare lo stato o eseguire un'azione frequente immediatamente. Alcune schede del Pannello di Controllo aprono gli stessi provider sottostanti utilizzati dal Centro di Controllo, ma il pannello non è un secondo database delle impostazioni.

Se un'impostazione non è elencata, usa la ricerca nella home del Centro di Controllo. Il suo registro di ricerca include i percorsi dell'interfaccia utente e i domini della tastiera, input, display, rete e sessione.
