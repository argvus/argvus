ARGVUS è un ambiente desktop modulare Hyprland e Wayland per Arch Linux. Inizia con [installation](/docs/getting-started/installation/), poi scegli una funzione dalla guida per l'utente.

Il desktop combina una sessione Hyprland, una barra delle applicazioni Waybar, un pannello di controllo Quickshell, applicazioni native e fornitori di sistema. La [architecture guide](/docs/developer-guide/architecture/overview/) spiega come questi componenti funzionano insieme.

## Punti di accesso comuni

- Apri l'applicazione delle impostazioni con `argvus --control-center`.
- Apri il calendario con `argvus --calendar`.
- Controlla la sessione con `argvus sessionctl status`.
- Leggi l'elenco dei comandi installati con `argvus --help`.
