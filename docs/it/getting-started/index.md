Questa sezione ti guida attraverso tutto il necessario per passare da un'installazione base di Arch Linux a un desktop ARGVUS funzionante.

Se vuoi solo il percorso più rapido, consulta invece [Quick Start](/docs/quick-start/).

## Passaggi

1. Controlla i [requirements](/docs/getting-started/installation/requirements/) per il tuo hardware e la tua configurazione grafica.
2. Segui [Install ARGVUS](/docs/getting-started/installation/install/) per aggiungere il repository dei pacchetti e installare i pacchetti.
3. Concludi con [First session](/docs/getting-started/installation/first-session/) per avviare per la prima volta la sessione grafica o TTY.

Una volta che ARGVUS è in esecuzione, la [User Guide](/docs/user-guide/) copre la configurazione quotidiana: aspetto, sessioni, applicazioni, hardware e altro ancora.
