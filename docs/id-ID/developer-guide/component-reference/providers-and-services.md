---
title: Penyedia dan layanan
description: ARGVUS provider packages.
---

Paket penyedia meliputi `argvus-display`, `argvus network`, `argvus-power`, `argvus-notifications`, `argvus-firewall` dan `argvus accounts`. Mereka mengekspos perintah terfokus, konfigurasi dan integrasi sistem yang digunakan oleh paket UI.
