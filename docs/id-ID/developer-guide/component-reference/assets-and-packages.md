---
title: Aset dan paket
description: ARGVUS aset dan proyek pengemasan.
---

`argvus-appearance` memiliki status tema dan aksen, orkestra tema, dan adaptor untuk konsumen eksternal. Konsumen visual yang dihasilkan dimiliki oleh `argvus-config`. `argvus-branding` menyediakan logo dan tanda kata ARGVUS. `argvus-wallpapers`, `argvus-fonts` dan `argvus-icons` menyediakan aset. `argvus-app-profiles` menyediakan profil aplikasi. `argvus-waybar` mengemas biner Waybar yang dipatch.
