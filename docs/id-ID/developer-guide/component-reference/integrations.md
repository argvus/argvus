---
title: Integrasi
description: Kompositor, login, kunci dan integrasi portal.
---

Konfigurasi kompositor paket `argvus-hyprland`; `argvus-portal` mengemas integrasi portal XDG; `argvus-greeter` mengintegrasikan salam; `argvus-lock` mengintegrasikan Hyprlock; overlay pemuatan yang dikirimkan dalam `argvus` mengintegrasikan visual pemuatan sesi; dan `argvus-boot-splash` mengintegrasikan visual boot.
