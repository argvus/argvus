---
title: Lingkungan pengembangan
description: Siapkan pembayaran untuk pengembangan ARGVUS.
---

Ruang kerja berisi repositori independen di bawah `de/`. Periksa `Cargo.toml`, `PKGBUILD`, Makefile, dan pembantu pengemasan repositori target sebelum membangun. Jaga agar konfigurasi sumber, payload paket, dan konfigurasi terinstal aktif tetap berbeda.

Situs dokumentasi berada di bawah `web/site-src` dan menggunakan Astro, Starlight, dan `starlight-versions`.
