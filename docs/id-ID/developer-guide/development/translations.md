---
title: Translations
description: Mempertahankan katalog pelokalan ARGVUS bersama.
---

`argvus-i18n` memiliki katalog bersama dan modul QML. Perbarui katalog bahasa Inggris dan Portugis bersamaan saat mengubah teks yang terlihat pengguna, lalu jalankan:

```sh
argvus i18n validate
```

Konsumennya mencakup aplikasi Rust asli, komponen shell, dan pembantu sesi.
