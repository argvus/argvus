---
title: Installation
description: Instal paket ARGVUS di Arch Linux.
---

ARGVUS didistribusikan sebagai paket Arch Linux yang ditandatangani. Penginstal publik mengonfigurasi repositori paket ARGVUS; kumpulan paket kemudian menginstal komponen desktop.

Lihat [persyaratan](/docs/getting-started/installation/requirements/), ikuti [langkah instalasi](/docs/getting-started/installation/install/), dan selesaikan dengan [sesi pertama](/docs/getting-started/installation/first-session/).

Repositori paket dan metapackage `argvus` dikelola secara terpisah dari paket komponen desktop. Lihat pengembang [matriks paket](/docs/reference/package-matrix/) untuk kepemilikan.
