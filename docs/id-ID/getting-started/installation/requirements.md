---
title: Persyaratan
description: Persyaratan sistem dan prasyarat untuk ARGVUS.
---

ARGVUS menargetkan Arch Linux dan memerlukan tumpukan grafis berkemampuan Wayland, Hyprland, dan dependensi runtime yang ditarik oleh paket. Manajer tampilan bersifat opsional: ARGVUS mendukung alur login grafis melalui salam dan alur TTY manual.

Sebelum instalasi, pastikan bahwa:

- sistem diperbarui sepenuhnya dengan `pacman`;
- kernel dan driver grafis yang berfungsi telah diinstal;
- pengguna dapat menjalankan sesi Wayland;
- jaringan tersedia ketika repositori paket dikonfigurasi.

Mesin virtual mungkin memerlukan pengaturan kompatibilitas yang dijelaskan di [Mesin virtual](/docs/user-guide/virtual-machines/).
