---
title: Pemecahan masalah instalasi
description: Mendiagnosis masalah instalasi paket dan repositori.
---

Periksa konfigurasi repositori dan ketersediaan paket dengan `pacman`. Konfirmasikan bahwa paket `argvus` dan paket komponen yang diperlukan telah diinstal sebelum menyelidiki perilaku runtime.

Penginstal publik hanya mengonfigurasi repositori; itu tidak menggantikan instalasi atau pengaturan sesi `pacman`.
