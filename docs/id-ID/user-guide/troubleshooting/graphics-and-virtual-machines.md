title: Grafik dan mesin virtual
description: Mendiagnosis kegagalan rendering dalam sesi Hyprland.

Periksa lingkungan sesi dan log kompositor. Di mesin virtual, periksa variabel kompatibilitas yang diekspor oleh `argvus start`. Jangan memaksakan rendering perangkat lunak pada perangkat keras fisik tanpa mengonfirmasi bahwa tumpukan grafis memerlukannya.
