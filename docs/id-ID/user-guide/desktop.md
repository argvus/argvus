title: Desktop
description: Memahami permukaan desktop ARGVUS.
---

Shell desktop terdiri dari Hyprland, taskbar Waybar yang ditambal, Panel Kontrol Quickshell, dan widget telemetri opsional. Hyprland memiliki jendela dan ruang kerja; bilah tugas mengomunikasikan ruang kerja/jendela dan status sistem; Panel Kontrol menyediakan tindakan cepat; pemberitahuan dan aplikasi muncul di samping permukaan ini.

Konfigurasi ada di [Pusat Kontrol](/docs/components/argvus-control-center/), sementara tindakan yang sering dilakukan ada di Panel Kontrol. Mulailah dengan [Konfigurasi pertama](/docs/user-guide/getting-started/) jika ini adalah sesi pertama Anda.

- [Pintasan keyboard](/docs/argvus-hyprland/keyboard-shortcuts/)
