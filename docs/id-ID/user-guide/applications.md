ARGVUS mengekspos aplikasi umum melalui operator `argvus` dan paket terfokus.

- [Peluncur](/docs/argvus-launcher/)
- [Terminal](/docs/components/argvus-terminal/)
- [Kalender](/docs/components/argvus-taskbar-calendar/)
- [Fokus ARGVUS](/docs/components/argvus-focus/) (Pomodoro dan sesi fokus)
- [Jam ARGVUS](/docs/components/argvus-clock/) (jam, jam dunia, stopwatch, timer dan alarm)
- [Permainan](/docs/argvus-games/) (termasuk [Ular](/docs/argvus-games/snake/))
- [Monitor sistem](/docs/components/argvus-system-monitor/)
- [Aplikasi bawaan](/docs/components/argvus-control-center/)
- [Perangkat yang dapat dilepas](/docs/components/argvus-removable-devices/)

Pusat Kontrol dibuka dengan `argvus --control-center`; halaman Aplikasinya mengelola aplikasi default.
