---
title: Mulai Cepat
description: Jalankan ARGVUS dalam satu perintah.
---

Cara tercepat untuk mencoba ARGVUS pada instalasi Arch Linux baru, langsung dari TTY:

```sh
curl -fsSL https://argvus.github.io/install.sh | sh
```

Perintah tunggal ini mengimpor dan menandatangani kunci repositori ARGVUS, mengonfigurasi repositori paket, memperbarui database paket, dan menginstal paket `argvus` dengan dependensinya.

Keluar, pilih **ARGVUS** dari pengelola tampilan Anda (atau mulai sesi TTY), dan Anda masuk.

## Langkah selanjutnya

- Butuh persyaratan, pengaturan repositori manual, atau detail tentang apa yang dilakukan penginstal? Lihat panduan lengkap [Memulai](/docs/getting-started/).
- Ingin mempersonalisasi desktop Anda setelah login pertama? Lihat [Konfigurasi pertama](/docs/user-guide/getting-started/) di Panduan Pengguna.
- Ada yang tidak berfungsi? Periksa [Pemecahan Masalah](/docs/user-guide/troubleshooting/).
