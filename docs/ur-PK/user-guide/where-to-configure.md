---

اس جدول کا استعمال اس وقت کریں جب آپ جانتے ہوں کہ آپ کیا تبدیل کرنا چاہتے ہیں لیکن یہ نہیں کہ کون سی ARGVUS سطح اس کی مالک ہے۔

مرکزی ڈیسک ٹاپ ایریاز کے گائیڈڈ جائزے کے لیے، `argvus welcome` کے ساتھ **ARGVUS Welcome** کھولیں یا **کنٹرول سینٹر → ٹولز اینڈ ڈائیگنوسٹک** سے۔

| میں چاہتا ہوں… | پر جائیں... |
| --- | --- |
| ایک تھیم یا موڈ منتخب کریں | **کنٹرول سینٹر → ظاہری شکل → تھیمز** |
| لہجے کا رنگ تبدیل کریں | **کنٹرول سینٹر → ظاہری شکل → لہجے** |
| وال پیپر تبدیل کریں | **کنٹرول سینٹر → ظاہری شکل → وال پیپر** |
| بصری اثرات کو فعال یا غیر فعال کریں | **کنٹرول سینٹر → ظاہری شکل → اثرات**، **کنٹرول سینٹر → ظاہری شکل → لانچرز**، **کنٹرول سینٹر → کنفیگریشن**، **ٹاسک بار**، **ویجیٹ ٹیلی میٹری** یا **کنٹرول پینل** |
| ٹاسک بار کی پوزیشن، اونچائی، بارڈر یا یوٹیلیٹی گروپنگ کو تبدیل کریں | **کنٹرول سینٹر → ظاہری شکل → ٹاسک بار → پوزیشن**، **اونچائی**، **بارڈر** اور ** شبیہیں** |
| ٹاسک بار کو حسب ضرورت بنائیں JSONC یا CSS | [وی بار اور ٹاسک بار کو اوور رائیڈز](/docs/argvus-waybar/) |
| ونڈو گیپس یا بارڈرز کو تبدیل کریں | **کنٹرول سینٹر → ڈیسک ٹاپ اور ان پٹ → ہائپرلینڈ → ونڈوز → اسپیس** اور **بارڈرز** |
| ونڈو شیڈو کو تبدیل کریں | **کنٹرول سینٹر → ڈیسک ٹاپ اور ان پٹ → ہائپر لینڈ → بارڈرز → شیڈو** |
| دکھائی دینے والے کنٹرول پینل کارڈز کا انتخاب کریں | **کنٹرول سینٹر → ظاہری شکل → کنٹرول پینل** |
| کی بورڈ شارٹ کٹس کو تبدیل کریں | **کنٹرول سینٹر → لوکیل اور ریجن → کی بورڈ شارٹ کٹ** |
| ایک اعلی درجے کی ہائپرلینڈ اصول، مانیٹر کی ترتیب یا نئی کی بائنڈنگ شامل کریں | [Hyprland overrides](/docs/argvus-hyprland/hyprland-overrides/) |
| ماؤس یا ٹچ پیڈ کا رویہ تبدیل کریں | **کنٹرول سینٹر → لوکیل اور ریجن → ماؤس اور ٹچ پیڈ** |
| فونٹس تبدیل کریں | **کنٹرول سینٹر → فونٹس** |
| ڈیفالٹ ایپلی کیشنز کا انتخاب کریں | **کنٹرول سینٹر → ڈیفالٹ ایپلی کیشنز** |
| ڈسپلے کی ترتیبات کو تبدیل کریں | **کنٹرول سینٹر → ڈسپلے** یا کنٹرول پینل ڈسپلے کارڈ |
| نیٹ ورک کنکشن چیک کریں یا تبدیل کریں | کنٹرول پینل نیٹ ورک کارڈ؛ مستقل نیٹ ورک کنفیگریشن انسٹال کردہ نیٹ ورک ٹولز کے ذریعہ فراہم کی جاتی ہے۔
| والیوم تبدیل کریں یا جلدی سے خاموش کریں | کنٹرول پینل والیوم کارڈ یا میڈیا کیز |
| چمک کو جلدی سے تبدیل کریں | کنٹرول پینل برائٹنس کارڈ یا برائٹنیس کیز |
| لاک، لاگ آؤٹ، معطل یا پاور آف | کنٹرول پینل سیشن/پاور کارڈز |
| زبان، ٹائم زون یا علاقائی ترتیبات کو ترتیب دیں | **کنٹرول سینٹر → مقام اور علاقہ** |

## کنفیگریشن یا فوری ایکشن؟

جب آپ چاہتے ہیں کہ کوئی ترتیب آپ کے ڈیسک ٹاپ کنفیگریشن کا حصہ بنی رہے تو کنٹرول سینٹر دیکھنے کی جگہ ہے۔ کنٹرول پینل یہ دیکھنے کی جگہ ہے جب آپ اسٹیٹس کا معائنہ کرنا چاہتے ہیں یا ابھی بار بار کارروائی کرنا چاہتے ہیں۔ کچھ کنٹرول پینل کارڈ وہی بنیادی فراہم کنندگان کو کھولتے ہیں جو کنٹرول سینٹر کے ذریعہ استعمال ہوتے ہیں، لیکن پینل سیٹنگز کا دوسرا ڈیٹا بیس نہیں ہے۔

اگر کوئی ترتیب درج نہیں ہے تو، کنٹرول سینٹر کی ہوم تلاش کا استعمال کریں۔ اس کی تلاش کی رجسٹری میں صارف کے سامنے آنے کے راستے اور کی بورڈ، ان پٹ، ڈسپلے، نیٹ ورک اور سیشن ڈومین شامل ہیں۔
