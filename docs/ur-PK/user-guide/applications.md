- [لانچر](/docs/argvus-launcher/)
- [ٹرمینل](/docs/components/argvus-terminal/)
- [کیلنڈر](/docs/components/argvus-taskbar-calendar/)
- [ARGVUS فوکس](/docs/components/argvus-focus/) (پومودورو اور فوکس سیشنز)
- [ARGVUS Clock](/docs/components/argvus-clock/) (گھڑی، عالمی گھڑیاں، اسٹاپ واچ، ٹائمر اور الارم)
- [گیمز](/docs/argvus-games/) (بشمول [Snake](/docs/argvus-games/snake/))
- [                                                                   ﺮﭩﯿﻧﺎﻣ ﻢﭩﺴﺳ](/docs/components/argvus-system-monitor/)
- [پہلے سے طے شدہ ایپلی کیشنز](/docs/components/argvus-control-center/)
- [ہٹائی جانے والی ڈیوائسز](/docs/components/argvus-removable-devices/)

کنٹرول سینٹر `argvus --control-center` کے ساتھ کھولا گیا ہے۔ اس کا ایپس صفحہ ڈیفالٹ ایپلیکیشنز کا نظم کرتا ہے۔
