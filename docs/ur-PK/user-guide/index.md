---

ARGVUS آرک لینکس کے لیے ایک ماڈیولر ہائپرلینڈ اور وائی لینڈ ڈیسک ٹاپ ماحول ہے۔ [انسٹالیشن](/docs/getting-started/installation/) کے ساتھ شروع کریں، پھر صارف گائیڈ سے ایک فیچر منتخب کریں۔

ڈیسک ٹاپ ایک ہائپرلینڈ سیشن، ایک وے بار ٹاسک بار، کوئیک شیل کنٹرول پینل، مقامی ایپلی کیشنز اور سسٹم فراہم کنندگان کو یکجا کرتا ہے۔ [آرکیٹیکچر گائیڈ](/docs/developer-guide/architecture/overview/) بتاتا ہے کہ یہ ٹکڑے ایک ساتھ کیسے کام کرتے ہیں۔

## کامن انٹری پوائنٹس

- `argvus --control-center` کے ساتھ سیٹنگز ایپلیکیشن کھولیں۔
- `argvus --calendar` کے ساتھ کیلنڈر کھولیں۔
- `argvus sessionctl status` کے ساتھ سیشن کا معائنہ کریں۔
- `argvus --help` کے ساتھ انسٹال کردہ کمانڈ لسٹ پڑھیں۔
