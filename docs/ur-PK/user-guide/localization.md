title: لوکلائزیشن
description: انگریزی یا پرتگالی میں ARGVUS استعمال کریں۔
---

`argvus-i18n` مشترکہ کیٹلاگ، `argvus i18n validate` کمانڈ اور QML ماڈیول `org.argvus.i18n` فراہم کرتا ہے۔ ARGVUS فی الحال انگریزی اور پرتگالی کیٹلاگ بھیجتا ہے۔

مقامی ایپلی کیشنز اور شیل اجزاء مشترکہ کیٹلاگ استعمال کرتے ہیں۔ اس لیے ایک ترجمہ شدہ سٹرنگ ایک سے زیادہ ریپوزٹری استعمال کر سکتی ہے۔

زبان، علاقائی لوکیل، جنریٹڈ سسٹم لوکیلز، ٹائم زون، تاریخ/وقت اور کی بورڈ کو کنفیگر کرنے کے لیے **کنٹرول سینٹر → لوکیل اور ریجن** کا استعمال کریں۔ موجودہ ARGVUS کیٹلاگ انگریزی اور پرتگالی فراہم کرتے ہیں۔ یہ سسٹم لوکیلز کی فہرست سے الگ ہے جو آپریٹنگ سسٹم نے تیار کیا ہے۔

ڈسپلے لینگویج کو تبدیل کرنے سے ARGVUS کی ترجیح محفوظ ہو جاتی ہے اور خود بخود `argvus-control-panel.service` دوبارہ شروع ہو جاتا ہے، لہذا کنٹرول پینل فوری طور پر تبدیلی کی عکاسی کرتا ہے۔ دیگر ایپلی کیشنز اور شیل سطحوں کو سیشن دوبارہ لوڈ یا ایک نئے سیشن کی ضرورت ہو سکتی ہے۔ `/etc/locale.gen` اندراجات بنانے یا تبدیل کرنے کے لیے اجازت درکار ہوتی ہے اور `locale-gen` کو چلاتا ہے۔ ایک ایسے مقام کا انتخاب کرنا جو پیدا نہیں ہوا ہے مسترد کر دیا جاتا ہے۔ کی بورڈ لے آؤٹ، ویرینٹ اور کنسول کی میپ الگ الگ سیٹنگز ہیں اور ان کو انٹرفیس لینگویج کے ساتھ الجھن میں نہیں ڈالنا چاہیے۔

## جب ماحولیاتی متغیر تبدیلی کو اوور رائیڈ کرتے ہیں۔

ARGVUS ایپلیکیشنز پہلے مستقل ARGVUS زبان کی فائل سے زبان کا پتہ لگاتی ہیں، پھر `LC_ALL`، `LC_MESSAGES` اور `LANG`۔ مقامی ماحول کے متغیرات اس وجہ سے کنٹرول سینٹر کو زبان کی تبدیلی کو نظر انداز کرتے ہوئے ظاہر کر سکتے ہیں، خاص طور پر جب صارف کی خدمت یا گرافیکل سیشن پرانے ماحول کو برقرار رکھتا ہے۔

اس کے ساتھ موثر اقدار کا معائنہ کریں:

```sh
systemctl --user show-environment | rg '^(LANG|LC_|ARGVUS)='
locale
echo $LANG
localectl status
```

اگر `~/.config/locale.conf` موجود ہے اور `LANG`، `LC_ALL` یا `LC_MESSAGES` کی وضاحت کرتا ہے، تو اس کا نام عارضی طور پر تبدیل کریں تاکہ یہ ان اقدار کو دوبارہ پیش نہ کرے۔ اسے حذف کرنے کے بجائے بیک اپ رکھیں:

```sh
mv ~/.config/locale.conf ~/.config/locale.conf.backup
```

زبان کو دوبارہ **کنٹرول سینٹر → لوکیل اور ریجن** میں لاگو کریں۔ کنٹرول پینل خود بخود دوبارہ شروع ہو جاتا ہے۔ اگر دوسرے اجزاء اب بھی پچھلی زبان دکھاتے ہیں، لاگ آؤٹ کریں اور اس طرح گرافیکل سیشن اور `systemd --user` کو نیا ماحول ملے گا۔ بعد میں تشخیصی احکامات کو دہرائیں۔ تکنیکی معاہدوں اور ترجیح کے لیے [ماحولیاتی متغیرات](/docs/reference/environment-variables/) دیکھیں۔
