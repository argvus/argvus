---
title: ورچوئل مشینیں۔
description: ورچوئل گرافکس ہارڈویئر کے ساتھ ARGVUS چلائیں۔
---

`argvus start` ورچوئلائزیشن کا پتہ لگاتا ہے اور متاثرہ سیشنز کے لیے مطابقت کی ترتیبات برآمد کرتا ہے، بشمول سافٹ ویئر رینڈرنگ اور کرسر/موڈیفائر فال بیکس جب پتہ چلا ماحول کی ضرورت ہو۔

اگر کوئی ورچوئل مشین اب بھی رینڈر کرنے میں ناکام رہتی ہے تو اوور رائڈ شامل کرنے سے پہلے سیشن کے ماحول اور لاگ کا معائنہ کریں۔ دیکھیں [گرافکس کی خرابیوں کا سراغ لگانا](/docs/user-guide/troubleshooting/graphics-and-virtual-machines/)۔

ورچوئلائزیشن کا پتہ چلنے پر، `argvus start` سیشن کے لیے مطابقت کے متغیرات کو برآمد کرتا ہے، بشمول سافٹ ویئر رینڈرنگ، سافٹ ویئر کرسر اور موڈیفائر فال بیکس۔ یہ عام لاگ ان پاتھ کو پہلی چیز بناتا ہے ایک مستقل اوور رائڈ شامل نہ کریں کیونکہ ڈیسک ٹاپ VM میں چل رہا ہے۔

اگر پتہ لگانا کافی نہیں ہے تو، تشخیصی فال بیک کے طور پر صارف Hyprland اوور رائڈ کا استعمال کریں:

```sh
mkdir -p ~/.config/argvus/data/hypr
nano ~/.config/argvus/data/hypr/user.lua
```

اسے صرف اس وقت شامل کریں جب VM گرافکس اسٹیک کو اس کی ضرورت ہو:

```lua
hl.env("LIBGL_ALWAYS_SOFTWARE", "1")
```

سیشن کے ماحول کو تبدیل کرنے کے بعد لاگ آؤٹ کریں اور واپس جائیں۔ `echo $LIBGL_ALWAYS_SOFTWARE` کے ساتھ فعال قدر کی تصدیق کریں۔ سافٹ ویئر رینڈرنگ ڈیسک ٹاپ کو قابل استعمال بنا سکتا ہے لیکن کارکردگی کو کم کر سکتا ہے۔
