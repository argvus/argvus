`argvus network` ذیلی کمانڈ نیٹ ورک مینیجر کی رپورٹ اور کنٹرول کرتا ہے، اور `argvus bluetooth` بلوٹوتھ اڈاپٹر کی حالت اور دستیابی کو رپورٹ اور کنٹرول کرتا ہے۔ دونوں `argvus` کے اندر عمل میں چلتے ہیں۔ `networkctl` اور `bluetoothctl` بطور عرفی باقی ہیں۔ کنٹرول پینل اور وے بار ان کمانڈز کو کال کرتے ہیں۔

انسٹال شدہ ذیلی کمانڈز کے لیے کسی بھی کمانڈ پر `--help` استعمال کریں۔ نیٹ ورک اور بلوٹوتھ UI انٹیگریشن اختیاری ایڈوانس مینیجرز جیسے بلیو مین سے الگ ہے۔

کنٹرول سینٹر نیٹ ورک کی حیثیت کو کنفیگریشن صفحات سے الگ کرتا ہے: **نیٹ ورک → اسٹیٹس** موجودہ حالت کا خلاصہ کرتا ہے، جب کہ انٹرفیس، وائی فائی، ایتھرنیٹ، وی پی این، ڈی این ایس، پراکسی اور فائر وال علیحدہ راستے ہوتے ہیں جب ان کے فراہم کنندگان دستیاب ہوتے ہیں۔ **بلوٹوتھ → اسٹیٹ**، **آلات** اور **جوڑا** اڈاپٹر کی حالت اور ڈیوائس کی کارروائیوں کا احاطہ کرتا ہے۔ یہ صفحات فراہم کنندہ کی حمایت یافتہ نظام کی کارروائیاں انجام دیتے ہیں۔ ٹاسک بار اور کنٹرول پینل فوری اسٹیٹس/ایکشن سطح کو بے نقاب کرتے ہیں۔

نیٹ ورک اور بلوٹوتھ تبدیلیوں کے لیے اجازت درکار ہو سکتی ہے اور یہ نیٹ ورک مینجر یا بلوٹوتھ سروس کے ذریعے فوری طور پر لاگو ہو سکتی ہے۔ وہ ARGVUS ٹاسک بار کے اشارے کو تبدیل کرنے جیسے نہیں ہیں۔

کنٹرول سینٹر `--ask` کے ساتھ معیاری ان پٹ کے ذریعے nmcli کو Wi-Fi پاس ورڈ بھیجتا ہے۔ پاس ورڈز کو عمل کے دلائل سے خارج کر دیا گیا ہے اور کمانڈ کی واپسی کی غلطیوں سے اصلاح کی گئی ہے۔

## کمانڈ لائن نیٹ ورک مینجمنٹ

گرافیکل انٹرفیس کے بغیر نیٹ ورکنگ کو پوچھنے اور کنٹرول کرنے کے لیے `argvus networkctl` استعمال کریں:

```sh
# Show network status
argvus networkctl status

# Toggle networking on/off
argvus networkctl enable
argvus networkctl disable

# Wi-Fi control
argvus networkctl wifi on
argvus networkctl wifi off

# Open the network manager
argvus networkctl manager
```

## کمانڈ لائن بلوٹوتھ مینجمنٹ

بلوٹوتھ اڈاپٹر کے لیے `argvus bluetoothctl` استعمال کریں:

```sh
# Show the adapter state (key=value lines)
argvus bluetoothctl status

# Exit 0 when an adapter is available, 1 otherwise
argvus bluetoothctl available

# Turn the adapter on or off, or toggle it
argvus bluetoothctl enable
argvus bluetoothctl disable
argvus bluetoothctl toggle

# Open the Bluetooth manager (Blueman)
argvus bluetoothctl manager
```

جب کرنل `/sys/class/bluetooth` میں کسی کنٹرولر کی فہرست نہیں دیتا ہے، `status` bluetoothctl پوچھے بغیر، `status=no-controller` کا فوری جواب دیتا ہے (جو سروس بند ہونے پر BlueZ کا انتظار کرے گا)۔ ٹاسک بار ماڈیول اور کنٹرول پینل کارڈ ایک ہی حیثیت کو پڑھتے ہیں۔

اپنے انسٹال کردہ ورژن کے لیے مخصوص اضافی اختیارات اور ذیلی کمانڈز دیکھنے کے لیے کسی بھی کمانڈ پر  `bluetoothctl` `--help` استعمال کریں۔

جب Wi-Fi پاس ورڈ ڈائیلاگ کھلا ہے، اسکین اپ ڈیٹس منتخب کردہ SSID اور سیکیورٹی کی قسم کو محفوظ رکھتی ہیں۔ اگر وہ نیٹ ورک غائب ہو جاتا ہے یا اس کی سیکیورٹی میں تبدیلی آتی ہے، تو تصدیق ایک خرابی کے ساتھ رک جاتی ہے اور اسے ایک نئے انتخاب کی ضرورت ہوتی ہے۔

دستی DNS حل کرنے والی فائل کو اپ ڈیٹ کرنے سے پہلے IPv4 اور IPv6 سرورز کو ان کے متعلقہ NetworkManager سیٹنگز میں بھیجتا ہے۔ سروس کے زیر انتظام حل کرنے والے سملنک فائل کو تبدیل کرنے سے انکار کر کے محفوظ کیے جاتے ہیں۔ خودکار DNS پر کامیاب واپسی بیک اپ کو بحال اور ہٹا دیتی ہے، لہذا بعد میں دستی سائیکل موجودہ حل کرنے والی حالت کو بچاتا ہے۔

نیٹ ورک پروفائل ایڈیٹر کو بند کرنے سے اس کا موجودہ کام ختم ہونے کا انتظار ہوتا ہے، اس لیے ایڈیٹر کو ضائع کر کے پروفائل کو محفوظ کرنے یا حذف کرنے میں رکاوٹ نہیں بن سکتی۔ پس منظر کی تازہ کارییں منسوخ کی جا سکتی ہیں۔

وائی ​​فائی کنکشن کی درخواستیں نیٹ ورک ایکشن گارڈ کا اشتراک کرتی ہیں: ایک رننگ ایکشن یا پروفائل ایڈیٹر کا کام مکمل ہو جاتا ہے اس سے پہلے کہ کوئی اور تبدیلی شروع ہو سکے۔ پیشرفت اور تکمیل کے پیغامات منتخب زبان کی پیروی کرتے ہیں۔

بلوٹوتھ ہٹانے کی تصدیق آلہ کی فہرست کے ریفریش ہونے پر بھی اصل آلہ کا پتہ برقرار رکھتی ہے۔ بلوٹوتھ سی ٹی ایل سے بیٹری کے فیصد کو تسلیم کیا جاتا ہے، اور ڈیوائس کی تفصیل کے سوالات باؤنڈڈ کنکرنسی اور انفرادی ٹائم آؤٹ کے ساتھ چلتے ہیں۔

Wi-Fi پاس ورڈ، دستی DNS اور نیٹ ورک سرچ فیلڈز بریکٹ شدہ پیسٹ کو قبول کرتے ہیں۔ پیسٹ کیے گئے کنٹرولز اور لائن بریکس کو چھوڑ دیا گیا ہے۔ غیر تعاون یافتہ Ctrl-only یا Alt-only کریکٹر شارٹ کٹ حروف داخل نہیں کرتے ہیں۔ ایڈیٹرز Ctrl+Alt کے بطور انکوڈ شدہ پرنٹ ایبل AltGr ایونٹس کو قبول کرتے ہیں۔ Ctrl+S صرف Alt کے بغیر محفوظ کرتا ہے۔ مشترکہ ٹیکسٹ ایڈیٹر بصری کالموں میں عمودی نیویگیشن رکھتا ہے اور وسیع حروف کے لیے افقی اسکرولنگ کو سیدھ میں رکھتا ہے۔ٹاسک بار نیٹ ورک انڈیکیٹر `argvus networkctl waybar --follow` کا استعمال کرتے ہوئے نیٹ ورک مینجر کے واقعات کی پیروی کرتا ہے، ابتدائی سنیپ شاٹ اور خودکار مانیٹر دوبارہ کنکشن کے ساتھ۔ اب یہ 10 سیکنڈ کے پولنگ وقفے کا انتظار نہیں کرتا۔ منسلک، محدود انٹرنیٹ تک رسائی اور منقطع الگ الگ ریاستیں رہیں۔ Wi-Fi اسٹیٹس اسکین کی درخواست کیے بغیر کیشڈ رسائی پوائنٹس کو پڑھتا ہے۔ `argvus networkctl waybar` واحد Waybar JSON سنیپ شاٹ خارج کرتا ہے۔
