# ARGVUS کیلکولیٹر

`argvus calculator` · `SUPER + C` · launcher: **ARGVUS Calculator**

ترتیبات → پروفائل میں ↑/↓ اور Enter یا قطار پر کلک سے انتخاب کریں۔ پروفائل اور اختیارات فوراً محفوظ ہوتے ہیں اور اگلی بار بحال ہوتے ہیں۔ ہر پروفائل سیشن میں اپنی عبارت رکھتا ہے۔ Enter یا = عبارت کو نتیجے سے بدلتا ہے، منتخب کیے بغیر کرسر آخر میں رکھتا ہے۔

شرح فی مدت فیصد ہے؛ شرح، تعداد اور ادائیگی کے لیے ایک ہی مدت رکھیں۔ ادائیگی مدت کے آخر میں ہوتی ہے اور صفر شرح ممکن ہے۔ سادہ اور مرکب سود جمع شدہ کل دیتے ہیں۔ تبدیلی آف لائن ہے، کرنسیاں شامل نہیں۔ تاریخ پروفائل، اختیارات اور مالی اندراجات سمیت 100 ریکارڈ رکھتی ہے؛ نتیجہ منتخب کرنے سے سیاق بحال ہوتا ہے۔ صاف کرنے سے محفوظ فائل بھی خالی ہوتی ہے۔

## پروگرامنگ

طے شدہ: اعشاری، علامت کے ساتھ 64 بٹ۔ حساب ورڈ کی چوڑائی پر گردش کرتا ہے؛ علامت والا دایاں شفٹ علامت بڑھاتا ہے۔ صحیح عدد کی تقسیم صفر کی طرف کاٹتی ہے۔ صفر سے تقسیم اور [0, bits) سے باہر شفٹ غلطیاں ہیں۔ بغیر سابقے کی تعداد منتخب بنیاد استعمال کرتی ہے۔ بنیاد بدلنے پر درست عبارت تبدیل ہوتی ہے؛ چوڑائی یا علامت بدلنے پر وہی بٹ دوبارہ سمجھے جاتے ہیں۔

- **بنیاد**: 2 / 8 / 10 / 16; **ورڈ سائز (بٹ)**: 8 / 16 / 32 / 64.
- **علامت کے ساتھ** / **بغیر علامت** · `0b1010`, `0o12`, `0xA`.
- `+ - * / %`, `AND OR XOR NOT`, `<< >>`, `& | ^ ~`, `(`, `)`.
- `9007199254740993+2 = 9007199254740995`; `0xFF AND 0b1010 = 10` (base 10).
- 8-bit: `255+1 = 0`; `NOT 0 = -1` (علامت کے ساتھ); `-7/2 = -3`.

## مالی

سادہ سود · مرکب سود · مقررہ قسط · موجودہ قدر · مستقبل کی قدر · فیصد تبدیلی.

- `P`: ابتدائی سرمایہ; `FV`: مستقبل کی رقم; `A`: فی مدت ادائیگی.
- `r`: فی مدت شرح (%) / 100; `n`: مدتوں کی تعداد.
- `G=(1+r)^n`; `H=(G-1)/r` (`r=0`: `H=n`).
- سادہ سود: `P*(1+r*n)`; مرکب سود: `P*G`.
- مقررہ قسط: `P*G/H`; موجودہ قدر: `(FV+A*H)/G`; مستقبل کی قدر: `P*G+A*H`.
- فیصد تبدیلی: `(حتمی رقم - اصل رقم) / اصل رقم * 100`.
