ARGVUS میں ایک تھیم پورے ڈیسک ٹاپ پر استعمال ہونے والے رنگوں، سطحوں، وال پیپر کے ڈیفالٹس اور ترتیب جیومیٹری کو سیٹ کرتا ہے: Hyprland، Waybar، کنٹرول پینل، ٹاسک بار، لاک اسکرین، اطلاعات اور ARGVUS ایپلیکیشنز۔ یہ گائیڈ ہر چیز کا احاطہ کرتا ہے جس کی آپ کو بطور صارف تھیمز کے ساتھ کام کرنے کی ضرورت ہے۔

## تھیم میں کیا شامل ہے۔

ہر سرکاری تھیم دو طریقوں کے ساتھ ایک مکمل بصری شناخت ہے:

- **چپچپا** — ایک کمپیکٹ لے آؤٹ جس میں ونڈو کے چھوٹے فرق ہیں، کوئی بیرونی خلا نہیں اور اسکرین کے کنارے کے قریب ٹاسک بار۔
- **فاصلہ** — ٹاسک بار اور شیل کی سطحوں کے ارد گرد بڑے خلاء، گول کونے اور مارجن کے ساتھ ایک کشادہ ترتیب۔

تھیم کو منتخب کرنے سے اس کی شناخت تبدیل نہیں ہوتی ہے: پیلیٹ، ڈیفالٹ ہائی لائٹ رنگ اور وال پیپر ایسوسی ایشن طریقوں کے درمیان یکساں رہتے ہیں۔ موڈ ایک الگ ترتیب ہے، دیکھیں [آفیشل تھیمز](/docs/components/argvus-themes/official-themes/)۔

## اس گائیڈ میں صفحات

- [تھیمز انسٹال کرنا](/docs/components/argvus-themes/installing-themes/) — آفیشل تھیمز کہاں سے آتے ہیں اور `pacman` کے ساتھ ان میں سے ایک یا سبھی کو کیسے انسٹال کیا جائے۔
- [آفیشل تھیمز](/docs/components/argvus-themes/official-themes/) — کیٹلاگ، ہر تھیم کا ڈیفالٹ ہائی لائٹ کلر، اور تھیم اور اس کا موڈ کیسے منتخب کیا جائے۔
- [ہائی لائٹ رنگ کو حسب ضرورت بنانا](/docs/components/argvus-themes/highlight-color/) — تھیم سے آزادانہ طور پر لہجے کا رنگ تبدیل کریں۔
- [تھیمز امپورٹ اور ایکسپورٹ کرنا](/docs/components/argvus-themes/import-and-export/) — ایکٹو تھیم کو اپنے ہائی لائٹ کلر اور وال پیپر کے ساتھ اپنی تھیم کے طور پر ایکسپورٹ کریں اور اسے دوسری مشین پر امپورٹ کریں۔

## فوری حوالہ

| ٹاسک | کہاں |
| --- | --- |
| ایک تھیم چنیں | **کنٹرول سینٹر → ظاہری شکل → تھیمز → آفیشل تھیمز** |
| چسپاں اور فاصلہ پر سوئچ کریں | **کنٹرول سینٹر → ظاہری شکل → موڈ** |
| نمایاں رنگ تبدیل کریں | **کنٹرول سینٹر → ظاہری شکل → نمایاں رنگ** |
| فعال تھیم برآمد کریں | **کنٹرول سینٹر → ظاہری شکل → تھیمز → ایکسپورٹ تھیم** |
| ایک تھیم درآمد کریں | **کنٹرول سینٹر → ظاہری شکل → تھیمز → امپورٹ تھیم** |
| کی بورڈ سے تھیم سلیکٹر کھولیں۔ `SUPER + SHIFT + T` |

## تھیمز کہاں سے آتے ہیں۔

ARGVUS `argvus-appearance` پیکیج کے ساتھ دو بلٹ ان تھیمز، **ARGVUS Dark** اور **ARGVUS Light** بھیجتا ہے۔ ہر دوسری آفیشل تھیم ایک علیحدہ `argvus-theme-<name>` پیکیج ہے۔ تھیم پیکج انسٹال کرنا اسے تھیم سلیکٹر میں شامل کرتا ہے۔ سیشن کو دوبارہ شروع کرنے کی ضرورت نہیں ہے۔ آپ کے اپنے تھیمز، برآمد یا درآمد شدہ، الگ سے **حسب ضرورت تھیمز** کے طور پر درج ہیں۔

## کی بورڈ اشارے

کنٹرول سینٹر تھیم کے صفحات فوٹر میں اپنی کلیدیں دکھاتے ہیں:

- `↑` / `↓` — نیویگیٹ کریں۔
- `Enter` — لگائیں یا کھولیں۔
- `e` — ایکٹو تھیم کو تھیمز کے صفحے پر برآمد کریں۔
- `i` — تھیمز کے صفحہ پر تھیم درآمد کریں۔
- `d` — اپنی مرضی کے مطابق تھیم کو حذف کریں۔
- `Esc` — واپس جائیں۔

## خرابی کا سراغ لگانا

- **میں نے انسٹال کی تھیم ظاہر نہیں ہوتی ہے۔** تصدیق کریں کہ پیکیج `pacman -Q argvus-theme-<name>` کے ساتھ انسٹال ہے، پھر کنٹرول سینٹر دوبارہ کھولیں۔ پیکیج `argvus-appearance` موجود کے ساتھ انسٹال ہونا چاہیے۔
- **میں نے تھیم کو تبدیل کرنے کے بعد ہائی لائٹ کا رنگ تبدیل کر دیا ہے۔ تھیم کو اس کا اپنا رنگ واپس دینے کے لیے **تھیم ڈیفالٹ پر ری سیٹ کریں** کا استعمال کریں۔
- **ایک تھیم آرکائیو درآمد کے لیے درج نہیں ہے۔** اسے براہ راست آپ کی ہوم ڈائرکٹری میں ہونا چاہیے اور `<id>/theme.toml` کو ہولڈ کرنا چاہیے۔ دیکھیں [تھیمز کی درآمد اور برآمد](/docs/components/argvus-themes/import-and-export/)۔
