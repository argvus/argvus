title: انضمام
description: کمپوزیٹر، لاگ ان، لاک اور پورٹل انضمام۔
---

`argvus-hyprland` پیکیجز کمپوزر کنفیگریشن؛ `argvus-portal` پیکیجز XDG پورٹل انضمام؛ `argvus-greeter` greetd کو مربوط کرتا ہے؛ `argvus-lock` Hyprlock کو مربوط کرتا ہے۔ `argvus` میں بھیجے گئے لوڈنگ اوورلے سیشن لوڈنگ ویژولز کو مربوط کرتا ہے۔ اور `argvus-boot-splash` بوٹ ویژول کو مربوط کرتا ہے۔
