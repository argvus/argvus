ورک اسپیس میں وہ کریٹس بھی ہوتے ہیں جو کمانڈز بانٹتے ہیں:

- `argvus-config`: کیننیکل کنفیگریشن اسٹور اور تیار کردہ درخت کا واحد مصنف (`data/generated/`)۔ یہ ایک لائبریری بھی ہے جو `argvus config`، `theme-switch` اور `effects-toggle` کے ذریعے عمل میں استعمال ہوتی ہے۔
- `argvus-i18n` اور `argvus-i18n-core`: `resources/locales/` میں کیٹلاگ، ان کی توثیق، اور `org.argvus.i18n` QML ماڈیول۔
- `argvus-tui` اور `argvus-theme`: مشترکہ ٹرمینل UI اور تھیم لوڈنگ۔
- `argvus-runtime`: ترجمہ شدہ پیغامات اور کمانڈز کے ذریعے اشتراک کردہ عمل کے مددگار۔

`argvus-session` ایک الگ ذخیرہ رہتا ہے۔ یہ سیشن انٹری پوائنٹس (`session`, `start`, `tty`) اور لائف سائیکل یونٹ فراہم کرتا ہے، اور `argvus sessionctl` اپنے کنٹرولر تک پہنچ جاتا ہے۔
