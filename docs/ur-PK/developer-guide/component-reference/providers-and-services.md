---
title: فراہم کنندگان اور خدمات
description: ARGVUS فراہم کنندہ پیکیجز۔
---

فراہم کنندگان کے پیکیجز میں `argvus-display`، `argvus network`، `argvus-power`، `argvus-notifications`، `argvus-firewall` اور `argvus accounts` شامل ہیں۔ وہ UI پیکجوں کے ذریعہ استعمال کردہ فوکسڈ کمانڈز، کنفیگریشن اور سسٹم کے انضمام کو بے نقاب کرتے ہیں۔
