---
title: ترجمہ
description: مشترکہ ARGVUS لوکلائزیشن کیٹلاگ کو برقرار رکھیں۔
---

`argvus-i18n` مشترکہ کیٹلاگ اور QML ماڈیول کا مالک ہے۔ صارف کے نظر آنے والے متن کو تبدیل کرتے وقت انگریزی اور پرتگالی کیٹلاگ کو ایک ساتھ اپ ڈیٹ کریں، پھر چلائیں:

```sh
argvus i18n validate
```

صارفین میں مقامی رسٹ ایپلی کیشنز، شیل اجزاء اور سیشن مددگار شامل ہیں۔
