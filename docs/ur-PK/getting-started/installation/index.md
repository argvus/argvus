title: انسٹالیشن
description: Arch Linux پر ARGVUS پیکجز انسٹال کریں۔

ARGVUS کو دستخط شدہ آرک لینکس پیکجز کے طور پر تقسیم کیا جاتا ہے۔ عوامی انسٹالر ARGVUS پیکیج ریپوزٹری کو تشکیل دیتا ہے۔ پیکیج سیٹ پھر ڈیسک ٹاپ کے اجزاء کو انسٹال کرتا ہے۔
