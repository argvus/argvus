ARGVUS سرکاری ARGVUS پیکیج ریپوزٹری کے ذریعے آرک لینکس پیکیج کے طور پر تقسیم کیا جاتا ہے۔

## انسٹال کرنے سے پہلے

ARGVUS انسٹال کرنے سے پہلے آفیشل Arch Linux `multilib ` ریپوزٹری کو فعال کریں۔ `/etc/pacman.conf ` میں ترمیم کریں اور `[multilib]` سیکشن اور اس کی ` Include` لائن دونوں کو غیر تبصرہ کریں:

```ini
[multilib]
Include = /etc/pacman.d/mirrorlist
```

پھر پیکیج ڈیٹا بیس کو ہم آہنگ کریں اور مکمل سسٹم اپ گریڈ کریں:

```sh
sudo pacman -Syu
```

فوری انسٹالر ARGVUS ریپوزٹری کو تشکیل دیتا ہے، لیکن `multilib` کو آپ کے لیے فعال نہیں کرتا ہے۔

## فوری انسٹال کریں۔

آرک لینکس کی تازہ تنصیب پر، آپ پہلے کسی دوسرے ڈیسک ٹاپ ماحول کو انسٹال کیے بغیر براہ راست TTY سے ARGVUS انسٹال کر سکتے ہیں۔

چلائیں:

```sh
curl -fsSL https://argvus.github.io/install.sh | sh
```

انسٹالر:

1. ARGVUS ریپوزٹری سائننگ کلید کو درآمد اور مقامی طور پر دستخط کرتا ہے۔
2. ARGVUS پیکیج ریپوزٹری کو کنفیگر کرتا ہے۔
3. پیکج ڈیٹا بیس کو اپ ڈیٹ کرتا ہے۔
4. `argvus` پیکیج اور اس کے انحصار کو انسٹال کرتا ہے۔

انسٹالیشن کے بعد، لاگ آؤٹ کریں اور اپنے ڈسپلے مینیجر سے **ARGVUS** کو منتخب کریں۔

> **نوٹ:** فوری انسٹالر کو `curl `، ` sudo`، اور معیاری آرک لینکس پیکیج مینجمنٹ ٹولز کی ضرورت ہوتی ہے۔

## صرف ذخیرہ کنفیگر کریں۔

ڈیسک ٹاپ کو انسٹال کیے بغیر ARGVUS پیکیج ریپوزٹری کو ترتیب دینے کے لیے، چلائیں:

```sh
curl -fsSL https://argvus.github.io/repo-install.sh | sh
```

اس کے بعد دستی طور پر ARGVUS انسٹال کریں:

```sh
sudo pacman -Syu argvus
```

## دستی تنصیب

اگر آپ ریپوزٹری کو مرحلہ وار ترتیب دینے کو ترجیح دیتے ہیں تو درج ذیل کمانڈز استعمال کریں۔

### 1. ریپوزٹری سائننگ کلید ڈاؤن لوڈ کریں۔

```sh
curl -fsSLo /tmp/argvus.gpg https://argvus.github.io/packages/arch/argvus.gpg
```

### 2. دستخطی کلید درآمد کریں۔

```sh
sudo pacman-key --add /tmp/argvus.gpg
```

### 3. کلید پر مقامی طور پر دستخط کریں۔

```sh
ARGVUS_KEY="$(gpg --show-keys --with-colons /tmp/argvus.gpg | grep '^pub:' | head -n1 | cut -d: -f5)"
sudo pacman-key --lsign-key "$ARGVUS_KEY"
```

### 4. ARGVUS ریپوزٹری کو کنفیگر کریں۔

```sh
curl -fsSL https://argvus.github.io/packages/arch/argvus.conf \
  | sudo tee /etc/pacman.d/argvus.conf
```

ذخیرہ کنفیگریشن کو `/etc/pacman.conf` میں شامل کریں:

```sh
echo "Include = /etc/pacman.d/argvus.conf" \
  | sudo tee -a /etc/pacman.conf
```

ریپوزٹری کنفیگریشن ARGVUS ریپوزٹریز کو قابل بناتی ہے، بشمول `argvus ` اور ` argvus-extras `، ` SigLevel = Required TrustedOnly` کے ساتھ۔ Pacman پیکجوں کو صرف اس صورت میں قبول کرتا ہے جب ان کے دستخط درست ہوں اور مقامی کیرنگ کے ذریعے قابل اعتماد ہوں۔

### 5. ARGVUS انسٹال کریں۔

```sh
sudo pacman -Syu argvus
```

انسٹالیشن کے بعد، لاگ آؤٹ کریں اور اپنے ڈسپلے مینیجر سے **ARGVUS** کو منتخب کریں۔

## اپ ڈیٹ

باقی آرک لینکس کے ساتھ مل کر ARGVUS کو اپ ڈیٹ کریں:

```sh
sudo pacman -Syu
```

صرف ARGVUS پیکیج کو اپ ڈیٹ کرنے کے لیے:

```sh
sudo pacman -S argvus
```

> **تجویز:** آرک لینکس عام طور پر انفرادی پیکجوں کو اپ ڈیٹ کرنے کے بجائے `sudo pacman -Syu` کے ساتھ مکمل سسٹم اپ گریڈ کرنے کی تجویز کرتا ہے۔

## ARGVUS کو ہٹا دیں۔

انحصار کو برقرار رکھتے ہوئے ARGVUS کو ہٹا دیں جو اب بھی دوسرے انسٹال شدہ پیکجوں کے لیے درکار ہیں:

```sh
sudo pacman -R argvus
```

ARGVUS اور انحصار کو ہٹا دیں جو اب کسی انسٹال شدہ پیکیج کے لیے درکار نہیں ہیں:

```sh
sudo pacman -Rns argvus
```

### ARGVUS ریپوزٹری کو ہٹا دیں۔

اگر آپ پیکیج ریپوزٹری کو بھی ہٹانا چاہتے ہیں تو اس کی کنفیگریشن کو ہٹا دیں:

```sh
sudo rm /etc/pacman.d/argvus.conf
```

پھر `/etc/pacman.conf` سے متعلقہ لائن کو ہٹا دیں:

```text
Include = /etc/pacman.d/argvus.conf
```

آپ اس کے ساتھ فائل میں ترمیم کر سکتے ہیں:

```sh
sudo nano /etc/pacman.conf
```

### دستخط کرنے والی کلید کو ہٹا دیں۔

پیک مین کیرنگ سے ARGVUS ریپوزٹری سائننگ کلید کو ہٹانے کے لیے، پہلے کیز کی فہرست بنائیں:

```sh
sudo pacman-key --list
```

پھر ARGVUS کلید کو اس کی کلید ID کے ساتھ ہٹا دیں:

```sh
sudo pacman-key --delete KEY_ID
```

`KEY_ID` کو ARGVUS سائننگ کلید ID سے تبدیل کریں۔

> **انتباہ:** اس کلید کو صرف اس وقت ہٹائیں جب آپ ARGVUS ریپوزٹری کو بھی ہٹا رہے ہوں۔ دیگر ذخیروں کے لیے درکار کلیدوں کو نہ ہٹائیں۔

## صارف کی ترتیب

پیکیج کی تنصیب `$HOME ` میں کنفیگریشن نہیں لکھتی ہے۔ ARGVUS `/usr/share/argvus` سے پیکڈ ڈیفالٹس پڑھتا ہے اور انہیں آپ کی ہوم ڈائرکٹری میں کاپی کیے بغیر کام کرتا ہے۔

رن ٹائم کنفیگریشن اس عمومی ترجیح کی پیروی کرتی ہے:

```text
~/.config/argvus/data/generated/<app>  ->  ~/.config/argvus/data/<component>/<app>  ->  $XDG_CONFIG_HOME/<app>  ->  /usr/share/argvus/<app>  ->  upstream defaults
```

`argvus-config ` وہ واحد جزو ہے جو `~/.config/argvus/data/generated/` لکھتا ہے، اور وہ پروجیکشن ایکٹو لیئر ہے: ایک منظم یا مقامی کاپی صرف اس وقت اثر انداز ہوتی ہے جب متعلقہ تیار کردہ فائل غائب ہو۔ARGVUS کے زیر انتظام کنفیگریشن `~/.config/argvus/` کے تحت رہتی ہے۔ ایک اختیاری `$XDG_CONFIG_HOME/<app>` اوور رائڈ ان ایپلی کیشنز کے لیے دستیاب رہتا ہے جو مقامی صارف کنفیگریشن کو سپورٹ کرتی ہیں۔

`argvus --setup` ڈسپیچر اختیاری ہے اور واضح دستی کے لیے ہے۔
اوور رائیڈ کرتا ہے، بازیابی نہیں۔ اگر `~/.config/argvus ` کو حذف کر دیا جاتا ہے، ` SUPER + SHIFT + R`
کیننیکل پروفائل اور جنریٹڈ رن ٹائم اسٹیٹ کو نارمل کے ذریعے دوبارہ بناتا ہے۔
پائپ لائن کو دوبارہ لوڈ کریں۔

```sh
argvus --setup --copy foot-tui
argvus --setup --copy kitty-tui
argvus --setup --copy-all
```

`--copy-all` تعاون یافتہ TUI پروفائل فائلوں کی ایک واضح اجازت یافتہ فہرست ہے۔ یہ
`/usr/share/argvus` کلون نہیں کرتا اور اسکرپٹس، خدمات، اثاثوں کو کاپی نہیں کرتا،
تیار کردہ فائلیں یا `config.json `۔ کرنٹ دیکھنے کے لیے ` argvus --setup --help` چلائیں۔
اختیارات ایک بار کاپی ہونے کے بعد، فائلیں صارف کی ملکیت میں اوور رائیڈز اور پیکیج بن جاتی ہیں۔
اپ گریڈ ان کی جگہ نہیں لیتے ہیں۔

موجودہ کاپی شدہ کنفیگریشن کو تبدیل کرنے کے لیے، `--force` استعمال کریں۔ ARGVUS اسے تبدیل کرنے سے پہلے ٹائم اسٹیمپڈ بیک اپ بناتا ہے:

```sh
argvus --setup --copy <app> --force
```

## Hyprland صارف کو اوور رائیڈ کرتا ہے۔

مکمل ہائپرلینڈ اوور رائیڈ گائیڈ کے لیے، بشمول ایک مکمل مقامی ترتیب اور بڑھنے والے ARGVUS ٹکڑوں کے درمیان فرق، دیکھیں [Hyprland overrides](/docs/argvus-hyprland/hyprland-overrides/)۔

```sh
mkdir -p ~/.config/argvus/data/hypr
nano ~/.config/argvus/data/hypr/user.lua
```

### ورچوئل مشین فال بیک

کچھ ورچوئل مشینیں Hyprland، Kitty، یا Quickshell کے ساتھ رینڈرنگ کے مسائل کا سامنا کر سکتی ہیں۔ ARGVUS `vmwgfx` گرافکس ڈرائیور کا استعمال کرتے ہوئے ورچوئل مشینوں کا پتہ لگاتا ہے اور ضرورت پڑنے پر سافٹ ویئر رینڈرنگ کو قابل بناتا ہے۔

اگر پتہ لگانا آپ کی ورچوئل مشین پر کام نہیں کرتا ہے، `user.lua` میں دستی طور پر فال بیک کو فعال کریں:

```lua
-- Virtual machine compatibility
hl.env("LIBGL_ALWAYS_SOFTWARE", "1")
```

`user.lua` بنانے یا اس میں ترمیم کرنے کے بعد، Hyprland سے لاگ آؤٹ کریں اور دوبارہ لاگ ان کریں تاکہ سیشن کے ذریعے شروع کی گئی ایپلیکیشنز پر متغیر کا اطلاق ہو۔

اس کے ساتھ تصدیق کریں:

```sh
echo $LIBGL_ALWAYS_SOFTWARE
```

متوقع پیداوار ہے:

```text
1
```

> **نوٹ:** `LIBGL_ALWAYS_SOFTWARE=1 ` Mesa/OpenGL ایپلیکیشنز کو عام طور پر ` llvmpipe` کے ذریعے سافٹ ویئر رینڈرنگ استعمال کرنے پر مجبور کرتا ہے۔ یہ گرافیکل کارکردگی کو کم کر سکتا ہے اور اسے متاثرہ ورچوئل مشینوں کے لیے فال بیک کے طور پر استعمال کیا جانا چاہیے۔
